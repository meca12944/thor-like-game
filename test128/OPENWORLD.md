# test128 — 세미 오픈월드 (이스8식) 1차 적용 (2026-10-23)

사장님 지시: 「방으로 던전을 유치하면 답답 → 세미 오픈월드 이스8처럼, 중간세이브 위치 등」 → 샌드박스(claude/attack3 `sandbox/openworld/`)로 확인 후 인게임 적용.

## 바뀐 것
- **바람길 + 시작의 숲 = 이어진 지도 하나** (120×40 타일). 걸어서 넘어가면 화면 위에 구역 이름만 뜨고 로딩(페이드)이 없다.
  - 원본 지도는 `maps/src/field00.json` · `maps/src/field01.json` 에서 고치고 `python3 tools/stitch_region01.py` 로 `maps/field00.json` 을 다시 만든다.
  - 시작의 숲은 x+56 자리에 들어감. 옛 이름 `field01`(던전 · 보스 출구, 월드맵, `?go=field01`)은 world.js `ALIAS` 가 자동으로 `field00` + 스폰 이름 `f01_…` 로 바꿔 준다.
  - `areas` = 구역 이름 범위. 처음 들어가면 자동 저장. 오른쪽 위 지명도 구역 이름으로 바뀜.
- **저장 3가지**
  - 비석(조사): 체력 회복 + 저장 + **쓰러지면 돌아오는 곳**.
  - **F5 어디서나 저장** (전투 밖일 때만, 140px 안에 적 · 챔피언 가시덩굴 · 보스 중이면 거절). 오른쪽 아래에 「● 저장 가능 / 전투 중」 표시.
  - 자동 저장: 새 구역 첫 진입, 챔피언 격파 뒤.
  - 저장하면 마을 빠른 저장(가방 · 골드 · 장비)도 같이 됨. **다시 켜면 저장한 필드 자리에서 이어하기** (`?nosave` = 무시). 마을로 돌아가면 필드 이어하기는 지워짐.
- **쓰러지면 선택**: 공격 키 = **다시 도전 (전투 직전 자리, 체력 최소 절반, 그 지도 몹 다시 배치)** · T = 마지막 비석 (없으면 예전처럼 지도 시작점).
- **챔피언 가시덩굴**: 챔피언에게 90px 안으로 다가가면 반경 150px(3/4 시점 타원) 가시덩굴이 솟아 나갈 수 없다. 챔피언이 쓰러지면 걷히고 자동 저장.
- **고대 숲 신전 B1 + B2 = 이어진 던전 하나** (92×23). 위층 계단방과 아래층 계단방을 비탈길 통로(2칸 폭, 횃불 2개)로 이어서 계단 전환이 없어졌다. 아래층으로 내려가면 「고대 숲 신전 · 아래층」 카드만 뜬다.
  - 원본 `maps/src/dungeon01_b1.json` · `dungeon01_b2.json` → `python3 tools/stitch_temple01.py` → `maps/dungeon01_b1.json`. 옛 이름 `dungeon01_b2`(보스방 출구 등)는 `ALIAS` 로 `dungeon01_b1` + `b2_…`.
  - 열쇠 → 잠긴 문 → 비탈길 → 레버 2개 → 철창 → 봉인된 문 순서는 그대로. **보스방(골렘의 방)만 문 너머 따로** (신전 안 유일한 화면 전환).
  - 봉인된 문 앞에 새 비석 「골렘의 방 앞 비석」 (규칙: 보스 앞 비석).
- **새 판 1장: 펠트 + 잿빛 들판 = 이어진 지도 하나 (`maps/ch1.json`)**. 펠트 아래 길로 걸어 나가면 화면 전환 없이 잿빛 들판. 구역 카드 + 음악이 구역을 따라 바뀜 (펠트 「잿더미의 종」 → 들판 곡). 펠트의 그린 배경 · 들판의 잿빛 색 보정은 각자 구역에만.
  - **펠트 = 그록 대표 그림 + 마을배경방 D=3 부품** (10-23): 문·NPC·대사·단서 원본은 `maps/src/felt.json` 에서 고치고 `python3 tools/hd/build_felt.py <부품 폴더>` 로 `maps/felt.json` + `maps/ch1.json`(들판 붙일 자리)을 다시 만든다. 자세한 것 = `handoff/claude/TOWN_LAYOUT_ko.md` 4.
  - `field_felt.json` 은 그대로 고치면 된다 (composeMap 이 켜질 때 붙임). 바닥·나무 그림(hd)만 `python3 tools/hd/build_field_felt_hd.py` 로 다시 뽑는다 (칸을 바꾸면 다시 뽑기). 옛 이름 `felt` · `field_felt` (?go=, ?at=, 퀘스트 목표, 월드맵)는 `ALIAS`/`aliasPt` 가 자동으로 `ch1` 좌표로 바꿔 준다.
- 지도 화면(M) · 미니맵 · 길 안내는 합친 지도 그대로 동작 (예전 field00/field01 탐험 안개는 한 번 초기화됨).
