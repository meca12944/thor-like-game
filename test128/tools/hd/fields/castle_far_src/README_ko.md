## 제작 방법
GenerateImage로 초록(#00FF00) 단색 배경 위에 1280×720 생성(3회 시도 중 3번째 채택, 원본 `src/gen_castle_try3.jpg`) → Lanczos 2배 확대 + 약한 언샤프(먹선) → 초록도 기반 크로마키, 스필 제거, 반투명 가장자리 언프리멀티플라이, 400px 미만 잔티·60px 미만 구멍 정리, 1px 안티에일리어싱 → 약한 세피아 그레이딩(창문 주황은 보존). 흰/검/마젠타 배경 합성으로 테두리 확인: 초록 우세 픽셀 0개, 테두리 무늬 없음. 스크립트: `src/key.py, prev.py, layers.py, anim.py`.

## 약점
- 2배 확대라 원본 디테일 밀도는 1280급 — 가까이 보면 약간 부드러움.
- 앞/뒤 분리는 "외성벽 띠"만 앞으로 뺀 단순 분리. 탑 군집 단위의 깨끗한 분리는 못 함.
- 깃발 없음(banners.png 비어 있음).
- 연기·까마귀는 절차 생성이라 원화보다 단순함. 연기는 정지 이미지에 없고 효과 레이어에만 있음.
- 텍스처가 다소 촘촘해 부분적으로 생성 이미지 느낌이 남아 있을 수 있음.
