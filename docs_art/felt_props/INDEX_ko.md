# 펠트 프롭 / 랜드마크 픽셀아트 (2단계 아트) — 인덱스

- 기준: 1타일 = 48 에셋 px, 기존 felt 외관 타일셋과 같은 픽셀 스케일·팔레트(32색 + 보조색 9)·3/4 오블리크 시점·어두운 1px 외곽선.
- 모든 PNG는 투명 배경, 알파는 0/255 이진, 팔레트 스냅 완료. 크기는 `가로×세로 px (타일)`.
- 앵커 제안: 특별한 언급이 없으면 **발 앵커 = 하단 중앙** (ax = w/2, ay = h). 데칼/바닥 타일은 중앙 앵커이며 depth는 바닥 레이어로 둔다.
- 스트립은 가로로 이어 붙인 프레임이다. 프레임 크기 = 스트립 높이 × (스트립 너비 / 프레임 수).
- 사람, 글자, 고어 없음. 시각 참고 자료: `contact_sheet.png`, `mockup_plaza.png`, `mockup_overview.png`(`_half`), `mockup_memorial_day_night.png`.
- 생성: PixelLab v2 `generate-with-style-v2`에 기존 마을 에셋을 스타일 레퍼런스로 넣었다. 애니메이션은 `animate-with-text-v3`와 절차적 후처리(아래 표기)로 만들었다. 원본 매핑은 `_sources.json`에 있다.
