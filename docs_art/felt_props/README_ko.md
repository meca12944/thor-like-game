# 펠트 마을 프롭 (felt_props)

펠트 마을 개선 계획(`../felt_review/PLAN_ko.md`)에 쓸 2단계 픽셀아트 프롭·랜드마크 모음입니다.
파일별 크기, 타일 수, 배치 제안 전체 목록은 **[INDEX_ko.md](INDEX_ko.md)** 에 있습니다. 원본 매핑은 `_sources.json`, 한눈에 보기는 `contact_sheet.png`와 `mockup_*.png`를 참고하세요.

## 앵커 / 레이어 메모
- 기준: 1타일 = 48 px. PNG는 모두 투명 배경이고 알파는 0/255 이진값입니다.
- 기본 앵커는 **발 앵커 = 하단 중앙** (ax = w/2, ay = h)입니다.
- 데칼(`ash_decal_*`)과 바닥 타일(`ash_ground_tile_*`)은 **중앙 앵커**를 쓰고, depth는 바닥 레이어에 둡니다.
- 스트립은 프레임을 가로로 이어 붙인 것입니다. 프레임 너비 = 스트립 너비 / 프레임 수입니다.
- `thread_clump_N_cut.png`는 원본과 크기와 앵커가 같아서 그대로 바꿔 끼우면 됩니다.

## 권장 사항
- **분수 물**: `fountain_water.png` / `fountain_water_strip.png`(6프레임 292×311, 프레임당 약 120ms)는 `fountain.png`와 **같은 x, y, 앵커 (146, 310)** 로 두고, depth만 **fountain보다 한 단계 위(fountain + 1)** 로 올립니다.
- **빨랫줄**: `laundry_line_strip.png`(4프레임 107×82, 프레임당 약 180ms)는 루프가 완벽하지 않으므로 **핑퐁**으로 재생합니다.
- **색조**: 목업에서만 화면 그레이딩/황혼 색을 곱했습니다. **프롭 파일 자체에는 색조를 넣지 않았으므로** 게임에서 장면 조명/틴트를 따로 적용하세요.
