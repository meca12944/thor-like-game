# 주인공 얼굴 판: 그록 부탁 + 찍는 법 (팀 회의 결론, 2026-10-25)

사장님 10-25: 「미니 캐릭 주인공 얼굴은 그록이 그려 주면 도장처럼 찍어 넣는다. 자연스러워야 한다.」
회의: 팀장 · 모션 · 검흔. 근거 = 모션 교과서(도장 v1 실측) + 검흔 자료(`claude/hero-grok-atk` `face_plate_study_v1`, Stardew 농부 층 방식) + 인터넷(아래 출처).

## 1. 왜 이렇게 정했나 (숫자)
- 게임 크기(키 144)에서 얼굴 살색 칸: 정면 13×16 · ↘ 10×10 · 옆 8×9 · ↗ 4×4.
- 도장 v1: 장마다 얼굴 중심이 0.4~2.3px 떨림. 옆얼굴 피부 겹침 0.41~0.49(가장 약함).
- **크게 그려 받아 줄이면 눈이 뭉개진다** (v1, 교과서). → 게임 1픽셀 = 정확히 10×10 칸으로 받아, 우리가 칸에 맞춰 1배로 되돌린다(부드럽게 섞지 않음).
- 그록 그림은 「가짜 도트」(칸이 고르지 않고 색이 수만 개) → 받은 뒤 칸 맞추기 + 6색으로 고정은 우리가 한다.
- v1 옆얼굴 세모 눈·납작 코 = 그림 도구가 다시 그리며 생김 → 그록 글에 눈·코 칸을 정확히 적는다.

## 2. 그록에 붙여 넣을 글

> 같이 올릴 그림: `docs_art/hero_face/face_ref_for_grok.png` (지금 주인공 머리 3방향을 10배로 키운 것, 노란 칸 = 얼굴 판 크기)

```
지금 게임 주인공(긴 검은 머리, 갈색 피부, 어두운 코트)의 "얼굴 판"을 도트로 그려 줘.
몸 그림 위에 도장처럼 찍어서, 걷기·달리기 모든 장의 얼굴을 똑같이 만들 거야.
올린 그림은 지금 게임 속 머리를 10배로 키운 거야. 한 칸 = 게임 1픽셀. 노란 칸이 얼굴 판 크기야.

규칙
- 진짜 도트: 게임 1픽셀을 정확히 10x10 정사각형 한 칸으로. 칸이 반듯하게 격자에 맞고, 경계를 부드럽게 섞지 마(안티에일리어싱 금지).
- PNG, 바탕 투명. jpg 금지.
- 색은 6개만: 피부 밝음 / 피부 기본(#af8570 근처) / 피부 그림자 / 눈(진한 색) / 눈 반짝임(흰색) / 입·볼. 쓴 색의 hex 코드를 같이 적어 줘.
- 눈: 정면·비스듬 = 2x2 진한 점 + 흰 반짝임 1칸. 옆 = 폭 1칸 x 높이 2칸 진한 세로줄, 옆 윤곽선에서 1칸 안쪽. 흰자 세모 금지.
- 코·입은 1칸짜리 점·선. 턱선 1칸.
- 정면·비스듬 판에는 바깥 테두리 선을 넣지 마(몸 그림의 턱선을 그대로 씀). 옆 판만 코·턱 옆선 1칸 포함, 코는 윤곽선에 1칸 혹.
- 얼굴 판에는 머리카락을 넣지 마. 앞머리는 따로 "앞머리 층"으로 그려 줘(같은 칸 위치, 투명 바탕).

그려 줄 것 (판 크기는 게임 칸 기준)
1) 방향 3개: 정면↓ 19x22 / 비스듬↘ 16x16 / 옆→ 14x15 (살색 + 둘레 2~3칸)
2) 표정 3개 (방향마다): 기본 / 힘줌(공격, 눈썹 내리고 입 다묾) / 아픔(맞기, 눈 질끈)
3) 깜빡임: 방향마다 눈만 감은 작은 판
4) 달리기용 숙인 판: 방향마다 고개를 약 10도 숙인 기본 얼굴
5) 앞머리 층: 방향마다 1장
한 장에 방향별로 줄을 맞춰 나란히 놓아 줘(줄 = 방향 3개, 칸 = 기본·힘줌·아픔·깜빡임·숙임·앞머리).
```

## 3. 받은 뒤 찍는 법 (모션 담당)
1. 칸 맞추기: 10칸 격자에 맞춰 1배로 되돌림(가장 가까운 색, 섞지 않음) → 6색으로 고정.
2. 옆 판부터 100% 크기로 사장님께 먼저 보이고 OK 받은 뒤 찍는다.
3. 층 순서: 머리 → 얼굴 판 → 앞머리 층. 앞머리가 위로 오니 「앞머리가 얼굴을 가리는 장」 문제가 없다.
4. 몸 그림 피부도 같은 6색으로 바꾼다 → 판만 밝거나 어두워 보이는 일이 없다.
5. 지금 피부인 곳 ±1px만 바꾼다. 새 피부를 늘리지 않는다.
6. 장마다 자리는 표(dx, dy, 판 번호)로 정한다(Stardew 방식). 얼굴은 머리 출렁임을 그대로 따라가고, v1의 0.4~2.3px 떨림은 표로 없앤다. 옆얼굴은 머리 테두리로 자리를 찾는다.
7. 고개 ±5°까지는 같은 판(16px 얼굴에서 끝 1.4px 차이), 5~12°는 숙인 판, 그보다 크면(맞기·쓰러짐) 찍지 않는다. 판을 따로 1px 들썩이지 않는다(떠 보임) — 머리 출렁만 따른다. 깜빡임은 3~5초마다 1~2틱.
7-1. 경계는 섞지 않는다. 판 둘레 1px만 「그 장 색과 판 색 중 더 어두운 쪽」으로 해 턱선을 살린다.
7-2. ↗ 는 얼굴이 4×4라 찍지 않고 몸 그림 그대로, ↑ 는 앞머리 층도 없음. 옆 자리는 「머리 꼭대기 + 뒤통수 끝」 두 점으로 찾는다. 옆 정본 1장만 손으로 2~3px 고치면 모든 장에 반영된다.
8. 크기는 찍은 뒤 바꾸지 않는다. 확인은 100% 크기 + 제자리 돌기·원 배치 영상.
