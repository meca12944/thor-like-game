## 알려진 문제
- **망토**: 04/05/07의 주인공은 원본 일러스트대로 망토를 두르고 있음. 타이틀 화면(`docs_art/title_screen/`)은 "망토 없음(긴 코트)" 기준으로 수정되어 서로 불일치. 망토 없는 버전이 필요하면 원본 정지화부터 다시 그려야 함.
- **07 루프 이음매**: 크로스페이드 1초 구간(약 8.0~9.0초)에서 휘날리는 망토·머리카락이 살짝 겹쳐 반투명하게 보이는 고스팅이 있음. 또 초반에 카메라가 아주 약간 줌됨.
- **05**: 원본 정지화 자체에 피 표현이 많음(영상에서 추가된 유혈/훼손은 없음). 입자로 흩어지는 연출은 약하고 끝부분에만 나옴. 루프판은 이음매에서 흩어지던 몸이 원래대로 돌아오므로, 이벤트에는 one-shot판 권장.
- **04**: 원본은 "멀리서 본 구도"로 설명되어 있으나 실제 그림은 광장 안 주인공 중심 구도이며, 그림 그대로 애니메이션함.
- 모든 루프는 1초 크로스페이드라 움직임이 큰 부분은 이음매에서 잠깐 겹쳐 보일 수 있음.
- 주인공 장검은 전 씬 오른손 유지, 의상 변경 없음, 새 캐릭터·글자 아티팩트 없음(프레임 추출로 확인).
