해상도: 전부 **1920x1080 (16:9)**. 영상은 H.264 / yuv420p / 24fps / 약 9.04초(217프레임) / 오디오 없음.

## 게임에서 쓰는 법
1. `title_c_loop_bg.mp4`를 화면 전체(1920x1080 기준, 비율 유지 스케일)에 **무한 반복 재생**.
2. 그 위에 그리기:
   - 간단하게: `title_c_overlay.png`를 (0,0)에 그대로 덮기. 메뉴까지 그려져 있음.
   - 메뉴를 살아있게(선택 하이라이트 등) 하려면: 오버레이는 로고용으로만 쓰고 메뉴는 게임 UI로 직접 그리기.
     메뉴 위치(1920x1080 기준): 하단 y≈962, 가로 한 줄, 중심 x≈1360, 폰트 나눔명조(선택 항목 Bold, 색 #F0E4C8 / 비선택 #C8BA9E, 선택 표시 붉은 마름모 #B04034).
     이 경우 `make_titles.py`에서 메뉴 부분을 빼고 다시 돌려 로고 전용 오버레이를 만들면 됨.
3. 영상 재생 불가 시 `title_c.png` 사용.

부제는 반드시 **사멸의 궤적** (궤 = U+ADA4). 스크립트에 assert 있음.
주인공은 망토 없음(긴 코트) 기준으로 수정된 배경.

## 갱신 (2026-10-24 20:00 KST)
- `title_bg_c_notext.png`는 이제 **`title_c_loop_bg.mp4`의 0번 프레임 그대로**(1920x1080 PNG). 이전 파일은 생성 원본 정지화라 영상 첫 프레임과 주인공 크기·위치가 달랐음.
- `title_c.png`도 이 0번 프레임 위에 `make_titles.py`로 다시 합성함. `title_c_overlay.png`는 변경 없음.
- 따라서 "정지 화면 → Start → 영상 재생" 전환 시 정지화와 영상 첫 프레임이 정확히 일치함.
