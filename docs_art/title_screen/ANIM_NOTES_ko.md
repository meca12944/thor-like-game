# 타이틀 v2 — 애니메이션 대비 메모 (1920x1080 기준)
로고/메뉴는 make_titles.py로 배경 위에 따로 합성 → 영상 루프 위에 프레임마다 그대로 다시 얹으면 됨.

A 절벽 뒷모습 · 폐허 왕도
- 구름: 상단 0~520px 전체, 좌→우 천천히 흐르기 (로고 뒤 영역)
- 연기/불씨: 우측 폐허 x 750~1920, y 375~1080 — 연기 기둥 상승, 아래쪽 붉은 불씨 깜빡임
- 망토 끝/머리카락: 주인공 x 110~770, y 170~880 미세하게 펄럭임
- 재: 화면 전체에 입자 오버레이 추가

B 검 내린 주인공 · 핵 문장 · 재
- 핵 문장(가슴): 약 x 1000~1120, y 340~460 — 붉은 보랏빛 맥동 글로우
- 재/불씨: 이미 그려진 입자 + 위로 떠오르는 입자 오버레이
- 머리카락·망토 자락: x 390~1050 펄럭임 / 우측 폐허 실루엣 안개 흐름

C 고성 외길
- 구름: 상단 0~450px 크게 흐르기, 성 뒤 연기 x 975~1425, y 300~545 상승
- 마른 풀·관목: 하단/양옆 흔들림
- 주인공 망토·머리카락: x 560~940, y 600~960 바람에 펄럭임
- 재: 길을 따라 낮게 흩날리는 입자
