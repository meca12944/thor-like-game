# 타이틀 C — 대기(idle) 루프 배경 `title_c_idle_bg.mp4`

**용도:** 타이틀 화면에서는 주인공이 가만히 서 있고 배경만 움직입니다. New Game / Continue를 누르면 기존 `title_c_loop_bg.mp4`(걷는 영상)로 컷 전환합니다.

## 사양
- 1920×1080, 24fps, **216프레임 = 9.00초**, 끊김 없는 루프(크로스페이드 없음), 텍스트 없음
- H.264 High, yuv420p, BT.709/limited 태그, faststart, keyint=216(I프레임은 0번 하나뿐), 약 7.1MB
- 카메라는 완전히 고정했습니다(push-in, pan, zoom 없음). 주인공은 모든 프레임에서 still 픽셀을 그대로 다시 붙여서 고정했고, 머리카락·망토 바람 효과는 넣지 않았습니다.

## 움직이는 요소 (모두 위상 t/T의 주기 함수라서 N번 프레임 == 0번 프레임)
| 요소 | 방식 |
|---|---|
| 구름 | 인페인트한 하늘 plate에 진행파 형태의 변위 warp를 적용합니다. 바람에 맞춰 왼쪽으로 흐르고, 위쪽 구름이 더 크게 움직입니다. 크로스페이드가 없어서 붓 터치가 흐려지지 않습니다. |
| 성 연기 | 그려진 연기 기둥 영역에서 위·왼쪽으로 올라가는 파동 warp를 적용합니다. 3초 주기입니다. |
| 마른 풀 | 땅에서 질감이 있는 부분(길과 주인공 주변은 제외)에 수평 sway warp를 적용합니다. 진폭은 0.6~3px입니다. |
| 재 | 330개입니다. 밝은 재와 어두운 재가 섞여 있고, 깊이에 따라 크기와 속도가 다릅니다. 왼쪽으로 날립니다. |
| 불씨 | 46개입니다. 아래쪽 좌우에서 떠오르고, 깜빡임과 글로우(screen 합성)가 있습니다. |
| 까마귀 | 3마리가 성 주위를 타원 궤도로 돕니다. 루프마다 날갯짓 횟수가 정수(27/24/21회)이고 활공 구간이 있습니다. 궤도의 먼 쪽은 첨탑 뒤로 지나갑니다. |

- 0번 프레임에서는 모든 warp 변위가 정확히 0입니다(A·(sin(θ+ωt) − sin θ) 형태).
- 0번 프레임에서 까마귀 3마리는 성 실루엣 뒤에 숨어 있습니다. 그래서 0번 프레임에서 still과 달라지는 것은 재와 불씨 입자뿐입니다.
- 인코딩은 원본의 YUV 평면 위에 렌더 결과의 RGB 차이만 BT.709로 변환해서 더합니다. 그래서 주인공 영역은 인코딩 전 YUV가 loop_bg 0번 프레임과 비트 단위로 같습니다.

## 측정값 (`metrics.json`)
- **디코드한 Y(luma) 기준, idle 0번 프레임 vs loop_bg 0번 프레임**
  - 전체: PSNR 43.9dB, MAD 0.27
  - 주인공 마스크: PSNR 56.1dB, MAD 0.16 (픽셀의 84.5%가 완전히 같음)
  - 주인공 bbox(552,462)-(1001,995): PSNR 47.5dB, MAD 0.22
- **같은 비교를 RGB(기본 디코더)로 했을 때**
  - 전체: PSNR 42.2dB
  - 주인공 마스크: 51.9dB
  - 주인공 bbox: 45.7dB
- **인코딩 전 기준**
  - 주인공 마스크 차이: 0
  - 전체 MAD: 0.068 (재·불씨 입자만 다름)
- 주인공 고정 확인: 전체 216프레임 중 주인공 마스크 MAD가 가장 큰 프레임도 0.16입니다(인코딩 노이즈 수준).
- **이음매**
  - 렌더 단계에서 216번(=0번) 프레임과 0번 프레임의 최대 차이: 0
  - 디코드 기준 215→0 차이: Y MAD 0.58
  - 일반 연속 프레임 차이: 평균 0.25, 최대 0.30
  - 215→0 차이가 더 큰 이유는 I프레임과 P프레임의 코덱 노이즈 차이입니다(99퍼센타일 4레벨 이하). 주인공 영역에서는 0.01입니다.

## 약점 / 메모
- 구름은 순수 warp이기 때문에 계속 한쪽으로 흘러가지 않고, 진행파처럼 넘실대다가 9초마다 제자리로 돌아옵니다. 대신 0번 프레임이 정확하고 붓 터치가 선명하게 유지됩니다.
- 연기도 기존 연기를 일렁이게 하는 방식입니다. 새 연기가 계속 뿜어져 나오지는 않습니다.
- 까마귀와 재는 화면 크기 대비 작고 은은합니다. 모바일에서는 잘 안 보일 수 있습니다(`make_idle.py`의 `span`, `ASH` 개수와 `a` 값으로 조정할 수 있습니다).
- 주인공 마스크(grabcut + 보정) 경계 바로 바깥의 작은 길 그림자 조각 몇 개도 고정됩니다. 입자는 항상 주인공 뒤로 지나갑니다.
- **컷 전환:** 0번 프레임은 loop_bg 0번 프레임과 거의 같습니다. 다만 버튼을 누르는 시점은 루프 중간이므로 그 순간에는 구름이 최대 약 22px 어긋나 있습니다. 주인공은 항상 같으므로, 배경만 0.2~0.3초 크로스페이드하거나 다음 0번 프레임까지 기다렸다가(최대 9초) 컷하면 완전히 이어집니다.
