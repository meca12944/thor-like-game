# 펠트 마을 개선 통합안 (일러스트 작가 + 스토리 작가, 2026-10-24) — 스토리 초안, 사장님 승인 대기
근거: REPORT_ko.md(화면·코드 분석, 참고 게임 조사), STORY_ANSWERS_ko.md(스토리 답변 전문)

## 1단계 빠른 수정 (코드, 팀장)
- 분수 물 흐르게(건조 처리 제거 + 물결 루프 + 물소리)
- Felt 카메라 줌 1.3
- 석양 색 약화, 길 15~20% 밝게, 가장자리 어둡기 완화
- 횃불·화덕·촛불 5~8곳 실시간 깜빡임
- 벤을 노점 앞으로, 남문 "해 지면 문 닫음" 표지, 상점 그림 간판

## 2단계 배치·랜드마크 (그림: 일러스트 / 배치: 팀장)
- 아라크네 폐공방 입구를 성벽 밖으로: 동쪽 쪽문 → 짧은 폐허 길 → 입구. 쪽문에 가스의 밧줄·출입금지 판자
- 리네트 공방 = 왕실 의상 공방 폐허 지상 귀퉁이, 반쯤 녹은 금박 아치 + 흰 실
- 빈 구역 채우기: 광장 배급 천막, 성벽 밑 천막촌, 북쪽 잿더미 지구, 추모 벽(예배당 옆), 실종자 리본 나무
- 건물 터·그림자 추가, 빨래·리본·실 흔들림 애니(픽셀랩)

## 3단계 사람·시간·놀거리 (코드 + 스토리)
- 시간대는 이야기 따라: 도착 늦은 오후 → 리네트 합류 후 해 질 녘 → 보스 후 밤(추모 촛불·기도회) → 떠나는 날 맑은 아침. 밤엔 남문만 닫힘
- NPC 시간대별 위치(스토리 작가 동선표), 어른 난민 엑스트라 15명(보스 전후 대사), 아이 엑스트라 없음
- 추모 벽: 왕도 화재 희생자 천 7 + '찾습니다' 이름표 3(이름·좋아하는 것만), 보스 후 펠릭스 이름표에 목도리 조각
- 잿빛 단추 6개 → 리네트 '근위대 단추' 대사 + 장신구 「근위의 단추」
- 실 덩어리 5개 걷어내기, 배급 돕기, 가스 주사위(동전, 3판), 바르트 숫자(보스 후 '사라진 사람 없음' 빈칸)
- 보스 후 루카 노래 = 마을 BGM 밝은 버전
- 예배당 밑 길은 별개 떡밥, 1장에선 「아직 열 때가 아니오」
