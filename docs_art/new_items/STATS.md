# 신규 680종 스탯 설계 (items_stats.csv)

생성 스크립트: `/tmp/gen/stats.py` (결정적 · md5 해시로 지역 등급 배정). 게임 코드·town/assets는 수정하지 않음 — 이 문서는 기존 데이터의 범위를 그대로 이어 쓰는 설계안.

## 1. 기존 시스템 (조사 결과, 읽기 전용)
- `town/assets/icons/items_demo.json → items`: `s`(weapon/armor/helmet/offhand/consumable/material), `t`(1~10 = 지역 등급), `atk`, `df`, `fx`(효과 텍스트), `p`(가격), `sell`(= p/2), `r`(희귀도).
- 무기 atk: t1 4~8 · t2 8~13 · t3 14~15 · t5 17~19 · t7 21~24 · t8 25~27 · t9 28~31 · t10 36. 숨겨진 검 탁/규 38 · 찬 52 (LEGEND 기준).
- 몸 방어 df 1(t1)→13(t10), 투구 1~5, 방패 1~5 + 정면 막기 25/30/40%, 탑방패 이동 -5%.
- 장신구: df 0, 효과만 (공속 +5%, 이동 +10% 등). 투척/오브 atk 2~14.
- 소모품: 물약 회복 30/50/100%, 쿨 4초, 소지 5개. 버프 60초 ±15/30%. 가격 8~800.
- 강화(`enh`) +0~+9는 **무기만** atk +4%~+65%. 방어구·보조는 강화 없음.
- 레벨: 상한 60, 지역별 권장 Lv (LEVELS.md): 1~5 / 6~10 / 11~15 / 16~20 / 21~26 / 27~32 / 33~38 / 39~44 / 45~49 / 50~58.
- 레벨 제한 필드는 아직 없음 → `lv` = 해당 지역 등급 시작 레벨로 신설 제안.

## 3. 공식
- 별 보정 `mark = 1 + 0.04 × (0,1,2,3,4)` (★1→legend).
- **무기/검** `atk = ATK[t] × 타입배율 × mark`, ATK = [5,10,14,16,18,20,23,26,29.5,36] (기존 검 평균). 상한 ★1 16 / ★2 24 / ★3 30 / ★4 38 / legend 50 (lg_ 최대 52 = 찬블레이드).
  - 타입: 단검 0.75·공속1.3·사거리0.8·치명+10 / 대검·클레이모어 1.25~1.3·0.75~0.8 / 레이피어·에스톡 0.9~0.95·찌르기 / 쌍검·쌍낫 0.65~0.7·2타·보조칸 잠김 / 창·장창 1.0·사거리1.3~1.4 / 미늘창·글레이브 1.15·1.35 / 대도끼 1.3·0.75 / 대형망치 1.35·0.7 / 활 0.8·3.0 / 장궁 0.9·3.5 / 석궁 1.1·0.7·3.2 / 지팡이 0.85·2.5 / 건틀릿 0.7·1.4 등.
  - `atk_spd`, `range` = 기본 장검 대비 배율. `crit` = 5 + 타입 + 2×별.
  - 속성(element): 테마별 (잉걸불 화상 / 혹한 둔화 / 폭풍 감전 / 맹독 독 / 암영 저주 / 핏빛 흡혈 / 성운 무작위 / 고룡 화염+용족 / 성천 신성 …), 발동 확률 ★2 5% · ★3 10% · ★4 15% · legend 20%.
- **방어구** `df = 기준표[t] × 부위배율 × 타입배율 × mark`
  - 갑옷 = 기존 몸 방어표 [1,2.5,4,4.5,5,6.5,7,8.5,9,13] · 하의 = 몸 × 0.6
  - 투구 = 기존 투구표 [1..6] · 장갑/신발 = 투구 × 0.7
  - 타입: 판금 1.15 / 사슬 1.0 / 로브 0.6 (+MP) / 가죽 0.8 (+이동) 등. 가벼울수록 부가 스탯.
  - `hp` = 부위계수(갑옷4·하의3·투구2·장갑/신발1) × t. 부가 효과 1개 + ★2부터 테마 저항.
- **장신구** (반지·목걸이·귀걸이): df 없음. 치명 2/3/4/6/8% · 공격 1/2/3/4/6 · HP 5~25 · MP 5~22 · 스킬 게이지 3~15% · 회피 판정 2~7% (별 순). ★3부터 테마 속성.
- **방패** `df = 방패표[t] × 타입 × mark`, `block` = 기본(원형 25 · 연 30 · 탑 40 · 버클러 20) + 3×별. 탑방패 이동 -5%, 버클러는 반격.
- **보조무기** `atk = 투척표[t] × mark` ([3,4,6,7,8,9,10,11,12,14] 기존 투척/오브). 오브 자동 사격 2.0→1.2초, 마도서 마법진, 투척 칼 3~8발, 랜턴·토템은 오라/설치형 (atk 없음), 폭탄 범위 24~44px.
- **소모품**: 크기 s/m/l/x/g → HP 30/50/75/100/100%+재생, MP 20/40/60/100, 쿨 4초 (기존 물약 시스템과 같음). 테마 소모품은 효과량 10~60초 / 폭탄 공격 150~400%. 가격은 기존 8~800 범위.
- **퀘스트**: 스탯 없음, `desc`에 용도. 비매, 판매 0.
- **가격** `price = PRICE[t] × 부위계수 × mark` (PRICE = [200,650,1100,1350,1800,1900,2750,3750,5200,7000], 무기 1.0 · 갑옷 0.8 · 방패/보조 0.75 · 장신구 0.7 · 투구/하의 0.6 · 장갑/신발 0.5), `sell = price/2`. legend: 비매, sell = t × 120 (기존 드롭 sell = t×60의 2배). lg_: sell 3000.

## 4. LEGEND 특수 효과
- 111종 일반 legend: 테마 고유 효과(성천/성운/고룡 + 폭풍·잉걸불·암영) + 타입/부위 고유 효과의 조합 → 128개 effect 문자열 전부 다름 (검증 완료).
- 방어구 legend는 테마 세트 효과(2/4부위) 포함.
- lg_ 30종: 개별 수작업 효과 (예: 엑스칼 HP 100% 시 검기 빔, 무라마사 처치 누적 공격 +2%, 아이기스 석화 반격).
