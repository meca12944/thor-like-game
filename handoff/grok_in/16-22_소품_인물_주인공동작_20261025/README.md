## 약점 (솔직하게)
- **16 정문**: 96×80에 문과 베르디를 같이 넣어서 베르디가 작음(앉은 키 약 30px). 안경·잉크 얼룩은 4배 원본에서나 보임.
- **17 지름길**: 밧줄 다리는 한 칸짜리 그림이라 이어 붙여지지 않음. 길게 쓰려면 여러 장을 겹쳐 놓아야 함. 승강기·뒷문은 바깥 잿빛 바닥 기준으로 칠해서 공방 안에 놓으면 살짝 밝음.
- **18 공방 타일**: 1층 벽면(80px 반복)은 붉은 실 무늬가 넓은 벽에서 반복되는 게 보이고, 실이 핏자국처럼 읽힐 수 있음. 지하 2층 벽은 무늬가 커서 3타일 높이에서 잘린 느낌.
- **19 이야기 소품**: 인형이 제단에 비해 큼. 옷장 둘레에 나뭇조각이 흩어져 있어 충돌 판정을 그림보다 좁게 잡아야 함.
- **20 펠트 주민**: 채도를 낮춰서 붉은 실 포인트가 약함. 루카는 정면에 눈가리개가 없고 옆에만 있음, 류트 줄이 일부 멀쩡해 보임. 가스 의수는 생성이 계속 왼팔에 그려서 좌우 반전으로 맞췄고, 그래서 옆모습이 왼쪽을 봄. 마르타는 짜증보다 슬퍼 보임. 바트 백내장은 34px에서 거의 안 보임. 펠트(천 인형) 질감보다는 사람에 가까운 그림.
- **21 토비 낙서**: 32px판은 선을 굵혀 줄였더니 거의 실루엣. 21c의 별은 흐림. 4배판이 원래 느낌에 가까움.
