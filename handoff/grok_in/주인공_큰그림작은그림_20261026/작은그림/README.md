# F_v3. 주인공 - 팔 벌린 자세, 더 해진 망토

주인 말: "비교 npc 빼고 망토는 좀더 헤진 모습으로".
1. 콘택트 시트에서 루카·마르타를 뺐습니다. 이제 주인공 3방향(정면 / 옆(오른쪽) / 뒤)만 있습니다.
2. 망토를 더 해지게 했습니다.
   - 밑단을 들쭉날쭉 찢었고, 길게 늘어진 넝마 자락을 달았습니다.
   - 양옆 가장자리를 올이 풀리게 했습니다.
   - 작은 구멍 몇 개와 닳아서 바랜 자국을 넣었습니다.
   - 꿰맨 갈색 천 조각을 붙였습니다.
   - 색은 안팎 모두 같은 짙은 남색이고, 안감 색(빨강)은 없습니다.

나머지는 v2와 같습니다.
- 망토 아래의 꼭 맞는 남색 튜닉과 날씬한 바지, T자 자세, 빈손, 칼·효과 없음, 무표정.
- 주민 몸 비율, 키 918px, 옆모습은 오른쪽을 봅니다.

v2의 원본 그림(`F_hero_mini_armsopen_v2/_work/raw/hero7_*_tight_a.jpg`)을 참고 이미지로 넣고 GenerateImage로 망토만 고쳐 그렸습니다. 옆과 뒤는 새 정면 그림도 같이 넣어 망토 모양을 맞췄습니다. v1과 v2 폴더는 건드리지 않았습니다.

## 약점 (솔직하게)
- **해진 정도**: 정면과 뒤의 밑단은 비슷하게 해졌지만, 찢어진 자락의 모양과 위치는 3방향이 서로 정확히 맞지 않습니다. 구멍과 덧댄 천 조각의 수와 위치도 방향마다 다릅니다(정면 2, 옆 2, 뒤 2, 위치 다름).
- **망토 길이**: 정면은 무릎 아래와 장화 윗부분까지, 옆은 장화 위까지, 뒤는 장화 목까지 덮어서 조금씩 다릅니다.
- **옆모습 팔**: 뒤팔(왼쪽)이 머리카락과 망토 뒤에 반쯤 가려져 v2보다 덜 보입니다. 앞뒤로 뻗은 팔처럼 보이는 점은 v2와 같습니다.
- **옆 앞머리**: 옆얼굴의 앞머리가 v2보다 짧고 단정해서 정면의 곱슬기와 조금 다릅니다.
- **정면 얼굴**: 이번에 다시 그리면서 정면 얼굴이 약간 바뀌었습니다(머리가 조금 작아짐, 0.138에서 0.134로).
- **뒤 머리색**: 뒤 머리카락이 아주 살짝 초록빛 도는 검정입니다(평균 RGB 21,25,18). v2도 같았고 어두운 바탕에서만 겨우 보입니다.
- **뒤 손**: 손바닥 쪽처럼 보이는 손 모양은 v2와 같습니다.
- **크기 조정**: 원본에서 약 4% 줄여서 썼습니다.
