## 2. 사장님 규칙 · 소통 방식 (가장 중요)
### 소통
- 호칭은 **사장님**이다. 사장님은 한국어(**경상도 사투리**, 예: "좋심다")로 말한다. **답은 항상 한국어로**, 짧고 보기 쉽게 쓴다.
- 사장님은 **휴대폰으로** test128을 테스트한다. 터치 버튼은 **공격 / 대시 / 달리기**와 조이스틱이다. 모바일 화면에서 어떻게 보이는지를 늘 함께 고려한다.
- 시각을 말할 때는 KST로 적는다.

### 작업 규칙 (전달받음, 반드시 지킬 것)
1. **사장님이 명시적으로 지시한 것만 한다.** 추측으로 일을 늘리지 않는다. (최근 지시: "오늘은 1번, 2번만")
2. **팀원 봇에게 일을 배정하지 않는다.** 사장님이 시킬 때만 배정한다. (데일리 팀 배정 루틴도 현재 **일시정지**)
3. **완성된 결과물만** 확인받으러 가져간다. 중간 과정을 보고하느라 사장님 시간을 쓰지 않는다.
4. **승인 전에는 통합·배포(커밋) 금지.** 미리보기는 별도 폴더에 둔다.
5. **스프라이트·모션 수정은 PixelLab EDIT으로 기존 프레임을 고친다.** 손으로 픽셀을 편집하지 않는다. 사장님이 "생성해라"고 하기 전에는 **재생성하지 않는다.**
6. 결과는 **항상 GIF 미리보기**를 같이 보낸다 (4방향을 한 GIF나 시트로 묶는다).
7. **PixelLab 사용량을 추적한다.** 계정을 여러 봇이 같이 쓰므로 전체 잔액 차이가 아니라 **내 작업의 job 기록(billing_usage)을 합산**한다. 작업마다 **예산 상한**(예: 300~400)을 정하고 결과와 함께 사용량을 보고한다.
8. 다른 봇에게 메시지를 보내지 않는다(지시가 있을 때만).

## 8. PixelLab 사용법 요약 (`/workspace/pixellab_guide_ko.md`, `char_v4/pixellab/hero/NOTES.md`)
- API: `https://api.pixellab.ai/v2`, 헤더 `Authorization: Bearer $PIXELLAB_API_KEY`. 키는 `~/.config/pixellab/env`에 있고 `source`해서 환경변수로만 쓴다(**값 출력 금지**).
- 모든 생성은 비동기다: `background_job_id` → `GET /v2/background-jobs/{id}`로 확인하고, 결과는 `last_response.images[*].base64`에 있다. 잔액 `GET /v2/balance`는 무료.
- 결과 다운로드(backblaze)는 User-Agent가 없으면 403이 난다 → `curl -A Mozilla/5.0`.
- 동시 작업은 최대 8개다. 넘으면 429가 나지만 **과금되지 않는다**. "heavy load" 실패는 잠시 뒤 다시 시도한다.

| 기능 | 엔드포인트 | 256 캔버스 비용 |
|---|---|---|
| 캐릭터 회전 | `create-character-v3` (참조 모드, `n_directions:4`, `direction_images`로 좋은 방향 고정) | 8 / 모든 방향을 넣으면 가져오기만 해서 0.25 |
| 텍스트 애니 | `characters/animations` mode `v3` (한 방향씩, `custom_start_frame`, `end_frame`) | 프레임당 약 1 (8프레임 8). **256은 최대 8프레임** (10 보내면 422, 과금 없음) |
| 애니 편집 | `edit-animation-v2` (Pro, 같은 지시를 모든 프레임에 적용, 256은 **최대 4프레임**) | **25** |
| 이미지 편집 | `edit-images-v2` (Pro) / `edit-image-pixen` | 10 / 1 |
| 인페인팅 | `inpaint-v3` | 10 |
| 스켈레톤 | `animate-with-skeleton-v3` (디자인 유지) | 2~4 |
| 리사이즈 | `resize` (200x200 이하) | 1 |

**프롬프트 패턴**
1. 디자인 설명을 매번 통째로 붙인다: "Same character in every frame: long straight black hair, dark coat with gold trim, cape with red lining, gold pauldron, same face, same proportions and same size as the idle image; longsword in the right hand. Feet stay on the same ground line."
2. 동작은 단계 순서대로 쓴다: 예비 → 타격(+잔상) → 팔로스루 → 대기 복귀.
3. 방향은 대문자로 강하게 쓴다: "STRICT SIDE VIEW every frame … chest never turns toward the camera", "BACK VIEW every frame, face never shown … sword and arms stay visible", "He NEVER turns around".
4. 이펙트: "a wide cyan-white crescent slash trail following the blade tip" + "The character's own body and colors never turn white or glow; only effects are bright."

**함정**
- 옆모습에서 몸이 카메라 쪽으로 돈다 → STRICT SIDE 문구를 넣고, 그 프레임만 edit.
- 뒷모습에서 얼굴이 나오거나 칼이 가려진다.
- 디자인이 흘러간다(머리가 파래지는 등).
- 크기가 커진다(캔버스가 자동으로 커짐) → **로컬에서 발 (128,189)·키 124px를 다시 맞추는 후처리가 필수**.
- west에서 견갑이 반대쪽 어깨에 붙는다 → 반전하거나 pixen으로 고친 뒤 가져오기(0.25).
- 히로인이 주인공을 베낀다 → 본인 외형 설명을 끝까지 쓴다.
- 재시도하면 이전 결과를 덮어쓴다 → 출력 경로에 `_cand/<tag>/<motion>/<dir>_s<seed>/`처럼 태그·방향·시드를 넣는다. 같은 animation group은 409가 난다.

**사용량 기록**: run.log에 요청, 시드, `billing_usage`, "spent total from job records", 상한(cap)을 남긴다. 참고용 최근 잔액 기록: 6,868.75 / 10,000 (`heroines_v4px_20261018/balance_after2.json`, 10-19 00:46). 이후 big4hit 248, botw 256+104, trail_front 약 175(25x7), from8x8 360을 썼다. **잔액은 계정 공용이라 다른 봇 사용분도 섞여 있다.**

**참고 규칙 문서**
- `/workspace/yt_study/MOTION_RULES_ko.md`: 걷기 8장 x 5틱. 3연타 예비/스미어/히트스톱/팔로 = 1타 4/2/4/10, 2타 6/2/6/12, 3타 10/3/8~10/18. 잔상은 별도 레이어. 뒷모습은 어깨 회전을 크게.

## 10. 보안 주의
- **PixelLab API 키**: `~/.config/pixellab/env`에만 있다. `source ~/.config/pixellab/env` 후 `$PIXELLAB_API_KEY`로만 쓴다. **`cat`/`echo`로 출력하거나, 로그·문서·커밋·채팅에 넣지 않는다.** run.log에 헤더나 키를 남기지 않는다.
- **GitHub 인증**: `gh`가 `/home/box/.config/gh/hosts.yml`의 토큰으로 로그인되어 있다. 토큰 파일을 읽거나 출력하지 않는다. `gh` 명령으로만 쓴다.
- SSH 키, 비밀번호, 기타 토큰도 같다. 위치만 알고 **값은 절대 다루지 않는다**.
- 커밋 전에 `git diff --cached`로 키처럼 보이는 문자열이 섞였는지 확인한다. `.env`나 설정 파일은 커밋하지 않는다.
- force-push 금지. `/town/`(라이브)과 `/workspace/thor-like-game` 수정 금지.
