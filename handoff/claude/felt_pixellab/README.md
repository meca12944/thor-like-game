# 펠트 바깥 풍경 (PixelLab 부품으로 조립, 2026-10-20)

사장님 지시: 실내는 빼고 마을 바깥 전체를 PixelLab으로 만든다.

## 결과
- 게임: `test128/maps/felt.json` + `test128/assets/world/felt_bg.png` (56×38칸, 1칸 16px, 896×608). `?start=felt`로 바로 들어간다.
- 조립: `test128/tools/felt/build_felt.py` (부품은 `test128/tools/felt/parts/`). 배치, 길, 소품, NPC를 이 파일에서 고치고 다시 돌린다.
- 충돌: 건물·소품 그림의 불투명한 칸이 그대로 막힌 칸이 된다. 모든 NPC, 문, 출구가 남쪽 출발점에서 걸어서 닿는지 확인했다.

## 사용량: 총 67회 (작업 64개, 실패 0)
| 종류 | 엔드포인트 | 단가 | 개수 | 합 |
|---|---|---|---|---|
| 건물·폐허·소품 (2장씩) | `/map-objects` | 1 | 61 | 61 |
| 바닥 타일셋 (흙길↔돌바닥, 잿빛 풀↔흙길) | `/create-tileset` | 3 | 2 | 6 |
작업별 기록: `usage.jsonl` (`billing_usage` 그대로). 같은 계정을 다른 방도 쓰고 있어서, 잔액의 차이는 이 작업의 사용량과 맞지 않는다.

## 파일
- `specs.py`: 부품 목록과 프롬프트. `gen_all.py`: 생성(이미 있는 파일은 건너뜀, `FELT_CAP` 기본 200에서 멈춤). `pl.py`: API 클라이언트(키는 환경변수 `PIXELLAB_API_KEY`에서만 읽음).
- `assets_sheet.png`: 모든 부품의 두 시드를 나란히 놓은 시트. `out/assets/`: 원본.
- `felt_collision_overlay.png`: 빨강 = 막힘, 노랑 = 문, 파랑 = NPC, 초록 = 출구.
- `ingame_south.png`, `ingame_east.png`: 게임 화면.

## 고른 부품
여관 1번 시드는 간판에 글자가 들어가서 2번을 썼다. 리네트 공방은 처음 두 장이 아치만 나와서 `bld_atelier2`로 다시 뽑았다(2회). 통은 사람보다 커서 절반으로 줄였다. 잿빛 풀 타일은 주황빛이 강해서 채도와 밝기를 낮췄다.

## 남은 것
- NPC 그림은 예전 A·C·F 마을 사람으로 임시. 실내 10곳은 아직 없다(문은 안내 문구만).
- 타일셋 경계가 단순한 직사각형 길이라 다소 반듯하다. 길 모양은 `ROADS`에서 바꾼다.

# 펠트 광장 한 화면 (밀도 높인 시험판, 2026-10-20)

전체 마을은 단조롭다는 평이라, 광장 한 부분만 밀도 있게 다시 만들었다. 전체 마을 컨셉은 그록에게 맡긴다.

- 게임: `test128/maps/felt_plaza.json` + `test128/assets/world/felt_plaza_bg.png` (30×22칸, 480×352). `?start=felt_plaza`로 들어가고, 남쪽 출구는 `felt` 맵으로 이어진다.
- 조립: `test128/tools/felt/build_plaza.py` (부품 `test128/tools/felt/parts_plaza/`). 전체 마을 때와 달리 부품 그림자, 노을빛 색보정, 등불 빛 번짐, 가장자리 어둡게 처리를 넣었다. 바닥은 경계가 불규칙한 Pro 타일셋.
- 부품: 분수(계단 단 위 왕 석상), 쓰러진 기사 석상, 노점 2, 난민 천막과 모닥불, 집 3채 정면, 우물, 게시판, 줄등 2줄, 가로등, 까마귀, 거미줄, 잔해, 수레, 고목, 바닥 장식. `plaza_sheet.png`가 모든 후보.
- 고른 것: 재봉집 2번 시드는 간판에 "TAILOR" 글자가 있어 1번을 썼다. 낙엽 바닥 장식은 빈 그림이라 뺐다. 상자 더미는 생성 실패(과금 0)라 빠졌다.
- 확인: 문 3곳(여관 회복, 이장 집, 리네트 공방), NPC 4명(루카, 토비, 벤, 리네트), 게시판, 남쪽 출구 → `felt`. 모두 닿는다.

## 사용량: 49회
| 종류 | 단가 | 개수 | 합 |
|---|---|---|---|
| 부품 `/map-objects` (high detail) | 1 | 34 | 34 |
| Pro 바닥 타일셋 `/create-tileset` mode=pro | 15 | 1 | 15 |
| 실패 1건 (상자 더미) | 0 | 1 | 0 |
펠트 작업 누계: 116회 (전체 마을 67 + 광장 49).
