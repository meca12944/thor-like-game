## 1-4. 움직임 기준 (2026-10-23 연구, 사장님 "4가지 몬스터 움직임 연구, 탑다운 게임과 차이") — 펠트 4종 적용(10-23)
잰 값(펠트 4종, 같은 몹 3마리 vs 가만히 선 주인공 20초):
| 항목 | 실마물 | 실 꼭두각시 | 바늘 거미 | 들개 | 탑다운 게임(하데스·하이퍼 라이트 드리프터·엔터 더 건전) |
|---|---|---|---|---|---|
| 걷는 속도(px/초) | 31 | 28 | 42 | 48 | 몹 걸음은 주인공보다 확실히 느리고, 공격할 때만 빠름 |
| 주인공 달리기(156) 대비 | 20% | 18% | 27% | 31% | 약 30~60% |

| 같은 몹끼리 겹침 | 0% | 0% | **24%** | **22%** | 거의 0% — 서로 밀어내 주인공을 둘러쌈 |
| 맞았을 때 | 26px 밀림, 하던 공격 계속(움찔 없음) | | | | 약한 몹은 움찔(공격 준비 전), 공격 준비 중엔 안 밀림 |
| 걷는 그림 속도 | 속도와 상관없이 5틱/장 → 천천히 물러날 때(0.5배) 다리만 빨리 움직임 | | | | 다리 속도 = 이동 속도 |

결론(우리 게임 = 빠르게 달리며 검기, 피하기로 게이지):
1. **걸음은 느리게 유지, 공격만 빠르게**(돌진·뛰어들기). 주인공이 싸움을 주도하는 맛 = "빠르게 달린다". 대신 실마물·꼭두각시도 짧은 빠른 움직임 하나씩.
2. **항상 주인공을 본다**: 물러나기·빙빙 돌기 때도 얼굴은 주인공 쪽(뒷걸음·옆걸음). 보는 쪽 = 공격 올 쪽이라 저스트 회피 박자를 읽기 쉽다.
3. **서로 밀어내기**: 겹치면 검기 한 번에 다 맞고 경고가 겹쳐 안 보인다 → 몹끼리 간격을 두고 주인공을 둘러싼다.
4. **맞았을 때**: 걷기·빈틈 중엔 움찔+밀림(베는 손맛), **공격 경고 중엔 안 밀림**(경고 자리와 몸이 어긋나지 않게, 피하기 기회 = 게이지 유지).
5. **다리 속도 = 이동 속도**(주인공 `RUN.cadence`처럼). 느리게 물러날 땐 천천히 걷기.

## 1-5. 생동감 · 공격 다양성 연구 (2026-10-23, 사장님 "생동감 있게, 공격 패턴이 단조롭지 않게 재밌게") — 10개 모두 게임 반영(10-23)
### 잰 것 (펠트 4종, 가만히 선 주인공 vs 1마리 60초, 공격 순서)
| 몹 | 공격 수 | 같은 공격 연속 최대 | 바로 앞과 같은 공격 |
|---|---|---|---|
| 실마물 | 34 | 2번 | 3% |
| 실 꼭두각시 | 31 | **6번** (가위 베기) | 43% |
| 바늘 거미 | 34 | **5번** (뛰어들기) | 24% |
| 들개 | 34 | **11번** (돌진) | 51% |
- 고르는 방법이 "주사위"뿐이다(거리·상황·체력과 상관없음) → 같은 공격이 길게 반복되고, 주인공이 뭘 해도 몹 반응이 같다.
- 생동감 점검: 경고 때 몸 신호 = 공격 그림만 느려짐(번쩍·웅크림 없음) / 처음 주인공을 볼 때 반응 없음 / 대기 = 2% 숨쉬기뿐 / 걸을 때 발 먼지 없음 / 죽음 = 모든 몹 같은 연기 / 소리 = 종류별 공용.

### 탑다운 게임에서 배울 것
- 하데스: 몹마다 "말버릇"처럼 정해진 공격 리듬 + 체력이 줄면 행동이 바뀜, 몹 조합(방패 + 저격)으로 싸움마다 다른 느낌.
- 하이퍼 라이트 드리프터: 개는 빗나가면 짧게 한 번 더 달려듦(연속기), 처음 발견하면 짖고 뛰어오름.
- 엔터 더 건전: 공격 직전 몸이 번쩍·떨림으로 먼저 말함, 죽을 때 몹마다 다르게 터짐.
- 공통: 무작위보다 **"읽을 수 있는 변화"**가 재미 — 규칙을 배우면 피할 수 있어야 저스트 회피(게이지) 재미가 산다. 속이기(가짜 공격)는 경고 모양이 달라야 공정.

### 결론 = 제안 (전부 코드, 크레딧 0)
- 구현: 같은 공격 3연속 금지 + 거리 가중(`pickIntent`), 저스트 회피 당하면 0.6초 "?" 멍(`dazeT`), 들개 2차 돌진, 거미 맞으면 뒤로 폴짝 → 침, 실마물 실이 맞으면 16px 끌어당김 → 할퀴기, 체력 30% "!!" 성남(빠름·쿨 0.8배·꼭두각시 3연속), 경고 때 웅크림·떨림·빨간 바닥 빛, 첫 발견 "!" 뛰어오름, 몹마다 대기 버릇, 걸음 먼지, 맞을 때 찌그러짐, 펠트 솜·실 조각 죽음(`fluff`).
- 잰 값(60초): 같은 공격 연속 최대 11번 → 2번(실마물은 끌어당김 뒤 할퀴기 때문에 3번).
**공격 다양성**
1. 같은 공격은 **2번까지만 연속**, 몹마다 정해진 리듬(예: 들개 = 돌진·돌진·빙빙 돌다 파편).
2. **상황 따라 고르기**: 멀면 쏘기, 가까우면 근접, 주인공이 저스트 회피하면 잠깐 당황(빈틈 +0.3초).
3. **이어지는 공격**: 들개 돌진이 빗나가면 0.3초 뒤 짧은 2차 돌진(경고 다시), 바늘 거미는 맞으면 뒤로 폴짝 물러나며 침, 실마물은 묶은 뒤 끌어당겨 할퀴기.
4. **체력 30% 이하 성난 상태**: 조금 빨라지고 몸이 붉게 번쩍, 공격 하나 추가(꼭두각시 3연속 베기 등).
5. **몹 조합 배치**: 묶기(실마물) + 돌진(들개), 거미줄 장판(거미) + 연속 베기(꼭두각시) → 몹 하나하나보다 싸움마다 다른 그림. 들개 무리는 번갈아 달려듦.
**생동감**
6. **경고 때 몸이 먼저 말함**: 웅크림(납작) → 펴짐, 빨간 번쩍, 떨림.
7. **발견 반응**: 처음 주인공을 보면 "!" + 작은 뛰어오름 + 몹 소리.
8. **몹마다 대기 버릇**: 들개 킁킁·몸 털기, 거미 다리 떨기, 꼭두각시 실에 매달린 듯 흔들림, 실마물 꿈틀.
9. **걸을 때 발 먼지·맞을 때 몸 찌그러짐·실밥 튐**.
10. **펠트다운 죽음**: 솜·실 조각이 터져 흩어지고 몸이 납작해짐(몹마다 색).

## 1-6. 공격 순간 연출 · 몹 섞기 (2026-10-23, 사장님 "몹이 어떻게 하면 생동감 있게 공격하고 재미있을지") — 게임 반영(10-23)

# 2부. 몹 그림 규칙 (모션 교과서에 더해서)
- **정면·뒷면이 옆모습으로 나옴**(사냥개·망령): 프롬프트를 더 세게("STRICT front view") 하거나 **정면 그림에서 시작**. 망령은 style 이미지만으로 생성.
- **사이 장에서 몸 부품이 사라짐**(거미 뒷모습의 실통): 그 장만 다시.
- **방향마다 키가 다름** → 옆+정면 평균 키로 동작마다 한 번에 맞춤.
- **왼쪽 보는 그림**은 좌우 반전해서 오른쪽 기준으로(3번방 스트립 `MIRROR`).
- **공격 그림이 다른 몹처럼 보임**(실마물: 기어 다니다 공격 때 사람처럼 일어섬) → 게임 속 크기 영상으로 먼저 확인, 크게 보이면 공격만 다시(10~20).
- **동작 중 이상한 장**(바늘 거미 쏘기: 뒤집힌 것처럼 몸을 세움) → 다시 그리기 전에 `anim.map`으로 그 장을 건너뛴다(0).
- **총알·빛·검흔·장판은 그림에 굽지 않고 코드**(`world.js` 총알 종류, `projfx.py`).
- **폰 끊김**: 큰 스트립을 매 프레임 고품질로 줄이지 말고, 크기별로 한 번 줄여 저장해 찍기(`scaledStrip`), 화면 배율 최대 2.
- PixelLab `animate-with-text-v3`는 장 수 4 이상.
