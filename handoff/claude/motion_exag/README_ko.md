# 주인공 모션 과장판 (게임 미적용)
걷기·대기·피격·1~3타를 지금 게임 그림을 바탕으로 뼈대 방식으로 과장한 시안. 게임에는 넣지 않음.

- 영상 (위 줄 = 지금 게임, 아래 줄 = 과장판, 칸 = 오른쪽/왼쪽/아래/위)
  - `walk.mp4` `idle.mp4` `hurt.mp4` `hurt_slow.mp4`(0.5배속) `combo.mp4`(1→2→3타) `combo_slow.mp4`(0.5배속)
- 방법
  1. 게임 프레임마다 estimate-skeleton
  2. 관절을 기준 자세에서 더 멀리 밀어 과장. 걷기·대기는 평균 자세, 피격·공격은 첫 장 기준. 배율은 걷기 1.35, 대기 1.8, 피격 1.45, 공격 1.3. 뼈 길이는 원래대로 유지해서 다리가 짧아지지 않게 함
  3. 오른쪽: 첫 장에서 출발하는 animate-with-skeleton-v3 한 번(키 + 사이 그림, 최대 15장). 왼쪽은 반전
  4. 아래/위: 키마다 그 그림에서 출발해 [과장 키, 사이 그림, 다음 키]를 만든다. 망토·얼굴 유지
  5. 공격은 PixelLab이 그린 흰 검흔을 지우고 원래 프레임의 검흔을 다시 얹음
- 프레임: `frames/<동작>_<방향>/gen_*` (exag.json = 과장된 관절 좌표)
- 스크립트: `tools/anim/exag/` (scratchpad의 `all/` 폴더 기준 경로)
- PixelLab: 뼈대 13.1 + 생성 85건 약 175 = 약 188
