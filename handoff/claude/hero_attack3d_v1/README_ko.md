# 주인공 공격 6방향 v1: 3D 뼈대 설계 (게임 미적용)
사장님 지시: 6방향(→←↘↙↗↖), 뼈대를 최대한 많이(부드럽게), 앞으로 숙이기 40% 과장, 1타 왼쪽 / 2타 오른쪽 / 막타 80° 크게.
- PixelLab 캐릭터에 들어 있는 3D 뼈대로 공격을 직접 설계(`scripts/attack3d.py`): 숙임(×1.4), 몸통 비틀기, 무릎 굽히기, 앞발 내딛기, 칼 든 손은 어깨를 중심으로 도는 원 위에서 휘두름(막타 = 80° 기울어진 면)
- 같은 3D 동작을 옆·↘·↗ 카메라로 찍어 각 15장 뼈대 → animate-with-skeleton-v3. ←↙↖는 반전
- 막대 인형 확인: `stick_*.png`. 결과 프레임: `out_<타>_<east|se|ne>/`
- 검흔은 코드로 그림(칼끝이 보일 때만)
- PixelLab: 9건 36 + 뼈대 추정 0.1
