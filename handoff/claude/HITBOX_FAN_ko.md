# 주인공 베기 판정 = 몸 중심 부채꼴 (×0.7) — Claude 인계 문서

작성 2026-10-24 (KST) · 브랜치 `claude/hitbox-fan` (main 9bd16684에서 갈라짐) · **main에는 아직 안 들어감**

## 1. 정한 것
- 주인 허락: **「0.7배로 두고 판정도 줄여」**.
- 콤보 1·2·3타의 맞는 범위를 **몸 중심 부채꼴**로 바꿨다. 반지름 = 공격 사거리 `GK_REACH` × 0.7. 목표는 "보이는 검흔 = 맞는 곳".
- 기준 자료: `char_v4/pixellab/hero/slash_dark_designs/v3_hitbox/hitbox_spec.json` 과 같은 폴더 `README.md` (아래 4장).

## 2. 정확한 값 (필드 논리 px, 화면 384×216 기준)
| 타 | 중심(발 기준) | 반지름 R | 호 | 시작→끝 각도 | 기울기 rot | 판정 틱(60fps, 공격 시작부터) | sweep 틱 |
|---|---|---|---|---|---|---|---|
| 1타 가로베기 | (0, −13) | 32×0.7 = **22.4** | 140° | −70° → +70° | 0° | 3–10 | 4.2 |
| 2타 되베기 | (0, −13) | 30×0.7 = **21.0** | 140° | +70° → −70° | **−15°** | 3–10 | 4.2 |
| 3타 내려베기 | **(2, −16)** | 37×0.7 = **25.9** | 170° | −100°(머리 위) → +70° | 0° | 4–14 | 6.0 |

판정식 (spec 그대로):
- 점 p를 중심 기준으로 옮기고, `rot` 만큼 되돌린 뒤 y를 0.8로 나눈다 → r, 각도.
- `r ≤ R` 이고 각도가 휘두른 구간 안이면 맞음. 휘두른 비율 `u = (각도 − 시작) / (끝 − 시작)` 이 `0 ≤ u ≤ head(t)`.
- `head(t) = 1 − (1 − clamp((t − 시작틱 + 1) / sweep))²`. 판정 틱 밖이면 안 맞음.
- +x = 보는 쪽. 왼쪽을 보면 x를 뒤집는다. +y = 화면 아래. y 찌그러짐 0.8 (spec `squash_y`, 기존 world.js 부채꼴 판정의 `ddy/.8` 과 같음).
- 몹은 기존과 같은 몸 점 15개(발→머리 5줄 × 왼·가운데·오른쪽 `mm.r`)로 검사. 하나라도 들어오면 맞음.

### 5-4. 시트 형식 (`style_N_*_sheet_native.png`)
- 크기 1216×256 = **칸 76×64 px**, **16열 × 4줄**. 1 px = 필드 1 px (게임에서 ×k로 그림).
- **발 위치 = 칸 안 (26, 54)**. 칸의 (26,54)를 주인공 `hero.x, hero.y`에 맞춘다. 오른쪽 보기 기준, 왼쪽은 좌우 뒤집기.
- 줄: 0 = 1타 가로(H1), 1 = 2타 되베기(H2), 2 = 3타 내려베기(V), 3 = X 교차(제안, 게임에 X 공격 없음).
- 열 c = **공격 틱 2c** (0, 2, 4 … 30). 1타·2타는 틱 0–22(12칸), 3타 0–26(14칸), X 0–30(16칸). 남는 칸은 비어 있다.
- 검흔만 들어 있다(주인공 없음, 뒤·앞·장식 레이어를 합친 것). 3타는 와인드업 부분이 머리 뒤로 가므로 실제로 넣을 때 앞/뒤 순서를 나눠야 한다(`make_hitbox.py` `layers()` 참고).
- 타이밍: 판정 1·2타 틱 3–10, 3타 4–14. 판정 끝난 뒤 10틱 동안 사라짐(판정 없음). X는 A띠 3–10, B띠 10–17 (폭 6px, 길이 31.2px, 교차점 발+(12,−13)).

### 5-6. 규칙
- **이펙트(검기·빛)는 그림에 굽지 않고 코드로 그린다** (CLAUDE.md). 시트를 주인공 그림에 합치지 말고, 코드에서 따로 그리거나 시트를 따로 얹는다.
- 지금 게임 검기는 예전 밝은 하늘색 호(`sArc`)가 **사거리 32/30/37까지 날아간다** → 판정(22.4/21/25.9)보다 그림이 더 멀리 간다. 다크 스타일을 고르면 그 시트(또는 같은 모양을 코드로)로 바꿔야 "보이는 곳 = 맞는 곳"이 된다.
