## 문제
- 2타(찌르기) 그림만 상체가 정면 쪽으로 틀어져 크게 그려져 있었음 (어깨 금장 면적 1타의 약 2배, 다리는 정상).
- 얼굴만 축소(v1) → 어깨가 여전히 큼 / 상체 80% 축소(v2) → 숙인 자세라 키 100px까지 줄어 2타만 캐릭터가 작아짐.
- 크기 조절로는 해결 불가(그림 각도 문제).

## 해결 (PixelLab 미사용, 크레딧 0)
- 2타를 1타 셀만으로 재구성: 회수(1타 f7) → 당기기(f2) → 찌르기(f3, f4 유지) → f5 → f6 → 회수(f7).
- 틱 2,2,1,3,3,3,4 = 18 (기존과 동일), 찌르기 프레임이 tick 5-7이라 H8.combo 2타 hit tick 6 그대로.
- 체형/얼굴 크기 1타와 100% 동일. 3타 손대지 않음.
