# 펠트 마을을 우리 게임답게, 퀄리티 있게 — 방법 연구 (2026-10-23)

주인 지시: "어떻게 하면 펠트 마을을 화면에 우리 게임 컨셉답게 담아낼지. 픽셀랩이든 코드든, 어떤 방법으로 더 퀄리티 있게 뽑을지 생각하고 추론해."

## 1. 지금 마을이 싸 보이는 진짜 이유 (측정)
1. **도트 크기가 섞임** (가장 큼): 1920×1080 화면에서 배경 도트 한 칸 = 화면 5칸, 주인공·NPC·몹 도트 한 칸 = 약 1.3칸 → **약 4배 차이** (`dens_zoom.png`). 배경을 아무리 잘 그려도 굵은 도트라 캐릭터와 따로 논다.
   - 원인: 마을 부품을 16px = 1칸(1배)으로 뽑았고, 배경은 저해상도 판(384×216)에 그려 5배로 키움. 캐릭터는 고해상도로 따로 그림.
2. **시점이 섞임**: 픽셀랩 부품마다 시점이 제각각 (공방 = 마름모 시점, 예배당 = 정면 비스듬, 불탄 집 = 위에서 본 평면도) (`parts_sheet.png`).
3. 부품에 회색 판이 붙어 나옴 → 코드로 지움(구석에서 채우기).

## 2. 픽셀랩으로 할 수 있는 것 (API 확인, 크레딧 0)
- 한 번에 최대 **400px** (map-objects, pixflux), bitforge 200px → 큰 마을 한 장은 불가, **부품 조립**이 맞음.
- `view: "low top-down"` = 주인공과 같은 정면 비스듬 시점으로 고정.
- `color_image` = 팔레트 강제(모든 부품 같은 색), `background_image`+inpainting = 배경에 맞춰 그려 넣기, `init_image` = 코드 스케치에서 출발.
- `generate-with-style-v2` = 기준 그림 그림체 맞추기, `create-tiles-pro` = 바닥·건물벽 이어지는 타일(최대 128px, `tile_view: low top-down`, 기준 그림·팔레트 지원), `inpaint-v3` = 512px 조각 다듬기.

## 3. 실험 (10회 사용)
- 1차 (7회, `gen.py`, high top-down): 시점 제각각 → 탈락 원인 확인.
- 2차 (3회, `gen2.py`, **low top-down + 예배당 팔레트**): 공방·집·불탄 집이 예배당과 **같은 시점·같은 색** (`v2_sheet.png`). 공방이 노래짐(팔레트를 예배당 하나로 잡은 탓), 불탄 집이 덜 탐.
- 시험 조립 (0회, `compose_mock.py`): 광장 한 조각(24×14칸)을 **주인공과 같은 촘촘함(월드 1px = 3px)**으로 조립. 바닥 = 코드(돌길·흙길·풀), 빛 = 코드(해 질 녘, 등불, 점무늬 그림자, 재).
  - 결과 (`felt_compare.png` 위: 지금 / 아래: 시험, `felt_compare_zoom.png`): 바닥·건물·주인공·NPC가 **한 장의 그림처럼** 붙음.
  - 아직 부족: 돌길이 너무 고르고 큼, 색이 단조로움, 빈 곳이 많음 → 아래 4의 2·3·5단계로 채움.

## 4. 추천하는 만드는 법 (순서)
1. **배치 스케치(코드)**: 정본 건물 목록(이장 집, 대장간, 약초 오두막, 경비 초소, 여관, 예배당, 노점, 광장, 리네트 의상실, 폐공방 입구)을 길·광장과 함께 칸 단위로 배치. 시선이 모일 곳(금 간 분수 광장, 예배당 종탑, 리네트 공방)을 먼저.
2. **팔레트 한 장 설계**: 그을린 돌·나무·천 강조색(리네트 천의 빨강·보라·청록)·등불 주황을 담은 팔레트 그림 → 모든 부품에 `color_image`.
3. **바닥 = `create-tiles-pro`** 48px 타일(월드 16px × 3), 이어지는 세트(돌길·흙길·잿빛 풀·재), 기준 그림 = 승인한 건물.
4. **건물·소품 = map-objects `low top-down`** + 팔레트 + 같은 분위기 문구, 월드 1px = 3px. 먼저 기준 건물 1채를 승인받고 나머지를 맞춤.
5. **다듬기**: 조립한 마을을 512px 조각으로 `inpaint-v3` → 건물과 땅 경계, 그을음, 실·거미줄 자연스럽게.
6. **빛·분위기 = 코드**: 해 질 녘 색, 등불 빛, 점무늬 그림자, 재, 실. (잿빛 들판과 같은 방식)
7. **게임 화면(코드)**: 배경을 저해상도 판이 아니라 캐릭터처럼 고해상도로 그리기 (1장 지도 `composeMap`의 구역별 그림 → 3번방과 맞춤).

## 5. 예상 크레딧 (펠트 전체)
건물 13 + 소품 30 = 약 45회, 다시 뽑기 약 15회, 바닥 타일 약 10~20회, 다듬기 약 10~20회 → **약 80~100회** (남은 6,160회).
