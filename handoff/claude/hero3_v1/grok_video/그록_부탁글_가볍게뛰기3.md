# 그록 이매진 부탁 — 주인공 v3 가볍게 뛰기(조깅) 옆·정면·뒷면 (사장님 10-30 「가볍게 뛰기 영상」)

왜: 게임 평소 이동 빠르기(72 = 키의 1.7배/초)는 걷기가 아니라 **가볍게 뛰는** 빠르기. 그록 걷기 영상(키의 0.4배/초)을 넣으면 발이 미끄러짐 → 평소 이동 = 가볍게 뛰기, 두 번 눌러 달리기 = 지금 달리기. 걷기 영상 3개는 마을 같은 곳 천천히 걷기용으로 보관.

## 받은 뒤 (팀장) — 교본 0부 5번
장면 꺼내기 → `loopfind.py`(한 바퀴) → `zoomfit.py`(영상 확대 됐는지) → `vid2sprite.py … 144 [배율]` → 얼굴 찍기(`stamp_one.py`, 옆은 상자 `118,26,152,88`과 기울기) → **러닝머신 재기**(옆: 디딘 발이 장마다 뒤로 가는 칸 → 게임 평소 이동 72에 맞는지) → 걸음 소리 → 게임 연결.
