게임 값: 0.33초(20틱) 동안 몸이 2.75칸 미끄러지듯 이동(처음 빠르게), 그림 6장 자리(2·2·3·4·5·4틱), 잔상 = 주인공 그림 그대로. 이동은 코드가 하니 영상은 **제자리**에서 동작만.
한 영상에 **세 번** 하게 해서 가장 좋은 한 번을 고름.

## 받은 뒤 (팀장) — 교본 0부 5~7
장면 꺼내기 → 세 번 중 가장 좋은 한 번(웅크림 → 낮은 돌진 → 디딤 → 일어섬) 잘라 6~8장 → `zoomfit.py` → `vid2sprite.py … 144` → `ground.py`(바닥에) → 얼굴(정면·옆, 기울기 찾기 / 비스듬하면 영상 얼굴) → 아틀라스 `dash_*`(틱 2·2·3·4·5·4에 맞춰 고름, 낮은 돌진 장이 처음 빠른 2~3장에) → 잔상(주인공 그대로)·무적·거리는 코드 그대로 → 고른 녹화 전·후 영상.
