# 그록 이매진 부탁 — 정면·뒷면 공격 3타 + 달리다 찌르기 (사장님 11-01 「우리 완성된 옆모습 공격 모션 그록한테 전달하고 앞뒤 공격모션 제작하자 달리면서 찌르기도」)
**옆 완성본(게임에 들어감, PR #204)과 같은 동작을 정면·뒷면에서.** 참고: `ref_side/옆_3타_완성참고.mp4`·`옆_3타_핵심장.png`, `ref_side/옆_달리다찌르기_완성참고.mp4`·`옆_달리다찌르기_핵심장.png`.
옆 3타 = 1타 내려베기(머리 위 → 앞 → 뒤 아래) · 2타 올려베기(뒤 아래 → 아래 → 앞 위) · 3타 크게 들어 내려치기. 달리다 찌르기 = 칼을 허리 높이로 들고 달리다 찌름 → 다 뻗고 멈춤 → 바로 당겨 빼기.

**그록 1차(공격콤보_정면_1차·뒷면_1차, 11-01) = 안 씀** (사장님 11-01 「이거 아니다」). 고칠 점 그림 `그록1차_고칠점.png`:
- 정면: 1·2타가 옆으로 크게 휘두르기(가로 쓸기)라 옆 완성본과 다름(F-28), 4초쯤부터 화면이 당겨져 주인공이 커짐(F-112, 발 높이 827→931/960), 끝에 칼을 땅에 꽂음(F-180).
- 뒷면: 5.5초쯤부터 옆으로 돌아섬(B-136, 뒷모습 아님), 끝에 칼을 땅에 꽂음(B-180).
→ 부탁 글에 「크기 그대로·발 높이 그대로」 「뒷면은 끝까지 뒷모습, 옆으로 안 돎」 「칼 땅에 안 꽂음」 「정확히 두 번, 가로 쓸기 없음」 「앞으로 걸어 나오지 않고 제자리에서 발 구름」을 넣음.

**배운 것 그대로 (옆에서 끊김을 고친 방법)**: 한 영상 = 한 동작 덩어리, 다음 영상 시작 그림 = 앞 영상의 **멈춘 마지막 장**, 「바로 시작·되돌아가지 않음」, 분홍 임시 칼(#FF00FF), 초록 바탕. 발밑 흙 튀김은 괜찮음(사장님 10-31 「그대로 쓰자」).
순서: 정면 1·2타 → 정면 3타, 뒷면 1·2타 → 뒷면 3타, 정면 찌르기 → 정면 빼기, 뒷면 찌르기 → 뒷면 빼기 (8개). 결과는 줄이지 않은 원본 mp4 로 그록 폴더에.
