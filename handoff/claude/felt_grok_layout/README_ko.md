# 펠트 마을 — 그록 대표 그림 기준 구도 자료 (2026-10-23)

사장님 결정(3번방 전달): 그록 펠트 그림(드라이브 `1장_펠트_마을_추천.png`)을 대표 그림으로. 두 방이 같이 먼저 인게임에 넣어 구도를 잡는다. 이번 단계 크레딧 0.

나눈 일: 3번방 = 위에서 본 배치도로 펴기 → 맵 칸 배치 → 인게임 "구도 잡기 판". 마을배경방(여기) = 색 목록 + 건물 짝 맞추기 + 나중에 뽑을 부품 목록.

## 파일
- `grok_felt_keyart.png` 대표 그림 원본 (1536×864)
- `palette_32.png` / `palette.json` / `palette_view.png` — 마을 색 32개. PixelLab `color_image`에 그대로 넣는다. 다시 뽑기 `python3 palette.py`
  - 바탕 24색: 하늘 빼고 그림 전체에서 뽑은 색 (어두운→밝은)
  - 강조 8색: 물빛 2, 파란 차양, 포도주색 차양, 보라 천, 이끼, 불씨, 등불. 그림이 거의 세피아(채도 있는 점의 99.8%가 갈색)라 작은 점들에서 고른 색을 조금 또렷하게 올림
  - `keyart_in_palette.png` = 이 32색만으로 다시 칠한 그림 (색 목록이 그림을 잘 담는지 확인용)
- `match_annotated.png` / `match.json` — 그림 속 번호 ↔ 정본 건물. 다시 뽑기 `python3 match.py`
