# hero_atk_feel v1 (2026-10-20, 저장만 · 게임 미적용)
위/아래(대각선 그림) 공격 손맛 비교. 샌드박스에서 M 키(폰: 오른쪽 위 버튼)로 전환.
- 현재: 대각선 그림 그대로.
- A: 대각선 그림 + 코드 연출 (대각선 전진 1·2타 ~12px/3타 ~17px, 대각선 찌르기 잔상·3타 대각 반달, 칼끝 불꽃, 잔상 1장, 타격 순간 늘림).
- B: 위/아래 공격만 옆모습 공격 그림 + A와 같은 대각선 연출/판정.
- 영상: atk_modes_AB.mp4 (왼쪽 현재 / 가운데 A / 오른쪽 B, ↘↗↙ 1→2→3타, 실제 속도 + 1/3 슬로우).
