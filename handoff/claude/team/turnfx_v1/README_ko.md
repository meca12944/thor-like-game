# 방향 꺾기 효과 v1 (사장님 10-24 「방향 전환 시 모션이 있어야 부드럽고 역동적」 → 팀장 → 이펙트 담당) — 브랜치 claude/turn-fx (main 위), main 합치지 않음
몸 돌기 그림은 모션 담당 몫. 여기는 코드 효과만 (`test128/world.js` TURN, heroTurnFx, fx 'skid').
- 0.12초 이상 움직이던 방향에서 꺾을 때만, 0.14초에 한 번:
  - 120°+ (180° 브레이크·135°): 옛 방향으로 흙먼지 3번 + 미끄러진 자국 두 줄(0.45초) + 몸이 옛 방향으로 쏠림(출발·멈춤 쏠림과 같은 용수철 h8Lean, 세기 1.4) + 망토·머리카락이 늦게 따라오는 잔상 1장(옛 자세, 0.11초, 투명도 .32) + 작은 소리.
  - 40~90°: 발밑 먼지 1번 + 살짝 쏠림(0.55). 걸을 때는 쏠림·잔상 0.6배.
- 공격·회피대시·점프 공중 중에는 안 나옴. 손잡이 TURN 표 하나.
