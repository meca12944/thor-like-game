# 그록 얼굴을 도장처럼 붙이기 — 게임 예시 · 규격 · 티 안 나게 (검흔 담당, 10-25, 크레딧 0)
사장님: 「미니 캐릭 주인공 얼굴을 그록이 그려 주면 도장처럼 찍어 넣는다. 자연스러워야 한다.」 → 모션 담당과 같이 정리용.
※ 유튜브는 이 작업실에서 로봇 확인으로 막혀 영상 내용은 못 봄(앞 보고서와 같음). 아래는 **직접 읽은 글**과 **검색 요약(깊이 확인 못 함)**을 나눠 적음.

## 1. 얼굴(머리)을 따로 그려 몸에 붙이는 게임 예시
| 게임 | 크기 | 어떻게 | 출처 (확인 정도) |
|---|---|---|---|
| Stardew Valley (농부) | 한 칸 16x32px | 맨 아래 층 = 머리·몸통·장화, 그 위에 바지 → 셔츠 → 장신구(안경·화장·수염) → 머리카락 → 모자 → 팔 순서로 겹침. 좌우는 뒤집기. **눈 깜빡임은 몸 그림의 6x2px 사각형을 따로 가져와 덮음**. 피부·눈 등은 **정해진 색으로 찾아 다시 칠함**. 다른 층의 위치는 **동작(장)마다 코드가 정함** | https://stardewvalleywiki.com/Modding:Farmer_sprite (직접 읽음) |

- 공통점: **얼굴(눈)·머리카락·모자를 서로 다른 층**으로 두고, **층의 위치는 장마다 코드(표)로** 맞춤. 색은 **팔레트로 고정**.

## 2. 규격 (예시에서 본 것 → 우리 제안)
- 예시: Stardew 몸 16x32 에 깜빡임 판 6x2px / LPC 64x64 / 강좌(Pixelblog 55) 몸 26x32.
- 우리 주인공 (걷기 키 약 144~165px, 정면 얼굴 피부 14x18px 로 잼):
  | 항목 | 제안 |
  |---|---|
  | 얼굴 판 | 피부 + 둘레 2px = 약 **20x24px** (정면), 옆 14x24 |
  | 눈 | 2~3px 너비 · 2~3px 높이, 눈 사이 = 눈 하나 (Pixelblog 17 비율) |
  | 입 | 2~3px 한 줄 (늘 같은 모양) |
  | 외곽선 | 판 안에는 없음. **턱·뺨이 배경과 닿는 곳만 몸 그림의 외곽선을 그대로 남김** (판은 피부 안쪽만 바꿈) |
  | 색 수 | 피부 밝음·중간·그림자 3 + 눈 어둠 1 + 눈 반짝임 1 + 입/볼 1 = **6색 고정** |
  | 방향 | 그려서 5방향 (↓ ↘ → ↗ + ↑ 는 얼굴 없음), ↙ ← ↖ 는 뒤집기 (머리 가르마가 비대칭이면 그때만 따로) |
  | 표정 | **하나만** (사장님 10-25 「얼굴 표정은 하나로 가야 돼, 표정 변화는 안 돼」). 힘줌·아픔·깜빡임 판 없음 → 방향마다 기본 1장 (+ 숙인 판은 같은 표정을 기울인 것만) |
  | 고개 기울기 | 0° 판 + 숙인 판(약 10°) 1장 씩 — 도트는 돌리면 깨지므로 **돌리지 말고 미리 그린 판**으로 |

## 3. 붙인 티 안 나게 (읽은 것 + 우리 시험 결과)
1. **층 순서**: 머리(피부·뒷머리) → **얼굴 판** → **앞머리(이마를 덮는 머리카락) 층** → 모자/후드. 앞머리는 얼굴 판 위에 다시 얹어야 「얼굴이 머리카락 위에 떠 보이는」 티가 안 남 (Stardew 층 순서와 같은 생각).
2. **팔레트 고정**: Stardew는 피부·눈을 정해진 색으로 찾아 다시 칠함. 우리도 판과 몸 그림을 같은 6색으로 → 장마다 피부 빨강 155~165 로 흔들리던 것이 사라짐 (우리 C/D 방식의 밝기 맞춤은 그 전 단계).
3. **경계**: 판은 **지금 장에서도 피부인 자리(+1px)만** 바꿈 → 몸 그림의 턱선·외곽선이 그대로 남음. 외곽선은 「물체와 배경 둘 다보다 어두워야」(lospec 외곽선 글, 검색 요약) — 판에 새 외곽선을 넣지 않음.
4. **흔들림 맞추기**: 판의 자리는 장마다 **피부 겹침으로 찾고**(우리 도구) 결과를 **장별 표(dx, dy, 기울기 판 번호)** 로 저장 → 게임에서는 표대로 (Stardew가 층 위치를 장마다 코드로 정하는 것과 같음). 머리 위아래(bob)는 몸 그림이 이미 갖고 있으니 판은 그 위치를 따라가기만.
5. ~~깜빡임~~ → 하지 않음 (사장님 10-25 표정 하나, 깜빡임도 표정 변화).
6. **확인**: 100% 크기로 장을 넘기며 깜빡임·떨림 확인, 제자리 돌기(turn_check_v1)로 방향끼리 비교 (Pixelblog 55).

## 4. 그록에게 부탁할 것 (제안)
- 방향마다 **표정 하나** (기본) + 같은 표정의 숙인 판, **게임 크기 그대로(1배) 또는 정확히 4배**, 투명 바탕.
- **얼굴 층과 앞머리 층을 따로** (같은 칸 크기, 같은 자리).
- 쓴 색 6개를 색 번호(#hex)로 같이 적어 달라고 → 몸 그림도 같은 6색으로 맞춤.
