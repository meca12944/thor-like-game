# 얼굴 도장 v2 「얼굴이 아주 커진다」 — 보이는 크기 재기 + 앞머리 자료 (검흔 담당, 10-25, 크레딧 0)
재료: claude/motion-lab 807fea2c `motion_lab/grok_hero/stamp2/faces_lineup.png` (12줄 × 8장, 칸 156px = 게임 26px × 6배). 6x6 덩어리 = 게임 1px 로 셈. 결과 `v2_measure.json`.

| 동작 | 살색 넓이 (게임 px) 전 → 후 | 머리(살+머리카락) 중 살색 비율 | 밝기 (RGB 평균) | 윗얼굴 절반 중 앞머리 |
|---|---|---|---|---|
| 정면 걷기 | 112 → **162 (+45%)** | 0.17 → **0.25** | 126 → 128 | 0.58 → 0.60 |
| 정면 달리기 | 111 → **162 (+46%)** | 0.17 → **0.25** | 125 → 128 | 0.57 → 0.59 |
| ↘ 걷기 | 75 → 83 (+11%) | 0.12 → 0.13 | 127 → 135 | 0.20 → 0.24 |
| ↘ 달리기 | 81 → 83 (+3%) | 0.13 → 0.13 | 121 → 135 | 0.32 → 0.24 |
| 옆 걷기 | 54 → **99 (+83%)** | 0.10 → **0.19** | 125 → 135 | 0.36 → 0.67 |
| 옆 달리기 | 54 → **101 (+85%)** | 0.11 → **0.20** | 122 → 136 | 0.36 → 0.66 |

읽은 것:
1. **정면·옆이 커진 까닭은 앞머리가 아니라 얼굴 틀 자체** — 정면은 윗얼굴의 앞머리 비율이 그대로(0.58→0.60)인데 살색이 45% 늘었음 = 뺨·턱이 넓어짐. 옆은 살색이 거의 2배(54→99) = 뺨이 뒤·아래로 커짐 (앞머리 비율은 오히려 늘었는데도).
2. 머리 중 살색 비율: 원래 정면 0.17 · 옆 0.10 → v2 정면 0.25 · 옆 0.19. 같은 머리 크기에서 얼굴이 1.5~1.9배로 보임 = 사장님 「아주 커진다」.
3. ↘ 는 거의 그대로 (+3~11%) → ↘ 판은 크기 문제 없음.
4. 밝기: ↘·옆이 +8~14 밝아짐 (121~127 → 135). 밝은 살은 더 커 보임 (팽창색) → 판 밝기를 원래 장 평균에 맞추면 조금 줄어 보임.

추천 (모션과 맞출 것):
- 판의 **살색 바깥 틀을 원래 장의 살색 틀 안으로 잘라** 찍기 (원래 장에서 피부였던 자리 + 1px 만 바꿈 = 예전 C 방식의 경계) → 넓이가 원래와 같아짐. 눈·입 자리만 새 판으로.
- 목표 숫자: 머리 중 살색 비율 정면 0.17~0.19 · ↘ 0.12~0.14 · 옆 0.10~0.12, 살색 넓이 원래 ±10%.
- 밝기는 원래 장 평균 ±3 안 (지금 D 방식 그대로).

## 앞머리가 얼굴을 얼마나 덮어야 작아 보이나 (자료, 지어내지 않음)
- 도트 강좌에서 「앞머리 덮는 비율 = 얼굴 크기」를 숫자로 다룬 글은 **못 찾음**.
- 사람 머리 손질 쪽: 「앞머리는 이마 일부를 덮어 이마가 작아 보이게 하는 착시」, 다만 「이마가 짧은 사람은 앞머리가 머리를 더 작아 보이게 할 수 있다」(헤어 디자이너 인용) → 덮는 양이 보이는 크기를 바꾼다는 것만 확인 (https://www.newbeauty.com/view/bangs-for-your-face-shape, 검색 요약).
- 도트 쪽 조언(검색 요약): 앞머리는 큰 다발 4개 정도로 나눠 읽히게 (https://design.tutsplus.com/tutorials/kandi-runner-create-a-pixel-art-sprite-from-scratch--cms-21705), 눈이 앞머리에 묻히지 않게 눈 둘레를 살짝 어둡게 (https://polycount.com/discussion/comment/2143271/), 1배·흐림 시험 (https://itch.io/post/6047047).
- 우리 숫자로 본 답: 원래 그림은 **정면 윗얼굴의 약 58%를 앞머리가 덮고**, 머리 중 살색이 17%일 때 사장님이 보던 크기. v2도 덮는 양은 같으므로 앞머리를 더 늘리기보다 **살색 틀을 원래대로**가 맞음. 앞머리와 눈 사이는 1px 이상 띄워 눈이 묻히지 않게.
