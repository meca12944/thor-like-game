## 1) 검기 지운 몸 (`cells/`)

- `<방향>_<타>_clean.png` = 지운 칸(회색 바닥 그대로), `_rgba.png` = 바닥을 지워 몸만 남긴 투명 그림, `_mask.png` = 지운 자리, `meta.json` = 발 위치·몸 가운데.
- 확인 그림: `clean_sheet.png`(왼쪽 원본 / 오른쪽 지움), `rgba_sheet.png`(몸만).
- 남은 문제: **정면 1타(손 앞)·정면 3타(다리 앞)** 는 검기가 몸 위를 덮고 있던 자리라 메운 곳이 뭉개짐 → 모션 담당이 손으로 다듬거나, 그록에게 "검기 없는 같은 자세"를 한 번 더 부탁하는 게 빠름. 나머지 10칸은 깨끗함.
- 공격 그림에 칼 몸이 없음 (맨손 자세) → 칼은 사장님 답 대기.

## 2) 지운 몸 + 지금 게임 코드 검흔 (`grok_atk_codeslash_v1.mp4`, 4방향 × 3타, 반 속도)
- `gamecap.js`: 게임(main)에서 주인공만 숨기고(깜빡임 틱) 1·2·3타 검흔을 틱마다 찍음 → 검흔만 뽑음. 코드 칼(heroBlade)은 빼고 검흔만.
- `compose.py`: 그록 몸(0.35배, 게임 주인공 키 약 100px)을 게임 발 위치에 맞추고, 어두운 부채꼴은 몸 뒤·밝은 테두리는 몸 앞(게임과 같은 층)으로 얹음. 왼쪽 칸 = 그록 원본(검기 구운 그림), 오른쪽 칸 = 지운 몸 + 코드 검흔.

## 3) 그록 검기 모양을 코드 검흔이 따라가려면 (재 본 숫자, 단위 = 몸 키)
| 타 | 그록 | 지금 코드 (GK_FAN) | 다른 점 |
|---|---|---|---|
| 1타 세로 | 몸 앞에서 땅(0.05)부터 머리 위(1.15)까지 올라가는 **세로 초승달**, 가로 폭은 키의 0.35~0.7 | 땅 평면에서 -70°→70° 옆으로 쓸어 가는 **부채꼴**, 반지름 ≈ 0.65 | 쓸어 가는 면이 다름 (그록 = 세운 면, 코드 = 바닥 면). 크기도 그록이 1.7배 큼 |
| 2타 가로 | 허리 높이(0.4~0.8)에서 몸 뒤(-0.3)부터 앞(+0.72)까지 감는 **납작한 고리** (가로/세로 2.3) | 땅 평면 70°→-70° 부채꼴, rot -15 | 그록은 몸을 감싸는 고리(뒤까지 이어짐), 코드는 앞쪽 부채꼴만 |
| 3타 반원 | 머리 위(1.0)에서 발끝 앞 땅까지 내려오는 **큰 반원**, 폭 0.8~0.97 | -100°→70° 넓은 부채꼴, 반지름 ≈ 0.8 | 그록은 위에서 아래로 내려꽂는 세운 반원 |
| 공통 | 면 없이 **가는 빛 띠**(끝이 뾰족, 가운데 굵음), 청록 + 흰 심 | 어두운 면 + 강철 테두리(파쇄 강철, 사장님 10-24 선택) | 그림 방식 |

바꿀 것 (제안, 사장님 확인 뒤):
1. **그리기만 바꾸고 맞는 판정은 그대로** 두는 게 안전함: 판정 부채꼴(GK_FAN, 보이는 곳 = 맞는 곳)은 바닥 면이라, 세운 초승달을 그대로 판정으로 쓰면 앞쪽 좁은 띠만 맞게 됨(손맛·적중률이 크게 떨어짐 — 10-24 연구: 반지름 0.7배에서 적중 29%→69%).
   → 그리기 = 세운 초승달/고리, 판정 = 지금 부채꼴. 대신 세운 초승달이 **바닥에 닿는 끝**이 판정 부채꼴 앞끝과 같은 자리에 오게 맞춤.
2. 새 그리기 값 3개를 타마다 더함: `plane: 'v'|'ring'`(세운 면 / 고리), `top`(머리 위 높이, 1타 1.15·3타 1.0), `ring`(2타 고리 가로/세로 2.3, 허리 높이 0.6).
   gkFanImg 의 화소 계산을 쓰지 말고, 초승달 띠를 **곡선 몇 개 + 미리 그린 그림**으로 그림 (지금 캐시 구조 그대로, 비용 같음).
3. 면 대신 **띠**: 지금 테두리(rim) 그리기를 띠의 몸통으로 쓰고, 어두운 면(fan)은 끔 또는 아주 옅게. 색은 사장님이 고른 파쇄 강철 유지 / 그록의 청록으로 바꿀지는 사장님 선택.
4. 2타 고리는 몸 **뒤로 지나가는 부분**을 주인공 뒤 층(layer 0)에, 앞부분을 앞 층(layer 1)에 나눠 그림 (지금 층 나누기 그대로 씀).
