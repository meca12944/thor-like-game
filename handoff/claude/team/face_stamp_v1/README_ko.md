# 새 그록 주인공 얼굴 도장 시험 (검흔 담당, 10-25, 사장님 「5.5등신 모든 모션에서 얼굴을 잘 그리는 방법」, 크레딧 0)
옛 `handoff/claude/hero8_face_v1` (피부 모양 겹침으로 자리 찾기, 안 맞으면 안 찍음)를 새 주인공에 옮김.
- 도장: claude/motion-lab `frames/walk_down/000`(정면) · `frames/walk_right/000`(옆) · `se_test/walk_se/000`(↘)
- 시험: `se_test/walk_r2`(옆 걷기) · `run_se2`(↘ 달리기) · `run_s`(앞 달리기) 각 8장
- `common.py`: 새 피부 기준 (옛 기준 r>150 은 새 피부(평균 약 160,125,105)에서 겨우 걸리고 가죽 갈색과 헷갈림 → 밝기 0.5↑ · 채도 0.12~0.48 · 머리 위 34줄 안)
- `stamp.py`: 찍는 법 A = 얼굴 + 둘레 2칸 통째(옛 방식) / B = 지금도 피부인 자리만(앞을 가리는 머리카락·손은 남김) / **C = B + 밝기 맞춤(추천)**. 얼굴 크기가 8% 넘게 다르면 도장을 그 크기로 맞춤.
- 결과 그림: `faces_stamp_before_after.png` (전 / A / C, 초록 = 겹침 점수), 찍은 장 `out/<동작>/*_C.png`

## 얼굴이 뭉개지고 표정이 달라지는 까닭 (잰 것)
1. **얼굴이 아주 작음**: 걷기 키 약 165px에서 피부 넓이 67~137px (옆 67, 정면 137) → 눈 하나가 1~2px. 1px만 달라져도 표정이 바뀜.
2. **장마다 새로 그림**: PixelLab이 장마다 얼굴을 다시 그림 → 옆 걷기 8장 모두 눈이 빠지거나, 앞 달리기에서 눈 크기·입 모양이 장마다 다름.
3. **머리 크기가 동작마다 다름**: 앞 달리기 얼굴이 정면 걷기보다 11~16% 작음 (5.5등신이 동작마다 흔들리는 증거, 모션 담당 숫자와 맞춰 볼 것).
4. **크기 조절**: 장을 0.94~1.06배로 맞추면 1~2px 눈이 섞여 흐려짐.
5. **고개 기울기·밝기**: 달릴 때 고개가 기울고, 피부 밝기도 장마다 다름(평균 빨강 155~165).

## 추천 (모션 담당과 맞출 것)
- 방향마다 **도장 1장을 손으로 다듬어 정본**으로 (특히 옆 눈) → 모든 동작에 C 방식으로 찍기.
- 머리 크기를 먼저 맞추기 (몸 키가 아니라 **머리 높이**로 배율을 정하기) → 도장을 줄이지 않아도 됨.
- 고개가 기우는 동작(달리기·공격)은 기울인 도장을 따로 1장씩 (방향 × 2 = 크레딧 0, 손 다듬기).
- 맞기·쓰러지기는 표정이라 찍지 않음 (옛 규칙 그대로).
