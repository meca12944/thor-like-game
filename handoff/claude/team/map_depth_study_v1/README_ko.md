# 2D로 웅장하게 — 깊이 효과 · 맵 종류별 분위기 · 참고 게임 (검흔·효과 담당, 10-25, 크레딧 0, 연구만)
사장님: 「지도 및 맵 구현 엘든링처럼 2D로 웅장하게. 각종 맵 구성 어떻게 할지도 연구 회의해.」 팀장 초안(맵 7종 · 그리는 층 8개)에 대한 효과 담당 답.

## 1) 깊이·웅장함 코드 효과 (가벼운 순)
「잰 값」 = 우리 게임에서 직접 잰 것 (CPU 4배 느리게, 폰 흉내, 한 장면). 「어림」 = 아직 안 만듦, 같은 방식 효과에서 어림.
| 효과 | 어떻게 (그림에 굽지 않음) | 무게 | 한 장면 ms | 그리는 층 |
|---|---|---|---|---|
| 화면 색 (맵 종류마다) | 바닥·소품·캐릭터 위에 색 한 장 곱하기(multiply) — 지금 drawHDLight 'dusk' 방식 | 가벼움 | 어림 0.02 | 화면 색 |
| 먼 안개 띠 | 1x64 그라데이션 한 장 drawImage, 전망 줌에 진해짐 (main 들어감) | 가벼움 | 잰 값 0.13~0.19 (재 바람과 합) | 효과 |
| 날리는 것 (재·잎·불씨) | 화면 좌표 해시, 저장 없음, 바람·돌풍 (drawAshFall) | 가벼움 | 위와 합 | 효과 |
| 큰 구조물 그늘 띠 + 빛줄기 | 미리 그린 띠·빛 그림 drawImage (scenefx shade) | 가벼움 | 잰 값 약 0.2 | 앞 가림 위 |
| 구름 그림자 | 흐린 타원 3~4개를 한 번 그려 두고 천천히 흘림 (multiply) | 가벼움 | 어림 0.05~0.1 | 그림자 |
| 높이 그림자 (높은 길·탑·다리) | 물체마다 그림자 모양을 한 번 만들어 두고 drawImage, 높이에 비례해 해 반대쪽으로 밀기 | 가벼움 | 어림 물체 10개에 0.1 | 그림자 |
| 아래층 흐림·어둡게 (꺼진 땅 너머 옛 지붕) | **맵을 읽을 때 한 번** 아래층을 어둡고 푸르게 + 1px 흐리게 만든 그림으로 저장 → 매 장면은 drawImage 1번 (매 장면 blur 금지) | 가벼움 (미리 만들면) / 무거움 (매 장면 blur) | 어림 0.05 / 매 장면 blur 는 수 ms | 아래층 |
| 가까운 안개 (발밑 깔림) | 큰 반투명 안개 그림 2장을 다른 속도로 흘림 (시차) | 보통 | 어림 0.2~0.3 | 앞 가림 |
| 잿가루 폭포·구덩이 바람·붉은 실·호수 비침 | scenefx 물체 (claude/ch1-scenefx) | 보통 | 잰 값 0.18~0.28 씩, 5개 모두 0.85~0.90 | 효과 |
| 먼 배경 시차 (내성벽·왕성 탑) | 큰 그림 1~2장을 카메라의 0.2~0.5배로 움직임 | 가벼움 | 어림 0.05~0.1 (그림이 크면 메모리) | 먼 배경 |
| 진짜 피사계 흐림 (HD-2D 틸트시프트) | 화면 전체 blur 셰이더 | **무거움** | 폰에서 수 ms~ (WebGL 필요) | – 쓰지 않음 |
- 규칙: 화소마다 매 장면 계산 금지 (검흔 때 폰 멈춤 원인, 10-24). 미리 그린 그림 + drawImage, 화면 밖은 안 그림. 한 장면 효과 합계 **2ms 안**.
- HD-2D(옥토패스)의 깊이는 피사계 흐림·틸트시프트·블룸이 핵심 (Wikipedia HD-2D) — 우리는 캔버스 2D라 진짜 흐림 대신 「아래층·먼 배경을 미리 흐리게 만든 그림」으로 흉내.

## 2) 맵 종류별 분위기 세트 (1장부터, 초안)
| 맵 | 빛 방향·색 | 화면 색 (곱하기) | 안개 | 날리는 것 | 소리 결 |
|---|---|---|---|---|---|
| 잿빛 들판 (field) | 왼쪽 위 낮은 해, 흐린 노랑 | 잿빛 보라 약하게 (#d8d0dc 정도) | 먼 안개 띠 .32, 전망 때 진하게 / 꺼진 땅 둘레 발밑 안개 | 재 46 (바람 →), 가끔 불씨 | 바람 낮게, 멀리 종소리 (가라앉은 종탑 복선) |
| 펠트 (거점 마을) | 해질녘 옆빛 + 화덕·횃불 깜빡임 (지금 dusk + flick) | 따뜻한 dusk (지금 #cec4de) | 거의 없음 (마을은 맑게 = 쉼) | 화덕 연기 기둥(루카 모닥불), 재 적게 | 모닥불 탁탁, 사람 소리 작게 |
| 폐공방 (던전 1~2층) | 위에서 비스듬한 빛줄기 몇 개 + 손전등처럼 주인공 둘레만 밝음 (지금 m.dark) | 차갑고 어두운 남색 | 낮게 깔린 먼지 | 먼지, 끊긴 실 가닥 흔들림 | 베틀 삐걱, 실 튕기는 소리 |
| 보스방 (아라크네) | 가운데 위 한 줄기 빛 → 2페이즈 붉은 맥박 (지금 lairP2) | 1페 남색 → 2페 핏빛 | 가장자리 어둠 진하게 | 실 흔들림 + 박동 빛, 고치 가루 | 심장 박동(heartbeat 1.1초)에 맞춘 낮은 북 |
| 잇는 길 (다리·회랑) | 맵 양쪽 분위기를 섞음 (구역 경계에서 색 바꿈 0.5초) | 양쪽 사이 | 다리 아래 = 깊은 안개 (높이 느낌) | 바람 강하게 | 바람 |
| 숨은 곳 | 한 방향 좁은 빛 (발견 느낌) | 조금 밝게 | 없음 | 반짝이 몇 개 | 조용히, 작은 울림 |
- 원칙: **맵 종류마다 빛 방향 하나** (pixnote 명암 글: 한 장면에서 빛 방향은 같게), 색은 지역마다 확실히 다르게 (하이퍼 라이트 드리프터: 지역마다 보라·파랑 / 주황·빨강으로 크게 바뀜).

## 팀장 초안에 대한 의견
- 맵 7종 · 층 8개 찬성. **층 번호 + 높이(level)** 를 지도 데이터에 넣으면 (CrossCode 방식) 높이 그림자·아래층 흐림·다리 아래 안개를 코드가 자동으로 붙일 수 있음.
- 「아래층」 은 맵을 읽을 때 한 번만 흐림·어둡게 만들기 (매 장면 금지).
- 모든 효과는 구역(area)마다 켜고 끄는 값으로 (지금 m.fog · m.wind · m.ash 처럼) → 맵 담당이 JSON만 고치면 됨.
