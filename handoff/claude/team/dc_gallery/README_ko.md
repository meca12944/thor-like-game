## 바로 해 볼 것 TOP 5
1. 히트스톱 = 공격 세기 비례, 맞은 몹 크게·주인공 작게 흔들기 (전·후 영상).
2. 검기를 칼끝 지나간 길 따라 띠로 (지금 코드 다듬기).
3. 얼굴: 기준 1장 고정 → 동작 초안 → 얼굴만 덮기 (= face_stamp_v5 방식 맞음).
4. AI 영상 → 장면 고르기 시험(그림 1장, 동작 이름만, 한 색 배경, 보간 X) — 크레딧 견적 먼저.
5. 손맛 좋은 액션 게임 영상과 나란히 비교 영상.
