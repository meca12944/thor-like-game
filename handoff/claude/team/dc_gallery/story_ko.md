# DC 갤러리 팁 — 이야기·대사·연출(CG)·AI 글쓰기 (스토리 3번방, 2026-10-27)

> 사장님 지시 「DC AI개발갤러리 정보 싹 긁어와, 필멸자 개발하는 전원 다 보내」 → 팀장 배분: 스토리 = 이야기·대사·연출·AI 글쓰기.
> 본 곳: AI 게임 개발 갤(aidevelop) 목록 1~3쪽 + 관련 글, 인디 게임 개발 갤(game_dev) 관련 글. 페이지는 일반 접속으로 읽힌 것만 씀(우회 없음). 갤 안 검색은 다른 갤 글이 섞여 나와 안 씀. **댓글은 페이지에 안 실려 와서 본문만** 봄.
> 솔직히: 두 갤 모두 **이야기·대사를 AI로 쓰는 방법을 자세히 다룬 글은 거의 없음**(대부분 코딩·그림·도트 이야기). 아래는 그중 우리에게 쓸모 있는 것만.

## 2. TOP 3 (우리에게 가장 쓸모)
1. **AI 글 티 빼기 2규칙**(#1): 부제·소제목 남발 금지 + 「~와, ~」 쉼표 두 덩어리 문장 금지. → 지명 카드 2줄, 조사 글, 아이템 설명, 그록·클로드 글쓰기 부탁에 바로 적용. 다음 일로 1장 글 전체를 이 규칙으로 한 번 훑기 추천.
2. **긴 설명 대신 핵심 장면 먼저**(#2): 인트로·장 시작은 짧게, 이야기는 풍경·짧은 말로. 글자는 크게(#3과 함께, PC 1080p 대화창 크기 점검).
3. **사람이 결정, AI는 초안 + 한 곳에만 적기**(#5·#7): 정본 0절 = 결정 기록, 숫자·이름은 한 곳에만, 교본은 자주 정리.
