## 바로 해 볼 것 TOP 3 (모션)
1. **얼굴 기준 1장 고정 → 동작 초안 → 얼굴만 덮기** (팁 1·3): 4방향 모든 동작에 face_stamp_v5(정6) 적용 확인 + `headm.py` 로 머리·어깨 ±5% 표. 크레딧 0.
2. **「그림 1장 → 영상 → 장면 고르기」 시험 1개** (팁 1·2): 맞기 ↓ 한 동작만, 정6 그림 1장 + 동작 이름만 + 한 색 배경 + 보간 끔 → 6~8장 골라 우리 64색·발 맞춤·얼굴 도장. 지금 PixelLab 사이 장과 나란히 영상 + 머리 크기 숫자 비교. **영상 도구 크레딧 견적을 먼저 팀장께**.
3. **손맛 좋은 게임과 나란히 비교 영상** (팁 5): 달리기·대시·맞기 3장면, 우리(B·4방향·과장)와 같은 틱 축으로 → 과장 크기(EXAG) 숫자 조절 근거.
