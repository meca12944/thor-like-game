# 검기 크기·판정과 난이도 (주인 10-23 "어려운 편 게임에 맞는 검흔 크기 히트박스") — 미리보기, main 반영 안 함

측정 (reach.js, bot.js; 1장 펠트 몹 4종, 실제 게임 코드):
- 몹 근접 공격이 닿는 거리(몹 중심~주인공): 실마물 34 · 실 꼭두각시 38 · (바늘 거미 덮치기 66, 들개 돌진은 따로)
- 주인공 기본 검기가 닿는 거리: 52~56px → 근접 몹보다 16~20px 멀리서 때릴 수 있음 = 근접 몹은 거리만 잘 재면 안전.
- 자동 플레이(반응 0.3초, 피하기 성공 60% = 보통 사람, 몹 3마리, 60초 × 8번):

| 설정 | 몹 공격 밖에서 때린 비율 | 1분 처치 | 처치당 받은 피해 |
|---|---|---|---|
| 지금 (거리 1배, 폭 1배) | 19% | 21 | 1.9 |
| 거리 0.8배 | 2% | 13.8 | 2.4 |
| 추천: 거리 0.8배 + 폭 1.3배 | 2% | 17 | 2.3 |

결론: 어려운 편이면 검기 거리를 몹 근접 공격 거리와 비슷하게(0.8배: 32/30/37px) 줄여 "때리려면 위험한 곳에 들어가야" 하게 하고,
대신 부채꼴 폭을 1.3배(130/143/156°)로 넓혀 조준은 너그럽게 → 안전하게 때리기 19% → 2%, 처치 속도는 −19%만(폭 안 넓히면 −34%).
0.65배 이하는 안전 0%, 처치당 피해 2배 → 너무 답답함. 무기별 검흔(slash_by_weapon) 거리도 같은 0.8배로 맞추면 됨(창·채찍은 긴 대신 약점 유지).
