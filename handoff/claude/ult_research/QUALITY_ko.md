# 심연 초필살기 '공허 균열' 퀄리티 연구 (2026-10-23)

주인 지시: "이걸 퀄리티 있게 표현하려면 어떻게 해야 되는 게 가장 좋은지 탐구 연구".

## 1. 찾아본 원칙
- **명암 대비가 먼저**: 흑백으로 봐도 읽혀야 어디서나 읽힌다. 어두운 이펙트는 밝은 테두리·심이 있어야 보인다.
- **배경을 어둡게 하면 빛이 산다**: 빛나는 효과는 어두운 배경에서 돋보인다. 단, 효과까지 같이 어두워지면 안 된다.
- **도트답게**: 반투명 대신 디더링(두 색을 점무늬로 섞어 중간 단계를 만드는 기법), 적은 색, 낮은 프레임(끊어 움직이기)이 도트 느낌.
- **준비 → 충격 → 여운**: 힘을 모으고, 터지고, 흔적이 남아야 손맛이 난다.

## 2. 우리 이펙트에서 찾은 문제
1. 화면을 어둡게 하는 막이 이펙트 **위에도** 덮여서, 금과 구멍까지 어두워짐 → 명암 대비 **-6.5** (이펙트가 배경보다 어두움).
2. 반투명으로 흐려지고 60fps로 부드럽게 움직임 → 도트 게임 같지 않음.
3. 힘 모으기·충격·흔적이 없음.
4. 기술 동안 맞은 적이 **하얀 덩어리**로 굳어 있고(멈춘 화면에서 맞은 번쩍임이 안 꺼짐), 죽을 때 매끈한 흰 연기.
5. 기술 동안 주인공이 무적 표시로 **하얗게 바래고 깜빡임**.

## 3. 단계별 실험 (`?fxq=0..3`, fxq_compare.mp4)
| 단계 | 바꾼 것 | 명암 대비(이펙트-배경) | 이펙트 색 가짓수 |
|---|---|---|---|
| 0 원래 | — | **-6.5** | 89 |
| 1 빛나는 금 | 맵만 어둡게, 이펙트는 그 위에 밝게 | **+89** | 96 |
| 2 + 도트답게 | 12fps로 끊어 움직임, 사라질 때 디더링 | +99 | 94 |
| 3 + 준비·충격·여운 | 가슴으로 빨려드는 빛 → 충격 고리 → 갈래 금·튀는 돌·구멍 촉수 → 그을린 자국과 불티 | +73 | **86** |
- 1단계 하나로 읽힘이 가장 크게 좋아짐(어두운 효과 → 빛나는 효과).
- 3단계는 어두운 촉수·돌이 늘어 평균 대비가 조금 내려갔지만 여전히 높고, 색은 가장 적음(가장 도트다움). 눈으로 봐도 가장 완성도 있음.

## 4. 추가로 고친 것
- 맞은 적: 초필살기 중에는 흰 번쩍임 대신 그대로 보이게 → 구멍에 삼켜지는 모습이 보임.
- 쓰러질 때: 흰 연기 대신 도트 공허 파편이 터짐.
- 주인공: 초필살기 중에는 깜빡임·흰 덧칠 없이 또렷하게.

## 5. 채택 = 3단계 (기본값). 남은 다음 단계 후보
- 효과음: 금 가는 소리, 구멍 열리는 저음, 그을림 지글거림 (지금은 기존 필살기 소리).
- 화면 흔들림을 금이 적에 닿는 순간마다 1px.
- 큰 적(보스·챔피언)용 큰 구멍.
