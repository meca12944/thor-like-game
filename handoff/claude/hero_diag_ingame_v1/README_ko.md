# hero_diag_ingame v1 (2026-10-20, 사장님 OK · 인게임 세팅)
사장님 지시: "상하 모션을 대각선으로 대체하고 상하 모션을 없애야 돼" → 주인공은 정면/뒷모습을 쓰지 않는다.

## 규칙 (다른 캐릭터·리네트에도 같은 방식 권장)
- 아래(↓) 보기 = **↘ south-east 3/4 그림**, 위(↑) 보기 = **↗ north-east 3/4 그림**.
- 왼쪽 성분이 있으면(↙ ↖, 또는 정확히 위/아래인데 마지막 좌우가 왼쪽) **좌우 반전**. 그래서 그림은 ↘·↗ 두 방향만 그리면 된다.
- 좌우(→ ←)는 기존 옆모습 그대로.
- 대각선 그림이 있는 동작: 대기·걷기·달리기·회피·점프·1~3타. 없는 동작(피격·사망·시전·차지)은 위/아래를 볼 때 마지막 좌우 방향의 옆모습을 쓴다.
- 공격 판정 방향(H8HB)·콤보 타이밍은 그대로. 대각 공격은 옆모습 틱표 기반이라 contact frame = 4.

## 데이터 / 코드 (test128)
- 그림: anim/hero8_diag.webp (hero_sandbox v5 의 ↘/↗ 클립), hero8.json 의 `<동작>_down` = ↘, `<동작>_up` = ↗, `H8.diag=1`.
- 그 밖의 `_down/_up` 애니는 삭제.
- 코드: index.html `heroCell8()` — `DIAG8` 정규식, `vert`/`hl` 판정, `pick()` 으로 대각/옆모습 선택과 반전(fl).
- 적용 스크립트: tools/anim/apply_diag_v1.py (소스 handoff/claude/hero_sandbox_v5/assets).

## 리네트(2번 방) 적용 방법 요약
1. 리네트 ↘(south-east)·↗(north-east) 3/4 클립을 동작별로 준비 (옆모습 틱 수와 맞추면 콤보 타이밍 그대로 사용 가능).
2. 아틀라스에서 `<동작>_down` ← ↘ 클립, `<동작>_up` ← ↗ 클립으로 교체, 나머지 상하 애니는 삭제, `diag:1` 표시.
3. 그리는 함수에서 위/아래일 때 왼쪽 성분이면 반전, 대각 그림 없는 동작은 옆모습으로 대체 (heroCell8 의 pick() 참고).
- 영상: diag_8dir_ingame.mp4 (↘ ↙ ↗ ↖ → ← × 대기·걷기·달리기·1~3타·회피·피격·점프)
