# hero_attack_side_fwd v1 — 좌우 1·2타 칼 앞으로 + 대각선 공격 = 좌우 공격 인용 (게임 미적용, 저장만)
- 좌우 공격은 지금 게임 그림 그대로. 칼이 몸 뒤로 가던 장면만 다시 그림: 1타 4·5·6번째 장, 2타 4번째 장
  - 그 장면 그림에서 출발해 칼 든 팔만 몸 앞으로 뻗게 함(`plan.py`, animate-with-skeleton-v3, 장당 2). 2타 장면에 남은 옛 칼은 지움
- 대각선(↘↗ / ↙↖) 공격은 리네트처럼 좌우 공격 그림을 그대로 씀(↘↗ = 오른쪽, ↙↖ = 왼쪽)
