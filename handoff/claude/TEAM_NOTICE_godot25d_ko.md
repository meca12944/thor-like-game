사장님 결정: 「3D로 가자 → 2.5D로 가보고, 엔진은 고도(Godot)로 가자.」

지금까지 한 것 (팀장): 저장소 claude/linette-8dir 의 godot25d/ (README_ko.md 꼭 읽기)
- Godot 4.3, gl_compatibility. 작업 상자 안에서 xvfb-run + --write-movie 로 켜고 영상 찍기 됨(우리 방식 그대로 유지 가능).
- 배경 = 그록 그림 그대로(바닥에 평평하게, 빛 안 받음). 카메라 정사영 45도, 바닥 세로 1/sin45배 → 2D 그림 비율 그대로. 1 단위 = 지도 1칸(16px), 주인공 화면 키 42px.
- 캐릭터 = 3D 인형. 그록 설정화(정면·옆·뒷면) → Meshy Multi-Image to 3D(30) → 관절(5, 걷기·달리기 포함) → 움직임 라이브러리(1개 3크레딧, /openapi/v1/animations/library 검색 무료). 주인공 1명 56크레딧. 영상: godot25d/고도_2.5D_우리주인공.mp4
- 3D라 대각선·그림 장 수 문제는 없어짐(4방향 규칙은 2D 그림에만 해당).
- Meshy 열쇠는 사장님이 환경 변수 MESHY_API_KEY 로 넣을 예정 — 받기 전엔 Meshy 쓰지 말 것. 출력·커밋 금지, 크레딧 쓰기 전 예상량 보고.
