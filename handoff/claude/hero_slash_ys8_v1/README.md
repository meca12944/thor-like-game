# hero_slash_ys8 v1 (owner 2026-10-20: "좋다 세팅해")
Basic 3-hit: the hero stands still (idle) and a Ys VIII-style sword arc flies out in the attack direction.
- Arc: tapered crescent, white core / cyan rim / blue glow, sweeps in over 3 steps, tail chases head, sparks at the tip.
- hit1 flat horizontal, hit2 rising (reverse sweep, tilted 30°), hit3 big downward arc + flash; hit-stop 3/3/6, shake 1.2/1.5/3.
- In game: test128/sandbox/index.html (YS table, ysArc/ysDraw); all directions (diagonals rotate the arc, left mirrors it).
- Preview scripts: ys8.py (arc), render_ys8.py (video). hero_slash_ys8_ingame.mp4 = capture of the game sandbox.
- cw_148.png = the original white crescent (previous version, hero_slash_only), kept for reference. No PixelLab credits used.
