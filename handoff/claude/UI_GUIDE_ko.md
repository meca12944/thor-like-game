# UI 기준 (필멸자) — 아이템 사용부터 (사장님 2026-10-23 "사용자한테 불쾌감 없이, 우리 게임 특성 고려, 아이템 사용 세련되고 깔끔한 UI")

게임 특성: 빠르게 달리며 검기 공격 → 저스트 회피 → 필살기. **싸우는 중에 눈과 손을 빼앗지 않는 UI**가 기준이다.

## 원칙 (찾아본 것 + 우리 게임에 맞춘 것)
1. **버튼 하나, 멈춤 없음**: 싸움 중 아이템은 키 하나(E / 폰 물약 버튼)로 바로. 창을 열거나 시간을 멈추지 않는다.
2. **글보다 모양으로**: 개수 = 숫자 동그라미, 대기 = 어두운 부채꼴 + 초, 없음 = 회색. 상태를 한눈에.
3. **필요할 때만 눈에 띄게**: 평소엔 조용히, 체력 35% 아래 + 물약을 쓸 수 있을 때만 슬롯이 천천히 붉게 숨쉰다(깜빡이지 않음).
4. **실패는 조용히**: 못 쓸 때 화면 가운데 상자(msg)를 띄우지 않는다. 슬롯이 살짝 흔들리고 옆에 짧은 회색 말("물약 없음", "체력 가득") + 낮은 '톡' 소리 한 번.
5. **성공은 손맛 있게**: 슬롯 초록 고리 퍼짐 + 주인공 위 초록 "+N" + 체력 막대가 부드럽게 참 + 부드러운 '꿀꺽' 소리.
6. **주운 것은 구석에, 모아서**: 오른쪽 아래 작은 알약 모양 줄(최대 5개, 2.6초 뒤 사라짐), 같은 것은 "×2"로 합침. 싸움 한가운데 글자를 띄우지 않는다. 보물상자처럼 큰 일만 배너.
7. **폰 = 같은 정보**: 물약 버튼에 같은 개수 동그라미·대기 부채꼴.
