# UI 기준 (필멸자) — 아이템 사용부터 (사장님 2026-10-23 "사용자한테 불쾌감 없이, 우리 게임 특성 고려, 아이템 사용 세련되고 깔끔한 UI")

게임 특성: 빠르게 달리며 검기 공격 → 저스트 회피 → 필살기. **싸우는 중에 눈과 손을 빼앗지 않는 UI**가 기준이다.

## 원칙 (찾아본 것 + 우리 게임에 맞춘 것)
1. **버튼 하나, 멈춤 없음**: 싸움 중 아이템은 키 하나(E / 폰 물약 버튼)로 바로. 창을 열거나 시간을 멈추지 않는다.
2. **글보다 모양으로**: 개수 = 숫자 동그라미, 대기 = 어두운 부채꼴 + 초, 없음 = 회색. 상태를 한눈에.
3. **필요할 때만 눈에 띄게**: 평소엔 조용히, 체력 35% 아래 + 물약을 쓸 수 있을 때만 슬롯이 천천히 붉게 숨쉰다(깜빡이지 않음).
4. **실패는 조용히**: 못 쓸 때 화면 가운데 상자(msg)를 띄우지 않는다. 슬롯이 살짝 흔들리고 옆에 짧은 회색 말("물약 없음", "체력 가득") + 낮은 '톡' 소리 한 번.
5. **성공은 손맛 있게**: 슬롯 초록 고리 퍼짐 + 주인공 위 초록 "+N" + 체력 막대가 부드럽게 참 + 부드러운 '꿀꺽' 소리.
6. **주운 것은 구석에, 모아서**: 오른쪽 아래 작은 알약 모양 줄(최대 5개, 2.6초 뒤 사라짐), 같은 것은 "×2"로 합침. 싸움 한가운데 글자를 띄우지 않는다. 보물상자처럼 큰 일만 배너.
7. **폰 = 같은 정보**: 물약 버튼에 같은 개수 동그라미·대기 부채꼴.

## 대화창 (사장님 10-23 "대화 창 탐구 개발 최적화")
8. **읽기 쉬운 글자**: 대화 글자는 화면 크기와 상관없이 최소 15px(폰에서도), 줄 간격 1.5배, 검은 테두리 흰 글자 + 반투명 상자. 설정 → 화면 → 글자 크기(보통·크게·아주 크게)로 키울 수 있다. (게임 접근성 기준: 글자 크기 조절, 배경 상자, 말하는 사람 표시)
9. **누가 말하는지 분명히**: 이름은 상자 위에 붙은 금색 이름표, 초상화가 있으면 왼쪽에.
10. **빠르게 흘러나오고, 누르면 바로**: 글자가 1초에 55자로 흘러나온다. 첫 누름 = 이 쪽 전부 보기, 다음 누름 = 다음 쪽(작은 '톡') / 닫기, Esc = 바로 닫기. 긴 말은 상자 폭에 맞게 접고 3줄씩 쪽을 나눈다(1/2 표시). 다 나오면 오른쪽 아래 ▼가 통통 뛴다.
    - 폰: 그림 아무 데나 톡 = 넘기기. 대화 중엔 공격·대시·달리기 버튼과 막대기를 숨겨 글을 가리지 않는다. 아래 조작 안내줄도 대화 중엔 숨김.

## 일시정지 메뉴 · 설정 창
11. **메뉴는 갈 곳만, 계속하기가 맨 위**: 계속하기 · 설정 · 인벤토리 · 지도 · (들판) 펠트로 돌아가기 / (마을) 월드맵·빠른 저장. 데모 바로가기(상점·대장간)는 아래 작게.
12. **바꾸는 값은 「설정」 한 곳, 탭 4개**: 게임(난이도·달리기 기본) · 화면(흔들림·글자 크기·창 투명도) · 소리(음악·효과음) · 조작(키 바꾸기·게임패드).
13. **고를 수 있는 값을 다 보여 준다**: ◀ ▶ 대신 칩(쉬움 보통 어려움 악몽)과 소리 막대 10칸. 누르거나 ←→ 하면 **바로 적용·저장**(적용 버튼 없음). 효과음은 바꿀 때 작은 소리로 들려준다.
14. **설명은 고른 줄 하나만**: 예) 난이도 → "몹 체력 ×1.25 · 몹 공격 ×1.3 · 물약 최대 3개 · 저스트 회피 판정 빡빡". 창 높이는 탭을 바꿔도 그대로(덜컹거리지 않게).
- 들판에서 Esc / 폰 「메뉴」 = 이 메뉴(예전 작은 "일시정지" 상자 대신). 창이 열리면 게임은 멈춘다.
