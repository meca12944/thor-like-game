## 3. 코드로 할 것 (claude/hero-fix2 위, 크레딧 0, 효과는 코드로만)
1. 틱 다시 나누기 (끝): 아틀라스 공격 동작 틱 자체를 모션 표 [8,8,7,7]/[11,10,12,12]로 (마지막 장 = 서기), 게임은 절대 틱으로 재생 → hero_check 가 그대로 잼. 장이 모자란 방향은 마지막 장을 붙잡음.
2. 몸 반동: 그림 내딛기와 겹치지 않게 — 그림에 내딛는 장이 있는 동안 코드 내딛기 0, lean 만.
3. 칼 잔상: 위 표대로 (끝).
4. 검기는 손에서: 코드 칼은 손에서 (끝). 검기 띠 가운데를 손 쪽으로 옮기는 건 판정(C3)도 같이 바뀌므로 4번방·2번방 확인 뒤.
5. 검수: 4번방 대조 + 2번방 hero_check + 게임 안 영상(1배·0.25배, 몹 쳐서) → 팀장 → 사장님.

## 4. hero_check --atkbody (회의 2차 결과)
- 공격 9줄: 장 수 4~5 ○, 최소 3틱 ○(4~11), 그림 합 = 코드 길이 30/30/45 ○.
- 빨간 칸 「치는 칸 틱」: 도구가 **가장 넓은 장 = 치는 장**으로 보는데, 그록 그림은 망토·머리카락이 예고 장에서 가장 넓음(예: 168 = 126px > 169 = 117px) + ↓는 그림 1장 → 그록 공격 원본 36장이 오면 풀림. 2번방에 「넓이 대신 팔 끝(손 grip) 거리」로 재는 방법 제안.
- 나머지 빨간 칸(회피대시 2틱, 걷기 ↑ 6장, 달리기 머리·발, 맞기 1장)은 모션 몫.

## 5. 고친 버그 (회의 2차 중 발견)
- **검기 틱이 슬로모션을 무시**: `gkTick`이 게임 한 걸음마다 `f.t++` → 저스트 회피 슬로(0.3배) 동안 몸·코드 칼은 느린데 검기만 1배로 지나가 몸과 어긋남(0.3배 영상에서 띠가 안 보이던 원인). → 게임 시간(dt×60)으로 셈. 게임 걸음은 60fps 고정이라 PC 144Hz 모니터에서도 같은 속도.
