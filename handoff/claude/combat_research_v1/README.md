필드(world.js) 기본공격을 헤드리스로 재서 찾은 문제 4개와 고친 결과. 숫자는 probe.js / runprobe.js (base = main, new = 이 브랜치).

고친 것 (world.js, `[combat research]` 표시)
1. 공격 입력 0.18초 보관 — 휘두르는 중·회피대시 중에 누른 것도 버리지 않음.
2. 휘두르는 중에 누르면 다음 타로 이어짐 (전에는 1타로 되돌아감 → 연타하면 1타만 나옴).
3. 주인공이 맞힐 때도 짧게 멈칫(2/3/5프레임) + 3타는 화면 살짝 흔들림.
4. 방향키 없이 누르면 앞쪽 70° 안의 가까운 적 쪽으로 자동 조준.
5. 공격 중에도 방향키 쪽으로 계속 이동 (달리기 속도의 70%).
6. 3타 피해 14 → 20 (콤보를 끝까지 치는 게 이득이 되게).
