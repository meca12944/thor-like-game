# 모션 제작 표준 — 리네트 방식 (2026-10-20 사장님 지시: "앞으로 모션 구현 리네트처럼")

리네트(PixelLab `7e26e0f3`, 117px) 10동작을 만들며 정리한 순서다. 결과물과 스크립트는 브랜치 `claude/linette-8dir`의
`handoff/claude/linette_final_v1/`(최종 묶음), `linette_skel_v1/`(뼈대), `linette_thrust_v1/`(찌른 자세 방식)에 있다.

## 0. 기본 규칙
- 그림은 256 캔버스, 발 기준점 (128,189), 방향마다 크기 통일. 디자인이 바뀌면 안 된다.
- 그림 4방향(아래/위/오른쪽) + **왼쪽 = 오른쪽 좌우 반전**(사장님 OK).
- 이펙트(공격 흔적 등)는 그림에 굽지 않고 **게임 코드가 그린다**. PixelLab 프롬프트에 "no effects, no trails, no sparks"를 넣고, 그래도 이펙트가 끼면 그 장은 뺀다.
- 사용량은 job 기록(usage) 합계로 보고한다. 기록 파일 이름에 동작·방향·시드를 넣는다(덮어쓰기 방지).
- 사장님이 중간 확인 없이 진행하라고 하면 끝까지 만든 뒤 한 번에 보고한다.

## 1. 반복 이동 (걷기·달리기) — 모션캡처 뼈대 (1회 3)
1. 출발 그림 = 이미 쓸 만한 같은 방향 이동 그림 한 장(비율 확정본). 새로 편집하면 다리가 짧아진다.
2. `estimate-skeleton`(0.1) → CMU 모캡(`09_01` 달리기, `07_01` 걷기) 한 주기 → `retarget_x3.py`로 각도는 모캡, 뼈 길이는 캐릭터.
3. 과장은 허벅지·팔 각도·몸 숙임만(정강이 금지). 리네트 달리기 = 숙임 22°, 허벅지 1.3.
4. **무기 든 팔 고정은 주인공 전용.** 쌍검·맨손 캐릭터는 `NONE`으로 양팔을 흔든다. 모캡 팔 흔들림은 작아서 `arms_swing.py`(65°/80°)로 크게 만든다.
5. `animate-with-skeleton-v3`(12장 3).
6. 정면·뒷면: 기존 그림이 있으면 그대로 쓰고, 마무리에서 걸음마다 위아래 2~3px, 좌우 1px 출렁임을 넣는다.

## 2. 짧은 동작 (대시·맞기) — 자세 뼈대 (1회 3)
- 옆: `pose_keys.py`(몸 숙임/허벅지/무릎/팔 각도를 숫자로) → animate-with-skeleton-v3.
- 정면·뒷면: `pose_fb.py`. **발은 몸 아래 그대로**(다리 벌리면 "게다리"), 무릎 굽혀 낮추고 상체만 숙인다. 팔은 몸에 붙여 작게(크게 벌리면 T자).

## 3. 공격 (찌르기 등) — 찌른 자세 지정 (자세 10 + 애니 8)
1. 글로만 시키면 휘두르기·T자가 나온다. **찌른 자세 그림을 먼저 만든다**: 같은 방향 그림을 `edit-images-v2`(10)로 "팔 쭉 뻗고, 앞무릎 굽히고, 뒷다리 펴고".
   (`create-character-state`는 8방향을 다 만들어 25라 비싸다.)
2. 발바닥을 y=189로 맞춘 뒤 `characters/animations` v3에 `end_frame`으로 넣는다(8장 8). 방향 문구: "STRICT SIDE VIEW facing RIGHT every frame".
3. 타이밍: 앞 3~4장은 빨리 넘기고 찌른 자세를 길게 잡는다([2,1,1,2,2,2,2,1,10~18]), 회복은 7→4→0 역재생.
4. 다른 손 공격(2타)은 몸 뒤쪽 팔이라 편집이 안 먹힌다 → **1타 찌른 자세에서 뼈대로 팔만 바꿔 끼운 연타**(`swap_arms.py` + `atk2_chain.py`, 2~3).
5. 아래·위 공격: 진짜 정면·뒷면 찌르기는 읽히지 않는다. **대각선 그림(아래오른쪽/위오른쪽)을 쓰고, 마지막 좌우 방향에 따라 좌우 반전**(downl/upl).
6. 공격 흔적: `fx.py`(창 모양 빛줄기, 바늘 끝 앞쪽으로). 바늘 끝·방향은 `thrust_fx.py`가 찌른 프레임에서 자동 측정. 양손 막타는 두 줄로 크고 묵직하게.

## 4. 합치기 (PixelLab 0)
- `assemble.py`(동작별 출처·틱) → `polish.py`(방향마다 발 기준점·크기 통일, 동작마다 한 번만 이동 = 떨림 없음, 출렁임) →
  `build_atlas.py`(주인공 hero8과 같은 형식: 시트 + json) → `thrust_fx.py`(공격 흔적 데이터) → `showcase.py`(아틀라스에서 바로 재생한 영상).

## 5. 비용 감각 (리네트 실측)
- 효율 방식만 썼다면 1명 약 150~200. 리네트는 시행착오로 약 690(글로 뽑은 v1 288, 공격 실험 다수).
- 처음부터: 이동 = 뼈대, 짧은 동작 = 자세 뼈대, 공격 = 찌른 자세 지정. 한 방향 시험 → 통과하면 나머지.
