# 펠트 마을 최고의 배치 — 연구 결론 (2026-10-23)

주인 지시: "어떤 마을 배치가 가장 좋을지 연구하고 검색해서 최고의 배치를 찾아내." 대표 그림 = 그록 펠트 (주인 결정).

## 1. 기준 (조사)
- **도시 이미지 5요소 (케빈 린치 → 게임 마을)**: 길(알아보기 쉬운 큰길), 경계(벽·절벽·강으로 나뉨), 구역(구역마다 다른 개성 — "아무 데나 떨어뜨려도 어느 구역인지 아는가"), 모이는 곳(광장·갈림길), 랜드마크(탑·석상).
- **디즈니 "위니"**: 멀리 보이는 큰 랜드마크가 사람을 끌어당긴다. 계속 보이면 지루하니 가렸다 보였다(숨김과 드러냄).
- **허브 마을 (할로우 나이트 더트머스, 이스8 표류촌, 하데스)**: 작고, 들어오자마자 핵심 시설, 저장·순간이동 지점이 마을 한가운데, 이야기가 진행되면 마을이 바뀐다.
- **우리 게임 조건**: 빠른 액션 → 마을에서 오래 걷지 않게 (입구에서 시설까지 달리기 6초 안), 마을은 전투 없음, 3/4 시점 카메라라 화면에 마을의 일부만 보임.

## 2. 그록 구도 점검 (숫자, `test128/tools/hd/town_metrics.py`)
| 항목 | 결과 | 판정 |
|---|---|---|
| 길 | 분수 광장에서 방사형 + 고리 | 좋음 (막다른 칸 1개) |
| 구역 | 남 입구·작업 / 서 시장 / 북 왕성 폐허 / 북동 예배당·묘지 / 동 거미줄 | 좋음 (5구역) |
| 입구 → 시설 (달리기) | 대장간 0.4 · 이장 1.2 · 광장 2.2 · 여관 2.6 · 약초 2.7 · 잡화 3.2 · 리네트 3.3 · 폐공방 3.3 · 예배당 4.2 · 무기점 5.1초 | 전부 6초 안 |
| 이야기 한 바퀴 | 입구 → 이장 → 광장 → 리네트(북) → 예배당(북동) → 폐공방(동) → 입구 ≈ 15초, 되돌아가지 않는 시계 방향 고리 | 좋음 |
| 랜드마크가 화면에 들어오는 곳 | 왕성 16% · 예배당 12~15% · 폐공방 16% · 분수 25% | **약함** (3/4 시점은 멀리 못 봄) |

결론: 그록 구도는 그대로 최고에 가깝다. 약점은 "멀리서 보이는 랜드마크"뿐이라, 탑다운 게임에 맞는 방식으로 보완한다.

## 3. 최고의 배치 = 그록 구도 + 6가지 보완
1. **광장 분수 = 마을 저장·순간이동 비석** (넣음): 모이는 곳 + 랜드마크 + 기능을 한 곳에. 입구에서 2.2초.
2. **분수에 부서진 왕 석상 (키 큰)**: 화면에 들어오는 곳 25% → 31%. 부품 목록에 추가 요청.
3. **구역을 빛과 색으로 구분** (넣음, 코드): 남 입구 = 화로 주황 · 서 시장 = 따뜻한 등불 · 북 왕성 = 불씨 붉은빛 · 북동 예배당 = 보라 촛불 · 동 거미줄 = 창백한 푸른 안개. 최종 부품에는 구역별 강조 소품(서: 줄등·차양, 북동: 촛대·묘비, 동: 거미줄·고치, 남: 모루·장작)을 넣는다.
4. **폐공방 예고 (숨김과 드러냄)** (넣음): 광장에서 동쪽 길을 따라 거미줄 실이 점점 짙어진다. 폐공방은 광장에서 안 보이지만 실이 길을 안내한다.
5. **입구 첫 장면 = 그림 같은 장면**: 남문으로 들어서면 가스 화로 · 롬 대장간 연기 · 이장 집 · 북쪽으로 분수 석상. 첫인상을 정하는 자리라 소품·빛을 가장 공들인다.
6. **(선택) 마을에서만 카메라 조금 멀리 (0.85배)**: 랜드마크 보이는 곳 왕성 16 → 24%, 분수 25 → 33%. 마을은 전투가 없어서 가능. 주인 결정 필요.
