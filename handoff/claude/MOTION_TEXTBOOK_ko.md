> - 무엇: 「그림 한 장 → 게임에 바로 쓰는 스프라이트」 Claude/Codex 스킬 + 파이썬 도구. 길 두 개: **A 아틀라스 행**(기본 그림 1장으로 동작 줄을 그림 AI(GPT·그록)에 그리게 → 단색 배경 벗겨 진짜 투명 → 장 잘라 아틀라스 + `manifest.json` 칸 자리표), **B 영상 → 루프**(같은 그림 1장을 **그록 이매진(영상 AI)**으로 움직이게 → 실제 동작 주기에서 잘라 이음매 없는 투명 루프, 걷기는 발 엇갈림을 세어 두 걸음 한 바퀴).
> - 우리 문제와 맞는 점: ① **얼굴·몸이 장마다 안 바뀜** — 모든 장이 같은 그림 1장(B는 한 영상)에서 나옴 = 우리 「같은 그림에서 출발」 규칙과 같음. ② **AI 도트는 진짜 도트가 아님**(칸이 흔들리고 테두리가 번짐) → 「Backbone Lattice」: 동작 전체에서 칸 크기 하나를 재서 모든 장을 그 칸에 맞춤 + 동작 전체가 **같은 색표 하나**(`palette_size`, 장마다 색 깜빡임 없앰) + 정수 배율만(늘림·줄임 없음) + 1칸 눈·테두리는 「어두운 소수 색 우선」으로 살림. ③ 줄일 때는 K-Centroid(칸마다 가장 많은 색). ④ 발 기준 맞춤(`foot-centroid`): 망토·머리카락이 몸 가운데를 끌지 않게 다리로 자리 맞춤 → 장마다 좌우 떨림 없음. ⑤ **한쪽 손 소품**(우리 칼): 오른쪽 그림을 뒤집으면 칼 손이 바뀜 → 왼쪽을 따로 그리거나 「칼=오른손」 확인(handed-check). ⑥ 서기에 숨쉬기 층(Breathe)을 코드로 얹음.
> - 바로 쓸 것(크레딧 0): **몸 전체 색표 하나**(동작 하나 = 색 48개 이하 공유) + 발 기준 자리 맞춤을 우리 도구에. 시험할 것(그록 구독): 주인공 그림 1장 → 사장님이 그록 이매진으로 「달리기·공격」 영상 → mp4를 드라이브에 → 우리가 장 잘라 루프(sprite-gen B와 같은 방법). **설치함 (사장님 10-27 「설치 해라」)**: 팀장 작업 폴더 venv(세션마다 다시 설치 필요: `git clone --depth 1 https://github.com/aldegad/sprite-gen && python3 -m venv .venv && .venv/bin/pip install -e .`). 이 작업실에는 그록·codex 로그인이 없어 **그리기·영상 만들기는 안 됨** → 사장님이 그록 이매진으로 만든 mp4를 드라이브에 올리면 `video-frames`·`video-loop`로 자름(ffmpeg 있음, img2webp 없음 → GIF·스트립으로).

## 3. 얼굴 A — 정답 (**확정**, 사장님 10-29 「이게 그냥 정답이야, 다른 얼굴 교본은 다 삭제해」 → 「얼굴은 이렇게 정리하자, 교본 저장해」)

Keep the hair, shoulders, armor, colors, position and size exactly the same. No effects.`

## 1-1. 실제처럼 보이게 — 숫자로 재고 고치기 (2026-10-23, 모션연구방, 결과 `motion_lab/research_v1/`)
- **발 미끄러짐은 실제 게임 속도로 잰다**: 게임이 한 장 넘길 때 땅이 가는 거리 vs 디딘 발이 그림 안에서 뒤로 가는 거리. 1배가 정답.
  주인공은 그림 1px = 들판 30/117px, 걷기 1.37 들판px/틱 → 그림 5.3px/틱, 달리기 10.1px/틱(`game_walk.py`로 실제 게임에서 잼).
  옛 주인공은 걷기 3.7배·달리기 2배 미끄러졌음(걸음 폭이 속도에 비해 좁음). 리네트는 1배(맞음).
- 미끄러짐이 2배 넘으면 **코드(다리 빠르기)로는 못 고친다** → 걸음 폭 넓게 다시 그리고(0부 5~7 그록 영상 — 부탁 글에 「longer strides」), 남는 차이는 `gait`(walkCyc·runCyc)로 맞춤.
- 조금 미끄러지면 코드로: **박자 다시 나누기**(발이 많이 가는 장은 길게, 적게 가는 장은 짧게, `retime`) + 남은 1~3px는 장마다 좌우로 살짝(`footlock`).
- **몸 오르내림**: 걷기는 디딜 때(다리 가장 벌어짐) 내려가고 다리 모일 때 올라감, 허리 위만 움직이고 발은 땅에(`warp`). 정면·뒷면 걷기는 디딘 발 쪽으로 몸무게 ±2px(한 바퀴에 한 번).
- **서기 숨쉬기**: 가슴 위만 1px(`breathe`). 단 주인공은 게임 코드가 이미 숨쉬기를 함(`H8T.breathPx`) → 그림에 넣지 않음.
- **쓰러지기 박자**: 같은 박자 대신 비틀(느림) → 떨어짐(머리 떨어진 거리의 제곱근으로 시간, 점점 빨라짐) → 쿵(3틱) → 멈춤(길게).
- **사라진 칼**: 다른 장에 그려진 진짜 칼을 손 위치에 옮겨 붙이면 0크레딧(`sword.py`). 흐린 칼 자국은 옆 색으로 메우고 떨어진 조각은 지움.
- **땅 점검은 칼·칼집을 빼고 장화로**(`boot_bot`): 칼끝을 땅으로 잘못 맞추면 몸 전체가 17px 뜸(옛 주인공 대각선 위 걷기).
- 3/4·정면은 가까운 발이 화면에서 더 아래 → "가장 낮은 발 = 땅"으로 장마다 맞추면 몸이 출렁임. **동작 하나에 한 번** 맞추고, 그래도 뜨는 장은 머리는 두고 다리만 늘림(`stretch`).
- **들판 동료 리네트도 따로 재야 함**: 샌드박스(`linette.html`)는 1배였지만 들판(`world.js` 동료)은 한 바퀴 거리 32/46 들판px로 1.4배 미끄러졌음 → 그린 걸음 폭 × 30/117 = 23.4/32.8. 장마다 박자가 다르면 걸음 장도 박자 합으로 골라야 함(전에는 장 수로 똑같이 나눔).
- **두 캐릭터 키 비율**(10-23 사장님 89%): 방향마다 서기 키가 다름(리네트 옆 114·정면 121, 주인공 옆 122·정면 118 → 정면에서 둘이 같은 키로 보였음). 비율은 **방향마다** 상대 서기 키로 맞추고 그 방향 동작 전체에 같은 배율(`linette_motion_v2/scale89.py`).
- **칼이 동작마다 순간이동(주인공 뒷모습, 10-23)**: 서기·대시·맞기·점프는 머리 옆에 칼끝만, 걷기·달리기는 손에 칼 → 바꿀 때 칼이 튐. 칼끝은 테두리째 투명하게(머리카락 색으로 메우면 칼끝 모양 검은 덩어리가 남음), 서기는 같은 그림판의 다른 장 칼을 손에 붙임(`hero8_face_v1/upsword_apply.py`). 점검법: **같은 방향 모든 동작을 한 줄에 나란히** 놓고 칼·머리·얼굴이 같은지 본다.
- **회피대시·맞기 박자(10-23 연구)**: 회피대시는 출발 순간이 가장 빠름(outCubic: 4틱에 거리 70%) → 그런데 그림은 처음 3장이 똑바로 선 자세라 **가장 빠를 때 서 있고 거의 멈췄을 때 가장 숙임**. 서 있는 장은 1틱씩, 숙인 장을 앞으로(`dashvid.py`로 실제 거리 곡선 위에서 비교). 맞기는 맞기 전 자세가 3틱 남아 **맞고 나서 늦게 젖혀짐** → 첫 장 1틱, 가장 젖혀진 장을 2~4틱 안에, 그 장을 가장 길게, 돌아오는 장은 천천히.
- **맞을 때 돌아보기·밀려나기(10-23 게임 반영)**: 맞기 그림은 앞에서 맞은 자세(뒤로 젖힘)뿐 → 등 뒤에서 맞으면 때린 쪽으로 젖혀져 이상함 → 맞는 순간 **때린 쪽을 보게**(공격 중엔 안 돌림). 밀려나기는 1틱 순간이동 대신 **7틱 동안 줄어드는 속도로**(같은 8px).
- **점프는 땅·공중·착지로 나눈다(10-23)**: 높이 곡선(포물선)과 그림 장을 시간으로 고르게 나누면 웅크림이 공중에서, 착지 웅크림이 꼭대기 근처에서 나옴 → 그림마다 발이 땅인지 공중인지 재서 [땅 웅크림][공중][착지] 표를 만들고, 웅크림·착지는 높이 0에서만(`jump_atk_v1`). 착지 자세는 움직이면 바로 끊어 미끄러지지 않게.
- **공격 반동은 몸 전체를 밀지 말고 기울인다(10-23)**: 통째로 밀면 발이 미끄러짐 → 발을 축으로 기울이기(shear), 모으기(뒤로+눌림) → 휘두름(앞으로+늘림) → 스프링으로 멈춤(조금 지나쳤다 돌아옴). 큰 공격만 한 발 내딛기.
- 새로 그린 한 주기(PixelLab)는 장마다 위아래로 떠다님 → 위 방법으로 땅·키를 서기와 같게. 시작 그림에 칼이 등 뒤에 숨어 있으면 **칼집에 넣은 칼**로 그려짐 → 칼날 보이는 그림에서 시작 + "BARE unsheathed blade, no scabbard".
