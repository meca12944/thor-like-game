# hero_combo_new v1 (2026-10-20, 사장님 지시 · 저장만, 게임 미적용)
"주인공 공격모션 새로 그려라 — 검은 오른손, 1타 찌르기, 2타 찌른 상태에서 위로 올리기, 3타 양손 위에서 밑으로 크게 베기, 부드럽게, 크기·칼·얼굴 비율 일정"

## 방식
- 옆모습(→, ←는 반전). 각 타 15프레임(총 45장).
- 뼈대: skeleton/design.py — 게임 대기(east) 키포인트의 뼈 길이 그대로, 키프레임 자세를 각도로 정의해 보간(부드러운 ease) → 모든 프레임 비율 동일. 머리는 몸 기울기와 상관없이 앞을 봄.
- 생성: PixelLab animate-with-skeleton-v3 (skeleton/animate_skel_act.py). 1타 시작 그림 = 게임 대기 east 000, 2타 시작 = 1타 마지막 프레임, 3타 시작 = 2타 마지막 프레임 (사슬 연결 → 이음새 없음). seed 911/912/914.
- 후처리: 회색 잡티 제거, 게임 팔레트 고정, 잡점 제거, 발 y=189 (frames/).
- 비용: 16 크레딧 (3타 1회 재생성 포함).

## 메모
- 2타 끝~3타 시작은 칼 든 팔이 머리 위로 올라가며 얼굴을 잠깐 가림(자세상 자연스러움).
