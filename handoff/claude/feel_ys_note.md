## 바뀌는 것 (feel=ys일 때만)
1. **타이밍**: 프레임 틱 다시 배분 (프레임 순서와 접촉 프레임은 그대로)
   - 접촉 전: 초반 프레임 1~2틱 → 예비 정점에서 멈춤(나머지 틱 전부, 3틱 이상) → 스미어 1틱
   - 접촉 후: 접촉 프레임을 남은 시간의 약 40% 동안 유지, 나머지는 고르게
   - 연타 길이 14/18/27 → **16/20/30틱**, 타격 틱 5/6/9 → **7/8/12**, 캔슬 13/16/25
2. **히트스톱**: 일반 4 → **6틱**, 피니시 9 → **11틱**
3. **전진**: 9/11/14 → **18/22/32px**. 처음부터 끌던 방식에서, 타격 직전 3틱부터 몰아서 미는 방식으로 바꿨다
4. **흔들림**: 일반 타격 [0,0] → **[1px, 0.06s]**, 막타 [2, 0.10], 피니시 [2, 0.12]. 메뉴의 '화면 흔들림' 옵션(끔/약/보통)을 그대로 따른다
   - 주의: 예전에 멀미 피드백으로 일반 타격 흔들림을 껐던 이력이 있다
5. **적 번쩍임**: 0.16 → **0.22초**
6. **타격 이펙트**: 맞은 자리에 흰 링 + 흰·청록·금색 불꽃 파편

## 코드 변경 (test128/index.html, 정확한 치환 6곳)
1. `/*/H8*/` 바로 뒤에 `FEELYS` 블록을 추가했다. 이 블록이 H8.combo, 각 hit 클립의 틱, H8.lunge를 덮어쓴다.
2. `deathTicks:110,\n};` 뒤에 `if(FEELYS){FEEL.hitStopMin=6;FEEL.hitStopFin=11;Object.assign(FEEL.shake,{hit:[1,.06],fin:[2,.10],finisher:[2,.12]});}`
3. 전진 공식: 시작 시점을 `w0=max(0,s.a0-tk(3))`로 바꾸고, `[w0,a1]` 구간에서 감속하며 밀도록 했다.
4. 타격 흔들림: `(s.fin?'fin':0)` → `(s.fin?'fin':FEELYS?'hit':0)`
5. `m.flash=.16` → `m.flash=FEELYS?.22:.16`
6. `hitFeel()` 맨 앞에 FEELYS일 때 `spawnRing` + `burst`를 넣었다.
