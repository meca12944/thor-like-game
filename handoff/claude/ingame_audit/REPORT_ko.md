# 인게임 점검 (2026-10-23) — 최적화 · 주인공 모션 · 회피 길이

주인 지시: "인게임 최적화가 안 되어 있다. 주인공 모션도 최신이 아니고 회피 이동 길이도 예전 것 같다. 전부 조사·연구해서 왜 그런지".
실제 주소(main a01e4d72, PR #94 모션연구방 포함)가 main과 같은지 파일을 비교해 확인함 → 사이트 올리기 문제는 아님.

## 1. 최적화 — 들판에서 숨은 마을 화면을 계속 그림
- 측정(`perf.py`, `prof2.py`): 들판 프레임 시간의 **46%**가 `index.html present()` = 들판 화면 뒤에 가려진 **마을 화면을 매 프레임 그리는 일**.
  - 마을 루프(`frame()`)가 들판·던전에 있을 때도 멈추지 않고 `render()`를 부름.
- 고침(브랜치): 들판·던전 화면이 떠 있으면 마을 그리기를 건너뜀 (`index.html` frame 한 줄).

| 장면 | 보통 PC 전→후 | 느린 PC(4배 느리게) 전→후 |
|---|---|---|
| 들판 | 46 → **60** fps | 8 → **21** fps |
| 펠트 마을 | 46 → **60** fps | 10 → **36** fps |
| 시작 마을 | 60 → 59 (그대로) | 16 → 14 (그대로) |
- 들판 → 마을 돌아오기, 마을에서 방향키 확인.
- 그 밖: 처음 열 때 18~23MB(대부분 배경음악 3MB짜리, 주인공 그림 1.4MB). 배경음악을 필요할 때 받기로 바꾸면 처음 여는 시간이 줄어듦(다음 후보).
