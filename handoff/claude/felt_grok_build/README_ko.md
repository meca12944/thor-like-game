## 자리 잡기
건물은 그록 크기의 0.7배(한 장 최대 400px 제한)라서, **자리 간격도 0.7배**로 줄이면 그록 그림과 같은 빽빽함이 된다:
월드 px = grok_foot × 0.8 × 0.7 = grok_foot × 0.56 → 맵 약 54×30칸 (지금 펠트 56×38과 비슷).
3번방 구도 판(×0.8, 76×43)에 그대로 세우면 건물 사이가 비어 보인다.

## 만든 방법 (다시 할 때)
1. `shapes.py` — 그록 원본 좌표로 건물마다 실루엣 다각형 (지붕 위 땅이 섞이지 않게 건물 안쪽으로 좁게)
2. `gen.py <id..> --var p|q` — 그록 조각(다각형 밖 투명)을 init_image(세기 300)로, `map-objects` low top-down + 마을 색. 1개 = 1크레딧
   - init 세기 600은 그록을 흐리게 베낄 뿐이라 버림. 투명 틀 없이 넣으면 둘레 땅까지 그림.
   - `PALFILE=palette_30_nofire.png`(불빛 2색 뺌) → 창문 금색 반짝이 줄어듦. q판은 이것.
   - `gen.py --text <id..>` — 소품은 글자+색만 (투명 배경)
3. `pack.py` — 틀 밖 지우기 + 손질 틀(TRIM)로 남은 땅 지우기 → `final/`
   - PixelLab remove-background 는 건물을 잘라 먹어 쓰지 않음.
   - 리네트 공방 = felt_hd atelier_v2 를 init 으로 마을 색 다시 그림(1). 주민 집(bl_house)·등불·화로·수레·상자 = felt_hd 그림을 마을 색으로 다시 칠함(무료).
