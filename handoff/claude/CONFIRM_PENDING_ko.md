# 사장님 컨펌 모음 (팀장, 2026-10-25) — A 전부 확정

> 사장님 10-25 「어 전부 진행해, 컨펌 안 된 거 따로 모아서 전달해 줘」.
> 아래 「진행 중」은 팀장 추천대로 이미 진행하고 있어요. 아니면 말씀만 해 주세요. 「사장님이 정해 주실 것」은 답을 받기 전까지 손대지 않아요.
> 답을 받으면 팀 회의 교본에 옮기고 이 목록에서 지워요.

## A. 사장님 결정 (10-25 「전부 팀장 추천대로 컨펌해」「핵심 자세부터 다시 그려라」) — 확정
| # | 무엇 | 확정 |
|---|---|---|
| A1 | 배수진·심연의 힘 | **「배수진」 하나로**: 켜지는 길 둘(장비 마모 80%↑ / 체력 25%↓), 켜지면 가슴 코어 핏빛. 코드는 마모 ②단계 때 |
| A2 | 왕비 기네비어 모습·장면 | 그록 그림 부탁 때 같이 정함 |
| A3 | 불쾌하지 않고 재밌는 것 | **토비의 숯 낙서 찾기** (펠트 벽 낙서 5개 → 작은 선물) |
| A4 | 롬·세라 | **1장에서 뺌** (대장간 = 고물 수리점 + 2장 카일라, 약초 = 마르타 정화제) |
| A5 | 고물 수리점 물건 | 수리 망치(비싸게 1개)·버려진 부품·숫돌 낱개·정화제, 마모 ②단계 때 |
| A6 | CG 일본풍·기억 조각 메뉴 | 1장 큰 장면 그림이 모인 뒤 정함 |
| A7 | 새 주인공 옆 인물 크기 | 리네트 먼저(주인공 키 89%) → 대화 많은 인물 → 나머지, 토비 작게 |
| A8 | turn-fx | 엘든링식 속도 들어간 뒤 다시 보고 정함 |
| A9 | 얼굴 앞머리 | 1~2칸만 걷기, 살색 넓이 ±10% 지킴 |
| A10 | 새 주인공 남은 동작 | **핵심 자세 방식 (약 300~330크레딧)** — 사장님 「핵심 자세부터 다시 그려라」 |
