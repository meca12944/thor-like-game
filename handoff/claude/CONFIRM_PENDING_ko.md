# 사장님 컨펌이 필요한 것 모음 (팀장, 2026-10-25)

> 사장님 10-25 「어 전부 진행해, 컨펌 안 된 거 따로 모아서 전달해 줘」.
> 아래 「진행 중」은 팀장 추천대로 이미 진행하고 있어요. 아니면 말씀만 해 주세요. 「사장님이 정해 주실 것」은 답을 받기 전까지 손대지 않아요.
> 답을 받으면 팀 회의 교본에 옮기고 이 목록에서 지워요.

## A. 사장님이 정해 주실 것 (진행 안 함)
| # | 무엇 | 팀 안 | 팀장 추천 |
|---|---|---|---|
| A1 | **배수진과 심연의 힘을 하나로 합칠까요?** (몰리면 세지는 힘) | 스토리: 「배수진」 하나로, 켜지는 길 둘(장비 닳음 80% 이상 / 체력 25% 이하), 켜지면 가슴 코어가 핏빛 · UI: 둘을 따로 둠 | **하나로 합치기** — 이름이 하나라 헷갈리지 않고, 코어가 핏빛으로 바뀌는 이야기와 이어져요 |
| A2 | **왕비 기네비어의 모습과 나오는 장면** | 지어내지 않고 사장님 자료를 기다려요 | 그록에게 그림을 부탁할 때 같이 정하기 |
| A3 | **"불쾌하지 않고 재밌는 것 하나"가 무엇인지** | 스토리: 토비의 숯 낙서 찾기(펠트 벽 낙서 5개를 찾으면 토비가 웃으며 작은 선물) | 토비 낙서 찾기 |
| A4 | **롬(대장간)·세라(약초)를 1장 인물에서 뺄까요?** | 스토리: 빼기 — 대장간 = 고물 수리점 + 2장 카일라, 약초 = 마르타의 정화제 | 빼기 |
| A5 | **고물 수리점에서 파는 물건** | UI: 수리 망치(비싸게 1개)·버려진 부품·숫돌 낱개·정화제 | UI 안대로, 마모 ②단계 때 확정 |
| A6 | **이야기 그림(CG)을 일본풍으로 할지, 「기억 조각」 메뉴를 넣을지** | 아직 정해지지 않음 | 1장 큰 장면 그림이 모인 뒤 정하기 |
| A7 | **새 주인공 옆에 설 인물들 크기** | UI: 리네트 먼저(주인공 키의 89%) → 대화 많은 인물 → 나머지, 토비는 작게 | UI 안대로 |
| A8 | **예전 방향 꺾기 효과(turn-fx)를 넣을지** | 시험 가지에만 있어요 | 엘든링식 속도에서 다시 보고 정하기 |
