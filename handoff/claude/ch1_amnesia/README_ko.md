# 1장 주인공 = 기억 없음 — 바뀐 글 전·후 (스토리 3번방, 2026-10-25)

사장님 10-25: 「그록이 한 거 그대로 냅둬. 스토리상 주인공은 기억이 없어진 상황이야. 대사가 이미 너무 잘 알고 있는 대사야.」
→ 주인공 말·지명 글만 고침. 그록 지도·그림·조사 글(잿더미·장검·돌에 그은 줄·배낭·발자국·이정표 「펠트 서문 →」)은 그대로.
영상: `amnesia_pc.mp4` (PC 1280×720, 깨끗한 저장: 깨어남 → 언덕 전망 → 마을 처음 → 바르트 → 들판 처음 = 이름).

## A. 주인공 대사 (`test128/maps/dialog_ch1.json`, `world.js` INTRO.line)
| 자리 | 전 | 후 |
|---|---|---|
| 무덤가 깨어남 | ...또다시 이 무덤가인가. 몇 번째 반복인지 이제 세지도 않았다. | ……여긴… 어디지. / (가슴 한가운데가 푸르게 욱신거린다.) / 이름이… 생각나지 않는다. |
| 마을 처음 | 끝나지 않는 악몽이네. / (…불탄 왕도가 보인다.) / …또 이 냄새다. 실 타는 냄새. | (…불탄 거대한 성이 보인다.) / ……사람이 사는 곳인가. / 타는 냄새… 처음 맡는 냄새인데, 낯설지가 않다. |
| 들판 처음 | 내가 남긴 찌꺼기가… 아직도 여기 있군. | …손이 먼저 칼자루를 찾는다. |
| 폐공방 1층 | 누군가 아직도 옷을 짓고 있군. 30년 동안. | …누가 돌리고 있는 거지. |
| 바르트 (보스 뒤) | 이름 같은 건 없다. | 이름은… 기억나지 않는다. |
| 오스왈드 | 신은 대답 안 한다. | …신 같은 건 모른다. |

그대로 둔 것: 아라크네 앞 「기억 안 난다」, 보스 뒤 「기억이 하나 돌아왔다」(여기부터 기억 조각), 리네트·토비·루카 한마디.

## B. 지명 (UI 장치 `maps/place_names.json` 채움 — 그록 지도 글은 그대로, 화면에 그릴 때만 바뀜)
배우는 때: 바르트 첫 대화(`talk:f_bart`, 왕도·잿빛 들판·펠트를 처음 말해 줌) 또는 아라크네 뒤 기억 조각(`scene:boss_post:arachne`). 대화창 글은 안 바뀜.
긴 문장을 먼저 넣어 「성벽 아래 마을 마을」처럼 겹치지 않게 함.

| 잿빛 들판 / 저 성벽 너머, 펠트 — 그리고 왕성 (언덕 전망) | 재로 덮인 들 / 그 너머 높은 성벽 — 그리고 거대한 성 |

그록 조사 글에서 낱말 둘만 직접 고침 (대화창이라 장치가 안 닿음): 「왕도의 옛 성문」→「거대한 옛 성문」, 「폐허가 된 왕도 쪽 길」→「폐허가 된 성 쪽 길」.
남은 것 (UI): 메뉴(HTML) 「펠트로 돌아가기」는 textOut 밖이라 안 바뀜.
