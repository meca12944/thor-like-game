# 주인공 "칼 없는 몸" (C안, 사장님 10-24 「C안으로 가자」)

평소에는 칼 든 그림 그대로, 벨 때(검기 0~4틱)만 이 그림으로 바꿔 끼우고, 효과 담당이 코드로 칼날을 그 손에서 휘두른다.

- 크레딧 0. PixelLab 안 씀. 지금 게임 그림(서기·걷기·달리기 × right·dr·down·up·n = 15동작 122장)에서 칼만 지움.
- 지우는 법 `ns.py`: 밝은 회색 칼날 찾기 → 직선 맞추기 → 칼날 띠(테두리 포함) + 날밑·칼자루(갈색, 살색은 남김) 지움 → 칼이 몸 위를 지나던 자리만 이웃 색 가운데값으로 메움 → 칼 둘레에 남은 가는 줄·부스러기 지움.
- 동작·장마다 눈으로 보고 고른 값: `cfg.py` (run_right 망토 메우기, run_up 손 쪽 어두운 칼날, walk_right 3·7장 칼에 가려졌던 정강이).
- 게임 넣기 `apply_nosword.py` → `test128/assets/anim/hero8_nosword.webp` + H8 anim `<이름>_ns` (칸 수·박자·앵커 같음 = 크기·위치 그대로)
  + `H8.grip[<이름>][i] = [dx, dy, 각도]` 칼 쥔 손(발 앵커 128,189 기준 그림px), 칼이 가리키던 방향(오른쪽 0°, 아래 +). 왼쪽은 뒤집기(dx, 각도 거울).
- 확인: `sheet_ns.py` → `motion_lab/research_v1/hero8/nosword_sheet.png` (위 = 지금, 아래 = 칼 없음), 장별 그림 `motion_lab/research_v1/hero8/nosword/`, 숫자 `stats.json`.
- 숫자(10-24): 122장, 지운 칸 45,138 (장마다 142~494), 메운 칸 1,972, 몸 칸 94.0%는 한 칸도 안 바뀜.
