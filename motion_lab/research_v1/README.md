- 주인공: 아틀라스 `/*H8*/`의 walk/run 3방향을 새 그림으로, `H8.gait` **walkCyc 155→112, runCyc 228→174**(다리 1.4배·1.3배 빠르게 = 발 미끄러짐 1배).

- 주인공 서기 숨쉬기는 게임 코드(`H8T.breathPx`)에 이미 있어서 넣지 않음.
