# 모션 연구방 (사장님 2026-10-23 "모션연구방 하나 열어서 모션만 연구하게 세팅해")

이 방은 **모션(캐릭터 움직임)만 연구**한다. 게임 코드·몹·밸런스·맵은 다루지 않는다.

## 재료: 지금 완성된 최종본만
| 폴더 | 내용 |
|---|---|
| `hero8/` | 주인공(망토, 게임에서 쓰는 hero8) 최종 모션 24개 |
| `linette/` | 리네트 최종 모션 64개 |

- `frames/<동작>_<방향>/000.png …` — 장마다 256×256, 발 기준점 (128,189). 게임 그림 그대로(크기·위치 맞춤 끝난 것).
- `clips.json` — 동작마다 장 수와 장마다 틱(60틱 = 1초).
- `sheet.png` — 모든 동작 첫 장, `preview.mp4` — 모든 동작이 게임 속도로 움직이는 영상.
- 원본(게임이 실제로 읽는 파일): 주인공 `test128/index.html`의 `/*H8*/` 아틀라스 + `test128/assets/anim/hero8_*.webp`, 리네트 `test128/assets/anim/linette8.json` + `linette8_*.webp`. 여기 `motion_lab/`은 연구용 복사본이다(2026-10-23 main 기준).

### 방향 이름
- 주인공: `right` 옆(→, ←는 게임이 좌우 반전), `down` 똑바른 정면(↓), `up` 비스듬한 뒷모습(↑). 대각선 입력은 이 그림들을 씀.
- 리네트: `right`/`left` 옆, `south` 정면(↓), `north` 뒷면(↑), `down` ↘ · `downl` ↙ · `up` ↗ · `upl` ↖ 대각선.

### 뺀 것 (게임에서 안 쓰는 동작)
- 주인공 칼 베기 몸동작(`hit1~3`, `rec1~2`, `hold`) — 공격은 몸동작 없이 검기만 코드로 그린다.
- 주인공 `_left` 동작 — 게임은 오른쪽을 좌우 반전해서 쓴다.
- 리네트 `atk1~3` — 공격은 몸동작 없이 검흔만, 이 동작들은 바늘 끝 위치 데이터로만 쓴다.

## 이 방의 규칙
1. **모션 교과서 하나만**: `handoff/claude/MOTION_TEXTBOOK_ko.md`. 작업 전에 읽고, 새로 배운 것은 거기에만 적는다(0부 교본, 1부 1-0 규칙).
2. 그리기·고치기 전에 **모습(정면/비스듬/옆) 확인**, **이미 만든 그림 먼저 찾기**.
3. 다듬은 것은 **전·후 비교 영상(MP4) 먼저** 보여 주고 사장님 OK 뒤에만 넣는다. 게임(main) 반영은 허락 뒤 브랜치 → PR.
4. 크기·위치는 동작 하나에 한 번만, 수정 전후 **움직임 숫자 비교**(`tools/anim/motioncheck/audit2.py`, `board.py`).
5. PixelLab 키는 `$PIXELLAB_API_KEY`만, 작업마다 쓴 크레딧 보고. 이펙트는 그림에 굽지 않는다.
6. 사장님께는 초등학생도 알아듣게, 채팅은 무조건 한글, 결과는 MP4/이미지로.
