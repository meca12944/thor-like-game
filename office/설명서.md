# 클로드 회사 — 설명서

사장님 PC 바탕화면에서 켜는 **업무 게시판**이에요.
직원(클로드)들에게 일을 시키고, 보고·영상·허락 요청을 **한 화면**에서 받아요.

## 한 번만 하는 설치 (윈도우)
1. 이 `office` 폴더를 PC의 아무 곳에나 둬요 (예: `문서\클로드회사`).
2. **`처음_설치.bat`** 을 두 번 눌러요. 필요한 프로그램(Node.js, Git, 클로드 코드)을 깔고, 게임 폴더를 받고, 바탕화면 아이콘을 만들어요.
3. 마지막에 열리는 파란 창에서 **클로드 코드에 로그인**해요 (지금 쓰는 구독 계정). 로그인이 끝나면 그 창은 닫아요.
4. 바탕화면의 **「클로드 회사」** 아이콘을 두 번 눌러요.

> 돈: 직원(클로드)은 **지금 구독 안에서** 일해요. 추가로 돈이 드는 건 그록 터널(키를 넣었을 때)뿐이에요.

## 처음 켰을 때
1. 오른쪽 위 **설정** → 「게임 원본 폴더」가 맞는지 봐요 (보통 `C:\Users\이름\thor-like-game`).
2. 왼쪽 **「기본 팀 만들기」** → 팀장·UI·스토리·몬스터·효과·모션·**AI협력팀** 7명이 생겨요.
   - 직원마다 **따로 쓰는 작업 공간**이 생겨서 서로 파일이 엉키지 않아요.
3. 아래 명령창에 할 일을 적고 **일 시키기** (보통 **팀장**에게). 팀장이 알아서 직원들에게 나눠요.

## 화면 보는 법
| 자리 | 뜻 |
|---|---|
| 위 노란 칸 「해도 될까요?」 | 직원이 허락을 구하는 것. **항상 허락**을 누르면 다음부터 모든 직원이 다시 안 물어요 |
| 왼쪽 직원 카드 | 쉬는 중 / 일하는 중(지금 하는 일) / 허락 기다림 / 문제 |
| 보고함 「사장님께」 | 사장님이 꼭 볼 보고만 |
| 보고함 「직원끼리」 | 직원들이 서로 주고받은 말 (사장님이 말을 옮길 필요 없음) |
| 보고함 「그록 터널」 | AI협력팀과 그록이 실시간으로 주고받은 말·그림·영상 |
| 「작업 보기」 | 그 직원이 지금 무엇을 하는지 실시간으로 |
| 「폴더 확인」 | AI협력팀이 그록 폴더를 확인하고 보고 |

## 허락 (묻는 횟수 줄이기)
- 기본은 **「알아서」**: 안전한 일은 묻지 않고, 애매한 것만 노란 칸으로 물어요.
- **「항상 허락」을 한 번 누르면 기억**해요 (`허락 목록`에서 보고 지울 수 있어요).
- 정말 아무것도 묻지 않게 하려면 직원 ⋯ → 고치기 → 허락 방식 「전부 허락」 (조심해서 쓰기).

## AI협력팀 · 그록 터널
- **그록 터널(실시간)**: 설정 → 「그록 키」에 xAI 키(console.x.ai에서 만듦)를 넣으면, AI협력팀이 그록에게 **직접** 묻고 그림·영상을 받아요. 사장님이 복사·붙여넣기 할 필요가 없어요.
  - 돈: 그림 1장 약 $0.04, 영상 1초 약 $0.08. **하루 한도**(기본 $5)를 넘으면 멈춰요.
  - 키는 이 PC의 `data` 폴더에만 있고, AI협력팀에게만 주어져요. 채팅에 키를 붙여 넣지 마세요.
- **그록 폴더**: 「Google Drive 데스크톱」을 깔면 드라이브 폴더가 PC 폴더로 보여요. 설정 → 「그록 폴더」에 그 경로를 넣으면, 새 파일이 올 때 AI협력팀이 **저절로** 확인해서 보고해요.
- 키가 없으면 예전처럼 드라이브 폴더 + 「붙여넣기 글 복사」 단추로 해요.

## 끄기 · 문제가 생기면
- 끄기: 설정 → 「회사 문 닫기」. (창만 닫으면 본체는 뒤에서 계속 일해요)
- 「클로드 코드를 못 찾았어요」: `처음_설치.bat` 을 다시 하고 PC를 다시 켜요.
- 「로그인이 안 되어 있어요」: 명령 프롬프트에서 `claude` 를 실행해 로그인해요.
- 기록: `data\server.log`, 직원별 기록 `data\logs\`.
