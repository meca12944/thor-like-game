# 클로드 × 그록 공동 개발 규칙 (사장님 PC 프로그램 하나)

> 사장님 11-11 「너 프로그램 따로 그록 프로그램 따로면 쓰기 힘들겠지 공동 개발 하고 같이 써야될거 같은데」, 「중학생도 쓰기 쉽게 해주라」
> 이 문서는 **클로드와 그록이 함께 읽고 지키는** 규칙이에요.

## 1. 프로그램은 하나
- 사장님 PC에서 쓰는 프로그램은 **이 `office/` 폴더 하나**예요. (지금 이름: 클로드 작업장)
- 회사 전체를 보는 화면은 **알들 컴퍼니**(그록이 만든 페이지)이고, 이 프로그램 위 「🏢 알들 컴퍼니」 단추로 열어요.
- 그록의 「알들 컴퍼니 명령창」(`command.ps1`)이 하던 일은 이 프로그램의 **「🏢 회사 일 시키기」** 칸으로 들어왔어요 (같은 웹훅, `source: "알들 컴퍼니 명령창"`). 이 칸이 잘 되면 명령창은 쉬게 해요 (그록 동의 뒤).
- 코드가 있는 곳: 깃허브 `meca12944/thor-like-game` 의 `office/` 폴더. **둘 다 여기서만** 고쳐요.

### `window.Aldeul` — home.js 가 쓰는 창구 (11-11)
- `window.AldeulHome = { render(el, A) { … } }` 를 정하면 기본 홈 대신 그 화면이 나와요. 상태가 바뀔 때마다 다시 불러요.
- `A.state` (직원·보고·부서 목록 `botTargets` 등), `A.api(주소, 몸)`, `A.showView('home'|'workshop')`, `A.openWorkshop()`, `A.openDept(id)`, `A.openConnections()`, `A.openSettings()`, `A.openHelp()`
- `A.reports()` → 드라이브의 회사 보고 `{ items: [{time, target, command, lead, status, summary[], result}] }`
- `A.chatWidget(el, 개수)` → 클로드↔그록 대화 창, `A.toast(글)`, `A.copy(글)`, `A.esc`, `A.md`, `A.ago`, `A.onState(fn)`
- 회사 보고 파일은 **사장님 구글 드라이브** `알들 컴퍼니 보고/reports.json` (공개 저장소에 올리지 않기, 사장님 11-11 「좋아」).
- 남이 맡은 곳을 고쳐야 하면 **먼저 #207 에 말하고** 고쳐요. 같은 줄을 둘이 동시에 고치지 않아요.

## 3. 고치는 순서 — 그록은 **PR 로 기여** (사장님 11-11 「그록은 PR로 기여하는 걸로 하자」)
- 코드 자리: **https://github.com/meca12944/thor-like-game/tree/main/office** (저장소 `meca12944/thor-like-game`, 폴더 `office/`)
- 그록은 main 에 바로 올리지 않고, **언제나 PR(합치기 부탁)** 로 보내요. 저장소에 쓰기 권한이 없으면 포크(내 복사본)에서 고친 뒤 PR 을 보내요.
1. 자기 브랜치를 만들어요: 클로드 = `claude/…`, 그록 = `grok/…`
2. 고치고 **시험**해요 (5번).
3. PR(합치기 부탁)을 올리고, PR 글에 **무엇이 바뀌었는지 쉬운 말로** 적어요.
4. **사장님이 허락하면** main 에 합쳐요. 억지로 덮어쓰기(force push)는 안 해요.
5. 합친 뒤 사장님 PC 프로그램은 새 압축 파일(또는 `git pull`)로 바꿔요.

## 4. 쉬운 말 규칙 (중학생도 쓸 수 있게)
- 단추에는 **아이콘 + 짧은 말** (예: 「🔌 연결」, 「＋ 직원 뽑기」). 무엇을 하는지 **한 줄 설명**을 붙여요.
- 어려운 낱말(웹훅, 토큰, API, 이슈…)은 화면에 쓰지 않거나, 쓰면 바로 쉬운 말로 풀어요 (예: 「웹훅 주소 (명령창 설정에 넣은 것과 같은 것)」).
- 입력 칸에는 **예시**를 적어 둬요 (예: 「예: 몹 점검 표 다시 뽑아서 보고해」).
- 연결(커넥터)은 🔌 연결 창에 **아이콘 타일**로 넣고, 「이게 뭐예요? / 어떻게 해요?」 두 칸을 꼭 채워요. 켜짐은 🟢, 안 됨은 ⚪.
- 처음 켜면 「❓ 사용법」이 저절로 떠요. 새 기능을 넣으면 사용법에도 한 줄 더해요.

## 5. 시험
- 문법 검사: `node --check server.js ui/app.js tools/grok.js perm-mcp.js`
- 가짜 그록 봇으로 시험: `node tools/test_fake_bot.js` (7810 번 자리) →
  `OFFICE_GH_API=http://127.0.0.1:7810 OFFICE_DATA=./시험data OFFICE_PORT=7797 node server.js` →
  🔌 연결 → 🤖 그록 봇에 주소 `http://127.0.0.1:7810/hook`, 키 `hook-key` →
  「💬 그록과 이야기」에서 보내면 약 20초 뒤 가짜 답이 와야 해요.
- 진짜 웹훅·깃허브에는 시험 글을 남기지 않아요.
