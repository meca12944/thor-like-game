# 2번 마을 배치 컨셉 — B 강변 물레방아 마을

> 컨셉 문서. 실제 맵은 팀장 담당이고, 게임 코드나 에셋은 바꾸지 않았다.

## 왜 B가 2번 마을인가
- TOWNS.md의 「진행 순서」 표: 프롤로그는 A 시작 마을, 1지역 클리어 후 첫 거점이 **B → H**.
- data/towns.json B.arrival: "1지역 시작의 숲 보스(이끼 수정 골렘) 격파 후. 서쪽 광산 마을 H와 2지역 수정 동굴로 가는 관문."
- BGM `town_b_watermill`, 배경 컨셉 `docs_art/bg_concept/town_B.png`.
- **현재 맵 없음**: town/maps/world.json에서 townB 노드는 `scene: null, locked: true`. town/maps/에는 field00/01, dungeon01, boss01뿐이고, 구현된 마을은 A(town_a.js)뿐.

## 테마
강 위에 떠 있는 듯한 수상 마을. 커다란 물레방아와 방앗간, 나무다리, 부두와 나룻배, 낚시꾼. 맑은 낮이고 수련이 뜬 강이다. 강화는 +3까지 된다.

## 출입구와 동선
- **서쪽 길** → H 서쪽 광산 마을 → 2지역 수정 동굴 (메인 진행 방향)
- **동쪽 길** (⑧ 광장) → A 시작 마을 (9화면) / 1지역 시작의 숲. 첫 도착 시 들어오는 입구.
- **북쪽 길** (⑩ 돌다리) → C 설산 산장 마을 (후반에 개방)
- **남쪽 강** (⑬ 나룻배) → 하류 선착장 (B2 호위, 강 이동)
- 주요 동선: 동쪽 입구 → ⑧ 광장 → ⑨ 큰 다리 → 서안 상점가 ①②③ → 서쪽 출구. 다리 남쪽 부두 길로 ⑬⑭⑮에 닿는다.
- 폐허판(마왕의 길) 「무너진 물레방아」: ④가 부서지고 ⑨가 끊긴다. 잿더미 상인은 ④ 자리에 선다. 대피는 ⑬ 나룻배로 강을 건넌다.
