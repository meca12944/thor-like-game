# SFX 목록

## A. 게임에 이미 있는 SFX (사용 중)
`town/index.html` 의 `SFX_DATA` (base64 ogg 내장), `SFX.play()` 로 호출 (index.html, world.js). 수정하지 않음.

| key | 설명 | 상태 |
|---|---|---|
| `swing_light` | 검 약공격 휘두르기 | 사용 중 |
| `swing_heavy` | 강공격/피니시 휘두르기 | 사용 중 |
| `hit_light` | 일반 타격 | 사용 중 |
| `hit_heavy` | 강타격 | 사용 중 |
| `hit_crit` | 크리티컬 | 사용 중 |
| `kill` | 적 처치 | 사용 중 |
| `spin_dark` | 타이틀 회전베기(어둠) | 사용 중 |
| `wave` | 검기/웨이브 | 사용 중 |
| `ult_cutin` | 궁극기 컷인 | 사용 중 |
| `ult_boom` | 궁극기 폭발 | 사용 중 |

## B. 빠진 SFX → 초안 제작 (`docs_music/sfx_draft/`)
느낌 목표: 이스 VIII 같은 짧고 펀치 있는 타격감(빠른 어택, 저역 바디 + 고역 크랙, 짧은 꼬리). **v5 (전면 재제작)**: 사장님 피드백(기계적·가벼움)에 따라 51개 전부를 **실제 녹음된 CC0 소스**(Kenney.nl Impact Sounds / RPG Audio / Interface Sounds / UI Audio / Sci-fi Sounds — 모두 CC0 1.0) 레이어로 다시 만들었습니다. 가공: 피치 다운/업(리샘플), 하이/로우패스, 엔벨로프, 레이어링. 합성은 일부 타격의 서브베이스 보강에만 사용.
