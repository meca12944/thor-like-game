# 세계 이름표 — 장소 · 장비 · 아이템 · 능력 (「필멸자」 개편 제안)

> 대상: 마을·지역·던전, 장비 전체(무기·방어구·보조무기·숨은 검·마왕 장비), 소모품·열쇠·재료·성장 아이템, 능력·마법·필살기·흡수 능력.
> 원칙: ① 엘든링 고유명사(룬, 황금나무, 빛바랜 자, 성배병, 축복, 기억의 결정 등)를 쓰지 않는다. ② 「칭호 + 고유명」이나 「출처가 보이는 이름」으로 짓는다. 어느 보스·장인·마을에서 나왔는지 이름만 보고 알 수 있게 한다. ③ 새 스토리(억겁의 불사자, 낙인, 굳은 혼, 요람의 샘, 원탁)와 잇는다. ④ 「정령」과 「목 베기」 표현은 쓰지 않는다. ⑤ ID는 그대로 두고 표시 이름만 바꾼다(세이브 호환).
> 표시: **확정** = 사장님 확정 · **유지** = 기존 이름이 이미 톤에 맞음 · 표시 없음 = 제안(승인 대기).

### 재료
- **금속 주괴**: 철 주괴 · 강철 주괴 · 흑철 주괴 (**유지**) · 미스릴 주괴 → **백은 주괴**
- **보스 핵 (11)**: 「(보스 칭호)의 굳은 혼」으로 통일한다. 예: 이끼 수정 골렘의 핵 → 초록손의 굳은 혼, 흑기사의 업화 핵 → 모르반의 흑염 혼, 대사제의 공허 핵 → 오르비스의 공허 혼, 마룡의 삼두 핵 → 세 머리의 굳은 혼. 「굳은 혼만 흡수한다」는 규칙이 아이템 이름에서도 보인다
- **「정령」이 들어간 재료 (단어 정리)**: 정령 새싹 가지 → 이끼 새싹 가지 · 파도 정령 물방울 → 파도 망령의 물방울 · 모래 정령 가루 → 모래 망령 가루
- **타락 재료 접두어 (`x_`)**: 「타락한 ○○」 → 「검게 물든 ○○」. 칭호 「타락한 필멸자」와 겹치지 않게 한다
