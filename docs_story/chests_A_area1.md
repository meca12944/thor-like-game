# 상자 설정안 — 시작 마을 A + 1지역

> 게임용 데이터: `chests_A_area1.json`. 1지역 좌표는 `town/maps/*.json` 타일 좌표(x,y). **마을 A는 한 화면을 넘는 넓은 맵이라 좌표 없이 「구역 — 장소의 느낌」으로 적음** (구역: 중앙 분수 광장 / 동쪽 장인 거리 / 서쪽 밭 / 북쪽 언덕 주거 구역 / 남문).
> 능력 출처: 대지의 수정=1지역 보스, 수정 실=2지역, 사중 잠행=3지역, 해류의 숨결(잠수·물 위 걷기)=5지역 (WORLD_PLAN.md, SYSTEMS.md).
