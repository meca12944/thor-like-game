## 부록 4 — 회상 장과 본편 연결

| 회상 | 내용 | 본편에서 이어지는 곳 |
|---|---|---|
| Ⅰ 「베지 마라」 | 전쟁고아 아스란, 반으로 나눈 빵, 피의 맹세(다시 태어나는 힘은 나눌 수 없음) | 4장 기억 홍수 직후. 최종장 「배고플 때만 사냥한다」, 마왕 루트에서 먹어도 배부르지 않은 기억 |
| Ⅱ 「세 조각의 칼」 | 첨탑의 서른아홉 명단(맨 위 스승, 맨 아래 아스란), 「나는 다르지 않았다」, 칼을 셋으로 나눔 | 6장 직후. 7장 볼칸의 가문 일지, 8장 찢긴 일지와 필압 |
| Ⅲ 「절벽」 | 「나는 필멸자로 살겠다」, 명단 찢기, 결박·요람·처형인 칼, 서른일곱 줄, 가면 | 숨은 장 직후. 숨은 장 명단의 날짜와 떨리는 획, 최종장 옥좌의 위치 |
| 씨앗 | 회상 Ⅰ 「가슴의 작은 온기」, 회상 Ⅱ 「아무리 끝내도 다시 피어나는 이것」, 회상 Ⅲ 「끝낼 때마다 다시 데려가는 그것」 | 프롤로그 독백 → 숨은 장의 빈 홈 → 마왕 엔딩에서 종언으로 끊음 |

## 부록 5 — 굴레 복선 목록

플레이어가 직접 알 수 없도록 한 장에 한두 개만 둔다. 어느 것도 「돌아온다」고 말하지 않는다.

| 장 | 장치 | 무엇으로 암시하나 |
|---|---|---|
| 프롤로그 | 변하지 않는 세부 | 광장 왼쪽 세 번째 가로등 위의 까마귀(귀향, 엔딩 III에 같은 자리. 엔딩 IV에서만 비어 있음) |
| 프롤로그 | 기시감 · 숫자 | 떨어지는 바늘을 미리 받음. 엘스베트 「이번이 세 번째로구나」 |
| 프롤로그 | 독백 | 처음인데 「지친」 몸, 가슴속 씨앗 같은 온기 |
| 1장 | NPC 말실수 | 퀸트 「왼쪽은 지난번에—」, 바렌 「이 말을 하는 게 처음이 아닌 것 같다」 |
| 2장 | 기시감 | 처음 듣는 자장가의 끝 소절을 먼저 흥얼거림. 베일라 「궤도가 반들반들한 별」 |
| 3장 | NPC 대사 | 사바 「몇 번째 듣느냐… 다들 처음이라고 하지」 |
| 4장 | 보스 대사 | 세트라 「또 너로구나」, 「늘 같은 얼굴로 묻지」 |
| 회상 Ⅰ | 독백 | 검사 「이 장면을 끝까지 알고 있는 사람처럼 슬픈가」 |
| 5장 | NPC 말실수 | 오스왈드 「이 장을 몇 번이나 펼쳤는지」, 엘스베트 「숫자가 자꾸 미끄러지는구나」 |
| 6장 | NPC 말실수 | 선원 「이번엔 늦지 않으셨군요」 |
| 7장 | NPC 기시감 · 독백 | 로자린드 「방금 그 말, 전에도 한 것 같아」. 「같은 자리에서 같은 생각을 한다」 |
| 8장 | NPC 대사 | 이벨린 「모두 같은 사람이에요」 |
| 9장 | 현대인의 말 | 유나 「게임 2회차 하는 기분」 |
| 숨은 장 | 사물 · 독백 | 씨앗 모양의 빈 홈, 명단의 빈 첫 줄에서 떠오르는 「모두 같은 날짜」 |
| 최종장 | 보스 대사 · 소리 | 아스란 「이번엔 끝까지 가실 겁니까」, 절벽 위에서 들릴 리 없는 분수 소리 |
| 엔딩 I | 연출 | 크레딧 뒤 검은 화면의 분수 소리 한 컷 |
| 엔딩 II | 소리 · 대사 | 바위 속의 물소리, 유나 「다음에 또 보는 거지?」 |
| 엔딩 III | 변하지 않는 세부 | 같은 광장, 같은 까마귀, 생일 노래, 발이 아는 돌바닥 |
| 엔딩 IV | 회수 | 아스란 「이번엔 정말 끝까지」, 엘스베트 「몇 번째인지 이제 모르겠구나」, 씨앗을 끊자 소리가 사라짐. 마른 분수, 빈 가로등, 작은 신발 한 짝 |
