# 이름 변경안 — 엘든링풍 (승인 대기)

> 사장님 지시: 지금 이름이 가볍다 → 묵직한 서양식 이름 + 칭호/이명으로 바꾼다. **표만 제안하며, 다른 문서·데이터에는 아직 적용하지 않았다.** 승인되면 docs_story 전체에 일괄 반영하고, 다른 폴더(STORY.md·TOWNS.md·data/towns.json·지도 JSON 등)는 반영할 파일 목록으로 정리한다.
