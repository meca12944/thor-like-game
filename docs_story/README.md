## 맨 위 규칙
1. **아동 절대 보호 법칙**: 아이(토비·펠릭스·이안 등)에게는 몸을 다치게 하는 일이나 죽음이 절대 닿지 않는다. 어떤 루트·선택·연출에서도 마찬가지.

3. 참수 연출·정령 표현은 없다. 주인공의 피하기 동작은 **회피대시**(마스터 플랜 원문 "구르기" = 회피대시).

## 세계 요약 (새 정본)
- 300년 전 루드비히 왕의 금술로 왕도 전체가 시간 루프와 잿빛 안개에 갇혔다.
- 주인공 필멸자는 가슴에 '사멸의 코어'를 품고 300년 동안 수백 번 죽고 깨어났다. 루프를 유지하려고 만들어진 살아 있는 코어의 그릇(7장에서 밝혀짐).
- 새 시스템 [공허의 마모]: 장비·몸이 닳고, 임계점(배수진)에서 위험 + 각성 버프.
- 장: 프롤로그(펠트 바깥 무명 무덤가) → 1장 잿빛 들판 & 폐공방(아라크네) → 2장 철혈의 가도 & 하수도(단테 경) → 3장 대서고(셀레네) → 4장 연회장(엘레노어) → 5장 대성당·수장고(멜키어) → 6장 연금술 심장부·시계탑(클로비스) → 7장 왕성(루드비히) → 8장 공허의 틈새(사멸의 화신).
- 리네트는 폐공방 1층 뒤집힌 옷장에서 구출되고, 2장 카일라에게 가라고 안내한다.
- "30년 전"(아라크네, 벤의 왕실 장부)과 "300년"(루프)은 마스터 플랜 원문대로 둘 다 쓴다.

## 대사 형식 (게임에 넣을 때)
```json
{"speaker": "리네트", "expression": "smile", "text": "..."}
```
- `expression`: `neutral` `smile` `angry` `sad` `surprised` `blush` 중 하나.
- `speaker` 「필멸자」 = 주인공. 「나레이션」은 이름표 없이.
- 주인공 말투는 짧고 냉소적.
