## 리네트 — 리네트 동료 퀘스트 「영웅의 망토」

- 출신: 판타지 세계 출신 (A 시작 마을 태생, 왕도 궁정 의상실 견습 경력) · 22세 (성인)
- 매력 포인트: 밝고 수다스러운 재봉사. 겁이 많아 혼자 숲에 못 가지만, 지켜야 할 사람이 생기면 바늘 두 자루로 먼저 뛰어든다. 색과 옷감 이야기에 눈을 반짝이는 장인 기질 + 은근한 허세 + 진짜 용기.
- 의상: 고유 의상 유지(HEROINES.md): 하늘색 주름 미니스커트, 나비 리본 크롭 블라우스, 바늘꽂이 벨트, 줄무늬 사이하이 스타킹, 금발 트윈테일. 대본에서 외모·신체를 묘사하지 않는다.
- 관계 톤: 주인공은 프롤로그 시점 20세(성인, 팀장 결정). 리네트(22)와는 「단골 ↔ 재봉사」에서 시작해 호감도가 오를수록 설렘이 묻어나는 로맨스 톤. 비노출·비선정, 손끝·시선·말끝 정도의 설렘만.
- 칭호 분기 규칙: 영웅(+40↑) / 필멸자(-39~+39) / 타락한 필멸자(-40~-59) / 마왕(강림 후). 동료 퀘스트는 선악 「악명」(-20) 이하에서 거절되므로, 필멸자 칭호라도 -20~-39면 `mortal_infamous` 대사로 거절하고, 타락한 필멸자·마왕은 항상 거절/적대다.

### 3단계 `A_TAILOR3` 「영웅의 망토」

- 발생 조건: A_TAILOR2 완료 + 1지역 보스(이끼 수정 골렘) 격파 후 A 귀환(「숲에서 돌아온 날」 이벤트).

- 보상: 호감도 +25, 망토 염색 무료권
- 진행:
  1. 재봉소: 리네트가 「영웅의 망토」의 마지막 재료 「물빛 실크」를 말한다. 수정 동굴 입구 개울에 사는 물빛 누에의 고치에서만 나온다.
