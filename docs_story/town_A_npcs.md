# 시작 마을 A — NPC 10명 대사

> 원본 설정: `data/towns.json` (A npcs), STORY.md, TOWNS.md. 게임용 데이터: `town_A_npcs.json`.
> 표정: neutral/smile/angry/sad/surprised/blush. 기존 초상화는 normal/smile/angry/blush뿐 → neutral=normal, sad·surprised는 파일이 없으면 normal로 대체(HEROINES.md 표정 훅 규칙).
> 칭호 분기: hero / mortal / mortal_infamous / fallen / demon_king. 동료·선의 퀘스트의 거절 기준은 칭호가 아니라 선악 등급 「악명」(-20 이하)이므로 필멸자 칭호를 둘로 나눔.

## 마왕 루트 공통 규칙

- 마왕 강림 후 A는 자유 파괴 구역. 건물 내구도 합계 810의 70% 이상 붕괴 시 「잿빛 분수 터」.
- 아이(도토리 등)는 어떤 공격·스킬·잔해에도 맞지 않는다(히트 대상 제외). 경종 즉시 물결 할머니(+촌장 한결)가 분수 뒤 하수로 → 시작의 숲 감시탑으로 인솔, 인솔자가 없으면 지하실·하수로·뒷문으로 순간이동해 사라진다. 난민 행선지 B.
- 어른 NPC는 마왕 등급에서 살해 가능(TOWNSFOLK_COMBAT.md 선악 페널티 그대로). 살해 시 해당 NPC 퀘스트 영구 실패, 영구 성장 보상은 시신에서 「원한의 조각」.
- 첫 건물이 무너질 때 마을 강자 칼바람이 살아 있으면 방어하러 나온다.
