## v2 제작 파이프라인 (샘플 악기 + 믹싱·마스터링)

v1(순수 FM 합성)이 얇다는 피드백에 따라 **같은 곡 데이터**(`tools/music/songs/*.py`, 선율·화음 전부 자작)를 샘플 악기로 다시 연주·믹싱합니다. `python3 tools/music/render2.py <id ...>` (v1 은 `render.py` 로 그대로 남아 있음).

1. **연주 데이터 → MIDI**: 채널별 MIDI(mido), 타이밍 ±4–6ms·벨로시티 ±7 휴머나이즈(시드 고정, 루프 결정적), 리드 기타·바이올린의 `~` 벤드와 지연 비브라토를 피치벤드로.
2. **샘플 렌더**: FluidSynth 2.4 + GeneralUser GS 2.0 — 기타 DI(Clean/Muted), 핑거·피크·슬랩 베이스, 현(Slow/Fast/Synth 레이어), 합창(Choir+Oohs 레이어), 파이프 오르간, 금관, 플루트, 바이올린, 피아노, 첼레스타·튜블러 벨, 팀파니. 드럼은 Power 킷(록)·Orchestral 킷(어둠)·Room 킷(마을). VSCO-2 CE 타악 원샷(대북 BDrum·로그 드럼·공·서스펜디드 심벌·앤빌)을 타이코·붐에 레이어. 서브 드론·킥 서브·베이스 서브는 v1 합성 보강.
3. **기타 앰프 시뮬**: 4배 오버샘플 2단 비대칭 tanh 하이게인 → 4x12 캐비닛 EQ(HP 85, +3dB@115, −3dB@450, +4dB@2.3k, 5.2kHz 4차 LP). 리듬 기타는 서로 다른 시드의 더블 트래킹을 좌우 85% 패닝, 뮤트/오픈 분리.
4. **믹스**: 채널별 목표 레벨(게이트 RMS) 게인 스테이징, EQ·컴프·새추레이션, 킥 사이드체인 더킹(베이스·음악 버스 −1.6~−2.2dB), 드럼 버스 병렬 압축, 주파수별 감쇠 홀 IR(얼리 리플렉션 포함, RT60 곡별 1.8–3.0s), 템포 동기 딜레이, M/S 폭 확장(150Hz 이하 모노).
5. **마스터**: 글루 컴프 → (어둠 곡) 레퍼런스 대역 프로파일 매치 EQ(±4dB, 70%) → 소프트 클립 → 2배 오버샘플 피크 감지 룩어헤드 리미터(−1.0 dBFS) → **어둠·전투·필드 −12 LUFS, 마을·엔딩·잔잔 −14 LUFS**. 루프는 [인트로, 루프×3] 타임라인 전체를 처리한 뒤 가운데 루프를 잘라 이음새가 끊기지 않음.
6. **밝은 이스풍 곡**(필드·마을·타이틀·보스): 리드 기타에 바이올린 유니즌 더블, 패드 화음에 피아노 보이싱 레이어 자동 추가.
