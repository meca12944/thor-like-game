# 사멸의 궤적 — 히트박스 일치 검기 v3

주인공의 **실제 공격 판정 범위**에 맞춰 6종 검기 디자인을 다시 만들었습니다. 패턴은 스타일마다 가로·세로·X 3가지입니다.
이번 작업은 디자인 제안입니다. 게임 코드와 기존 에셋은 수정하지 않았고, 커밋이나 배포도 하지 않았습니다.

- 모든 수치는 **필드 논리 px** 기준입니다. 화면은 384×216이고, 1 px = 화면 ×k입니다.
- 미리보기는 ×3 배율, 어두운 바닥 위에서 렌더했습니다. 시트는 원본(native) 크기의 투명 PNG입니다.
- 원칙: **채워진 부채꼴/띠 = 판정 영역**, **밝은 테두리 = 최대 사거리**입니다. 검기 몸체는 판정 마스크 밖으로 나가지 않게 클립했습니다. 파티클·반짝임 같은 장식만 예외입니다.

### ⚠ 칼 길이와 판정의 차이

인게임 hit1 스프라이트의 칼끝은 발에서 앞으로 약 **32.8 px**까지 닿습니다. GK_REACH(32)와 거의 같습니다.
반면 사거리×0.7(22 px)로 그린 검기는 **눈에 보이는 칼 길이의 약 2/3 지점에서 끝납니다.**
"검기가 보이는 곳 = 맞는 곳"을 지키려면 아래 둘 중 하나를 정해야 합니다.

- (a) 판정을 ×0.7로 줄이고 이 디자인을 그대로 쓴다.
- (b) R을 GK_REACH(32/30/37)로 키운다. make_hitbox.py의 `SWEEP_K`만 1.0으로 바꾸면 됩니다.
