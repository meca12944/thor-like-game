# 검흔 v2 — 방향 베리에이션 (가로 · 세로 · X자)

Owner 피드백: "방향이 한곳인데 가로 세로 엑스표시도 넣어서 해봐봐".
v1 스타일 6종(팔레트·반경 70px·끝 굵고 밝음·잔상·스파클·스피드라인·채움 팬=히트박스)은 그대로 두고, 베기 방향만 3종 추가했다.
v1 파일(`../`)은 건드리지 않았다. `make_dirs.py`는 `../make.py`를 읽어 메모리에서만 패치해서 쓴다. 재생성: `python3 make_dirs.py` (약 2분).

### X자 타이밍
- 1타: f0 와인드업 → f1–f2 스윕 완료.
- 2타: f3 와인드업, **f4에 출발 (1타 시작 후 약 116 ms)**, f5에 완료.
- 교차 섬광: f5 (크기 3) → f6 (2) → f7 (1). 계산된 교차점에 8방향 광선과 링. 심연은 가운데에 검은 핀홀.
- 홀드: 두 궤적 모두 f5–f7 동안 완전한 X로 남음 (침식 없음, 잔상·스피드라인 꺼짐) → f8–f11에 함께 소멸.
- 히트박스 팬은 X에서 바깥쪽 띠만 표시 (fan_r0 .55).
