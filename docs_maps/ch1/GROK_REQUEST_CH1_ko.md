# 그록 부탁: 프롤로그 + 1장 (잿빛 들판 · 펠트 · 폐공방)

> 같이 보낼 지도: `docs_maps/ch1/ch1_for_grok.png`. 흰 테두리는 멀리서 보이는 큰 경관이고, 노란 부채꼴은 카메라가 물러나는 전망 자리예요. 지도 1칸 = 16px.

## 공통
- **세계: 거대한 성 안의 왕도.** 바깥 세상·산·지평선이 없다. 남쪽은 외성벽이고, 북쪽 먼 곳은 내성벽과 왕성 탑이다.
- 1장은 성벽 안 가장 바깥, 불타 무너진 구역이 재 덮인 벌판이 된 곳이다. **「자연」은 무너진 도시가 자연이 된 모습**이다 (엘든링처럼 웅장하게: 거대한 것과 사람의 크기 대비, 멀리서 보이는 표지물).
- 화풍: 지금까지 보내 준 펠트 소품·CG와 같다. 위에서 비스듬히 내려다보는 시점이다.
- 소품은 배경 투명 PNG로 보낸다. 바닥은 이어 붙일 수 있는 16px 타일 세트로 보낸다.
- **큰 경관은 「주인공 뒤에 그릴 부분」과 「주인공 앞에 그릴 부분」을 따로** 보낸다. 예: 수도교 아치 기둥 / 아치 윗부분.
- 빛·불·안개·잿가루·실 흔들림 같은 효과는 그림에 넣지 않는다. 게임 코드로 그린다.
- 마물은 지금 부탁하지 않는다 (다시 기획 중).

## 경관마다 사연 (그림 분위기 참고)

- **외성벽**: 300년 전 루드비히의 금술로 왕도 전체가 루프와 잿빛 안개에 갇혔다(정본). 성벽을 넘으려던 자는 안개 속에서 다시 무덤가로 돌아온다(팀 제안).
- **내성벽과 왕성 탑**: 루드비히가 시간을 묶은 곳(정본 7장). 맑은 순간 탑 꼭대기 하늘에 핏빛 금이 잠깐 비친다(팀 제안, 8장 복선).
- **석화된 거대 나무**: 안개가 가장 짙게 고여 나무째 돌이 된 곳(팀 제안). 아래에 핏방울 1/3 히든 정예(정본).
- **무너진 수도교**: 왕도에 물을 대던 다리. 루프가 시작된 밤의 충격으로 가운데가 끊겼고, 지금은 물 대신 잿가루가 폭포처럼 흐른다(팀 제안).
- **꺼진 지반**: 하수도로 스민 연금술 폐기물에 땅이 석회처럼 굳어 부서지며 꺼졌다(팀 제안, 정본 2장 하수도 석회화와 같은 원인).
- **폐공방에서 구덩이까지 걸린 붉은 실**: 30년 전 영혼을 꿰매던 아라크네의 실(정본). 펠릭스가 사라진 길이지만 고치는 비어 있다(아동 보호, 팀 제안).
- **쓰러진 거인 기사상**: 성문을 지키던 기사단 맹세의 상(팀 제안). 쓰러진 머리가 북쪽 2장 가도를 가리킨다. 베르디: "형(단테)이 저 상 앞에서 맹세했다"(팀 제안).
- **검은 호수**: 옛 외곽 예배당 종탑이 꺼진 땅과 함께 가라앉았다. 펠트 종탑 뚜껑문 아래 '종소리'는 물속 이 종이다(팀 제안, 1장 종탑 복선과 묶음).
- **옛 성문 아치**: 왕도가 넓어지기 전의 첫 성문. 아치 그늘이 안개를 조금 막아 생존자들이 모였고 그게 펠트가 됐다(팀 제안).

## 첫 장면 (인트로) 참고

- 전망 ① 무덤가 언덕 — 첫 장면: 보이는 것 — 석화된 거대 나무 + 왕성 탑(먼 배경)
- 전망 ② 수도교 끊긴 틈: 보이는 것 — 꺼진 지반 + 붉은 실
- 전망 ③ 석화 나무 절벽 끝: 보이는 것 — 내성벽 + 2장 가도 (먼 배경)
- 전망 ④ 1장 정문이 열릴 때: 보이는 것 — 돌기둥 베르디(작은 사람) 너머 쓰러진 거인 기사상 (크기 대비)
- 전망 ⑤ 거인 손바닥 위: 보이는 것 — 수도교 북쪽 토막 + 2장 가도
