# 그록에 붙여 넣을 글 (1장, 사장님 10-25)

> 쓰는 법: 그록 채팅에 그림 2장(`ch1_for_grok.png`, `world_overview.png`)을 먼저 올린다. 그다음 아래 [공통 설명]을 한 번 붙여 넣는다. 그 뒤로는 [1차]부터 한 번에 하나씩 붙여 넣는다.

---

## [공통 설명] (처음에 한 번)

```
지금부터 내 2D 액션 RPG 「필멸자」의 1장 배경 그림을 부탁할게.
올린 그림 2장은 우리가 설계한 지도야.
- world_overview.png = 세계 전체 (거대한 성 안의 왕도)
- ch1_for_grok.png = 1장 지도. 흰 테두리 = 멀리서도 보이는 큰 경관, 노란 부채꼴 = 카메라가 물러나며 경치를 보여 주는 자리. 지도 1칸 = 16px.

세계 규칙
- 이 세계는 하늘까지 솟은 거대한 성벽 안의 왕도다. 바깥 세상·산·지평선은 없다. 남쪽 끝은 외성벽, 북쪽 먼 곳은 내성벽과 왕성 탑이다.
- 1장은 성벽 안 가장 바깥, 불타 무너진 구역이 재가 눈처럼 쌓인 벌판이 된 곳이다.
- "자연"은 무너진 도시가 자연이 된 모습이다. 엘든링처럼 웅장하게: 거대한 것과 작은 사람의 크기 대비, 멀리서 보이는 표지물.

그림 규칙
- 화풍: 지금까지 보내 준 펠트 소품·CG와 같은 픽셀아트, 위에서 비스듬히 내려다보는 시점.
- 소품 = 배경이 투명한 PNG. 바닥 = 이어 붙일 수 있는 16px 타일 세트.
- 큰 경관은 "주인공 뒤에 그릴 부분"과 "주인공 앞에 그릴 부분"을 따로 그려 줘. (예: 아치 기둥 / 아치 윗부분)
- 빛·불·안개·잿가루·실 흔들림 같은 효과는 그림에 넣지 마. 게임 코드로 그린다.
- 몬스터는 아직 그리지 마 (다시 기획 중).

한 번에 3~4개씩 부탁할게. 이해했으면 "준비됐어"라고만 답해 줘.
```

---

## [1차] 들판 분위기 (가장 먼저)

```
1차 부탁 3개.
1) 잿빛 들판 바닥 세트 — 16px 이어 붙이는 타일 + 큰 장식 몇 개. 재가 눈처럼 쌓인 땅, 마른 풀, 발자국이 남는 잿더미.
2) 먼 배경: 내성벽과 왕성 탑 — 화면 가로 2배 길이의 띠 1장. 북쪽 하늘을 가로막는 거대한 내성벽, 그 가운데 솟은 왕성 탑. 모든 장에서 같은 탑을 쓸 거라 모양을 또렷하게. (안개는 코드로 넣음)
3) 석화된 거대 나무 (1장의 표지물) — 약 60x55칸(화면 2~3개 크기). 돌이 된 거대한 나무, 1장 어디서든 보임, 밑동에 깊은 그늘. 줄기·뿌리(주인공 뒤)와 가지 끝(주인공 앞)을 따로.
사연: 안개가 가장 짙게 고여 나무째 돌이 된 곳이다.
```

## [2차] 큰 경관

```
2차 부탁 4개.
4) 무너진 수도교 — 아치 반복 조각 + 끊긴 끝 2개, 높이 약 14칸. 들판을 가로지르는 돌 수도교. 위로 걷는 길, 아래로 아치를 지나감. 가운데가 끊겼음. 아치 기둥(뒤) / 아치 윗부분(앞) 따로.
   사연: 왕도에 물을 대던 다리. 지금은 물 대신 잿가루가 폭포처럼 흐른다(입자는 코드).
5) 쓰러진 거인 기사상 + 투구 + 떨어진 검 — 몸 약 120x20칸 / 투구 20x20 / 검 60x6. 옆으로 쓰러진 거대한 기사 석상. 등 위를 걸을 수 있고, 손바닥은 평평한 쉼터. 검은 땅에 박혀 칼날 위를 걷는다.
6) 꺼진 지반 + 아래 옛 동네 지붕 — 구덩이 약 75x70칸 + 아래층 그림 1장. 땅이 석회처럼 부서져 꺼진 큰 구덩이, 아래로 어둡게 옛 지붕들. 가장자리에 부서진 승강기·쇠사슬.
7) 옛 성문 아치 (펠트 마을 위) — 약 150x25칸. 무너진 첫 성문의 거대한 아치, 그 그늘 아래에 생존자 마을이 있다.
```

## [3차] 경관 마무리

```
3차 부탁 4개.
8) 검은 호수 + 가라앉은 종탑 끝 — 호수 약 85x50칸 / 종탑 끝 6x8. 검고 잔잔한 물, 물 위로 종탑 지붕만 나옴, 옆에 작은 섬. (물에 비친 탑은 코드)
9) 붉은 실의 첨탑 / 실 다발 — 높이 약 60칸. 폐공방 지붕에서 하늘로 묶여 올라간 붉은 실, 구덩이까지 길게 걸린 실.
10) 외성벽 밑동 — 가로로 긴 띠. 남쪽 끝 하늘까지 솟은 성벽의 밑동만 (높이는 북쪽으로 긴 그림자로 표현).
11) 북쪽 절벽 끝 — 구역 260x100칸. 깎아지른 절벽 끝, 낙석.
```

## [4차] 들판 소품

```
4차 부탁 4개 (모두 투명 배경 소품).
12) 작은 경관 4종 (각 10~50칸): 쓰러진 탑 몸통, 창이 꽂힌 옛 싸움터, 석화 숲, 바람이 깎은 잿더미 언덕
13) 부서진 마차 (약 8x5칸): 들판 한가운데 뒤집힌 마차
14) 탈영병 유해 3종 (약 2x1칸): 쓰러진 병사, 1개는 옆에 검붉은 방울
15) 무명 무덤가 + 가죽 배낭 유해 (약 12x8칸): 이름 없는 무덤들 — 주인공이 처음 눈뜨는 곳
```

## [5차] 문·지름길·폐공방

```
5차 부탁 4개.
16) 1장 정문 + 돌기둥 베르디 (약 6x5칸): 들판으로 나가는 문, 다리가 돌기둥과 굳어 버린 기록관 노인
17) 지름길 4종 (각 3~6칸): 밧줄 다리, 리프트, 하수 구멍, 보스방 뒷문
18) 폐공방 1층·지하1층·지하2층 바닥과 벽 (16px 타일): 붉은 인체 조직 실이 엉킨 재봉 공방 / 고문실 / 고치 저장고
19) 이야기 소품 (각 2~6칸): 뒤집힌 옷장, 대형 재봉틀, 숨겨진 제단, 빈 고치
```

(20 마을 사람 6명, 21 아라크네는 따로 부탁한다. 아라크네는 이미 받은 그림으로 작업 중.)
