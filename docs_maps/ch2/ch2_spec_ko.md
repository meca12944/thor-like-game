## 1. 한 줄 소개와 분위기
거대한 성 안 왕도의 남쪽, 1장 외곽에서 **북쪽 내성문(→ 7장 왕성)**으로 올라가는 성곽 길(세계 지도 docs_maps/world). 성문을 지키겠다는 일념 하나로 갑옷과 몸이 들러붙은 기사들이 배회한다. 가도 서쪽 땅 밑으로는 3·6장 연금술 폐기물과 수은이 흘러드는 맹독 하수도가 깔려 있고, 하수도 북쪽 끝은 3장 대서고 지하로 이어진다. 바깥 세상은 없다 — 지도 가장자리는 성벽·내성벽·무너진 집·땅 밑 석벽이고, 어디서든 북쪽 멀리 왕성 탑이 보인다.

## 3. 동선
- **처음 길 (남 → 북)**: 1장 외곽(1장 동북 629,76, 정문 밖 베르디) → 가도 외곽 → 무너진 초소 → 바리케이드(정예) → 보스 문 앞 쉼터 → 단테 경 → 성문 기어 손잡이로 내성문 → 7장 왕성 내성 길(거기서 3장 서쪽 대서고로).
- **곁길**: 가도 → 동쪽 무쇠 공방(카일라: 리네트의 왕실 천 → 마모 저항 방어구 + 리프트). 가도 외곽 전사자 시체 2곳에서 군번줄·펜던트 → 서쪽 성벽 위 바르바라 → 북동 숨겨진 무기고(반지·수리 망치) → 성문 우회로로 광장 옆에 바로.
- **하수도**: 가도 서쪽 맨홀 → 첫 수문 → 판자촌(그레이) → 중간 통로(로크)·저수조 / 막다른 배수로(결혼반지) / 맹독 최심부(렌즈 반지가 있어야 함정이 보임).
- **지름길 (4)**: ① 무쇠 공방 1↔2장 리프트(카일라, 정본 — 1장 지도 (600,280)과 이어짐) ② 무기고 → 성문 우회로(바르바라, 정본) ③ 판자촌 사다리 → 바리케이드 (팀 제안, 안에서 엶) ④ 저수조 북쪽 배수 통로 ↔ 3장 대서고 지하 (팀 제안, 3장에서 엶 — 세계 지도 「하수도 → 대서고 지하」).
- **다시 찾아오는 길(백트래킹)**:
  - 단테 처치 → 대검을 들고 리프트로 1장 정문 베르디에게 → 기록관의 렌즈 반지 → 다시 하수도 최심부 → 참수검.
  - 그레이의 암호화된 금서 → 1장 베르디 해독 → 3장 비밀방 / 4장 귀족가 직행 샛길(세계 지도: 1장 → 4장 쪽).
  - 그레이의 타임키퍼의 해체 공구 → 6장 클로비스 → 3장 지하 연금술 화로.
  - 로크: 6장 수은 필터 또는 하수도 최심부 수은 정화통 → 석화된 연금술사의 물약병.
