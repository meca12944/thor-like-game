## (1) 한 줄 소개와 분위기
왕도 진입을 막는 거대한 성곽 길. 성문을 지키겠다는 일념 하나로 갑옷과 몸이 들러붙은 기사들이 배회한다. 길 아래로는 3·6장 연금술 폐기물과 수은이 흘러드는 맹독 하수도가 미로처럼 깔려 있다. 위는 녹슨 쇠와 잿가루, 아래는 하얗게 석회로 굳어 가는 오물.

## (3) 동선
- **처음 길**: 1장 정문(베르디) → 가도 외곽 → 바리케이드(정예) → 보스 문 앞 쉼터 → 단테 경 → 성문 기어 손잡이로 왕도 성문 → 3장.
- **곁길**: 가도 → 무쇠 공방(카일라: 리네트의 왕실 천 → 마모 저항 방어구 + 리프트). 가도 외곽 전사자 시체 2곳에서 군번줄·펜던트 → 성벽 위 바르바라 → 숨겨진 무기고(반지·수리 망치) → 성문 우회로로 광장 옆에 바로.
- **하수도**: 가도 외곽 맨홀 → 첫 수문 → 판자촌(그레이) → 중간 통로(로크)·저수조 → 막다른 배수로(결혼반지) / 맹독 최심부(렌즈 반지 있어야 함정이 보임).
- **지름길 (3)**: ① 무쇠 공방 1↔2장 리프트(카일라, 정본) ② 무기고 → 성문 우회로(바르바라, 정본) ③ 저수조 사다리 → 바리케이드 (팀 제안, 안에서 엶).
- **다시 찾아오는 길(백트래킹)**:
  - 단테 처치 → 대검을 들고 리프트로 1장 정문 베르디에게 → 기록관의 렌즈 반지 → 다시 하수도 최심부 → 참수검.
  - 그레이의 암호화된 금서 → 1장 베르디 해독 → 3장 비밀방 / 4장 귀족가 직행 샛길(저수조 동쪽 비밀문, 팀 제안 자리).
  - 그레이의 타임키퍼의 해체 공구 → 6장 클로비스 → 3장 지하 연금술 화로.
  - 로크: 6장 수은 필터 또는 하수도 최심부 수은 정화통 → 석화된 연금술사의 물약병.
  - 3장 지하 금지된 서고 배수 통로 → 2장 하수도 (3장 쪽 지름길, 팀 제안).
