## 1. 한 줄 소개와 분위기
**"버려진 껍데기들의 무덤"** — 위는 잿가루 쌓인 고딕 대성당(환영 암살자가 기둥 뒤에 숨은 조용한 공포), 아래는 주인공이 300년 동안 죽으며 남긴 수천 개의 자기 시체가 산처럼 쌓인 수장고. 내려갈수록 "이게 다 나였다"는 섬뜩함이 커지고, 맨 밑에서 그 껍데기를 모은 거울 보스 멜키어를 만난다.

## 3. 동선
**처음 길**: 4장 귀족가 → 묘지 서문(쉼터) → 묘지 길 → 대성당 서문 → 본당(제단에서 사멸의 파편, 옆 예배실 둘에서 순백의 관현·정화의 송진) → 성가대석(피에트로, 오르간 수리 → 환영 암살자 적대 해제) → 종탑(관리실에서 흡음 천·열쇠 꾸러미, 들러 가는 길) → 본당 남쪽 계단 → 지하 허브(오스왈드, 파편 분기) → 진입로(해골 구덩이) → 껍데기 산 → 최심부(보스 문 앞 쉼터) → 멜키어 → 리프트로 6장.

**분기 (정본)**: 사멸의 파편을 **오스왈드**(허브)에게 → 철염주 망토·찢어진 염주 + 보스 약화 / **시몬**(묘지)에게 → 저주받은 이단의 대검 + 보스전에 시몬 난입·광폭화. 묘지와 허브가 지름길 A·B로 이어져 있어 둘 다 만나 보고 고를 수 있다.

**지름길 3개 (팀 제안, 처음엔 잠김 → 안쪽에서 엶)**
- A: 진입로 해골 구덩이의 **사슬 승강대 ↔ 묘지 동남 뚜껑문** — 진입로에 닿으면 사슬을 풀어 묘지로 바로 올라갈 수 있다 (시몬에게 돌아갈 때).
- B: 최심부 ↔ 지하 허브 **철문** — 종탑에서 얻은 [낡은 열쇠 꾸러미]로 연다. 보스에서 죽으면 허브 모닥불에서 바로 최심부로.
- C: 종탑 꼭대기 **종 줄 ↔ 묘지 북쪽** — 위에서만 내려가는 줄(한 방향).

**다시 찾아오는 길 (백트래킹)**: 7장 대회랑 근위대장 석상에서 [시간이 굳은 핏방울 3/3]을 얻은 뒤 5장으로 돌아와 허브 → 지름길 B → 최심부 → 밑바닥 **검은 석관**(핏방울 1/3 1장 들판·2/3 3장 대서고·3/3 7장)에 부어 태초 세트 4개를 얻는다. 묘지 입구 → 석관까지 지름길로 약 40초.
