# 새 1장 짓기 순서 (사장님 2026-10-24 「그 순서로 가자」)

1. 그록 1장 그림이 오면 지금의 펠트·펠트 들판 자리에 **새 1장 (640×470)** 을 짓는다. 기준은 `docs_maps/ch1/` 설계도다.
2. 새 1장이 게임에서 돌아가면, 옛 내용을 한 번에 지운다 (git 기록에는 남는다).
   - 옛 숲 들판 field00~09
   - 옛 마을 townB·townH
   - 옛 보스 boss01, 옛 던전 dungeon01
   - 옛 들판 몹
   - 정본과 다른 옛 이야기 문서
3. 시작을 새 인트로로 바꾼다: 들판 남쪽 무덤가에서 눈뜬다 → 첫 언덕 전망.

뼈대는 남긴다. 싸움 손맛, 주인공, UI·폰 버튼, 저장, 대화, 지도 화면, 전망 자리·안개·바람, 지도 읽는 장치가 뼈대다.
