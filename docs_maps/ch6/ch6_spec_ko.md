## 1. 한 줄 소개와 분위기
왕도의 시간을 물리적으로 붙잡아 둔 **거대한 증기 기관과 황동 톱니의 미궁**. 땅 쪽(쓰레기장·정제소)은 녹슨 고철과 푸른 수은이 흐르고, 그 위로 잿빛 안개 낭떠러지를 건너 **시계탑**이 솟는다. 위로 갈수록 톱니가 돌고 시계바늘이 움직여 **달리면서 타이밍을 맞춰 건너는** 장이다.
- **세계 속 자리** (사장님 10-24 「거대한 성, 그 안 왕도」, 세계 지도 `docs_maps/world/`): 6장은 왕도 **동남쪽 내성**이다. 바깥 세상·지평선은 없다. 지도 가장자리는 모두 내성벽·건물 벽·꺼진 지반이고, 어디서든 **서북쪽 멀리 왕성 탑**이 보인다.
- 들어오는 길(팀 제안, 세계 지도 방향): **북쪽 4장 귀족가**에서 증기 관문으로 내려온다.
- 나가는 길: 클로비스를 쓰러뜨리면 얻는 [왕가의 열쇠] → **서쪽** 7장 왕성.
- 지도 그림은 북쪽이 위다. 땅(쓰레기장·정제소)이 북쪽, 시계탑 층들이 남쪽 아래에 나란히 그려져 있다 (층은 옆으로 나란히, README 규칙).

## 3. 동선
**처음 길** (약 6~8분, 싸움 포함)
1. 북쪽 4장 귀족가에서 **증기 관문**(1 시작)으로 내려옴 → **기계 쓰레기장**.
2. 쓰레기장 가운데 쯤에서 **자드**(2)를 만남 → [부서진 톱니 반지](3)·[잊혀진 나선 열쇠](4)·**함정 해제법**(5).
   - 해제법을 안 듣고 가면 증기 회랑·정제소의 즉사 함정이 켜져 있음(팀 제안: 정본 「즉사 함정들을 끄는 법을 알려주고」).
3. **증기 파이프 회랑** → **중앙 수은 정제소**. 메인 추출기(6)를 나선 열쇠로 열어 수은검·석회 망토·수은관·조제도구(7~10). 파이프 밸브(12)를 풀어 [수은 필터](11).
4. 실험실 계단 → **상층부 연금술 실험실**의 시간 정지 금고(13)에서 모래시계 반지·봉인된 기름(14·15).
5. 시계탑 연결 다리 → **하층** → **중층**(정예 **태엽 집행자** 16 → 17~19) → **최상층**: 도는 시계바늘 위를 타이밍 점프해 [타임키퍼의 부러진 반쪽 반지](20).
6. 보스 문 앞 쉼터 → **메인 태엽실**: **클로비스**(21) → 메인 태엽이 멈추면 [시계태엽의 황동 망토](22)·[왕가의 열쇠](23) → 서쪽 7장 왕성으로.

**지름길** (모두 팀 제안, 처음엔 잠김 → 안쪽에서 엶)
- 지름길1 **정제소 하역 승강기**: 정제소 안쪽에서 켜면 쓰레기장 동쪽(자드 쪽)과 바로 이어짐 → 증기 회랑을 건너뜀.
- 지름길2 **시계탑 화물 승강기**: 중층에서 내리면 실험실과 바로 이어짐 → 하층을 건너뜀.
- 지름길3 **쓰레기장 배관 뒷문**: 쓰레기장 안쪽에서 열면 증기 관문과 이어짐 → 북쪽 4장 쪽으로 빨리 돌아감.

**다시 찾아오는 길 (백트래킹, 정본 아이템배치 2절)**
- **수은 필터 → 2장 하수도 로크**: 정제소에서 얻은 필터를 2장 로크에게 줌 → 로크가 석상으로 굳으며 [석화된 연금술사의 물약병]. (지도: 정제소 동쪽 백트래킹 표시)
- **초침을 부수는 대검 (2장 → 6장 → 3장)**: 2장 그레이에게 [타임키퍼의 해체 공구]를 미리 삼 → 클로비스를 쓰러뜨린 직후 흉곽에서 **태엽 핵**(24) 적출 → 3장 대서고 지하 연금술 화로에 녹임. (지도: 보스방 서쪽 백트래킹 표시)
- 지름길1·2를 열어 두면 클로비스 뒤 쓰레기장(자드)·정제소로 1분 안에 돌아올 수 있음.
