## 1. 한 줄 소개와 분위기
세계: 거대한 성벽 안 왕도의 **동쪽 구역**이다 (사장님 10-24). 지도 가장자리는 성벽과 불탄 저택 담이다. 서쪽 서문은 왕성 바깥 고리로, 남쪽 통로는 6장으로, 남서 맨홀은 1장 동쪽 들판 끝(금서 해독 샛길)으로 이어진다.
300년 전 반란군의 화염이 덮친 순간 그대로 시간이 멈춘 사치스러운 귀족 거리와 저택이다. 불타는 유령 귀족들이 끝없는 만찬을 즐긴다.
- 색: 잿빛 거리에 굳은 불꽃의 주황과 붉음
- 이안이 있는 곳과 재 무덤만 **이상하게 깨끗하고 고요하다**

## 3. 동선
- **처음 길 (정면)**
  1. 서문(왕성 바깥 고리, 세계 지도 서쪽)으로 「불타는 정면 거리」에 들어온다 (화염 지대). 멀리 서쪽 하늘에 왕성 탑이 보인다.
  2. 불탄 아치문을 지나 「귀족가 대로」로 간다.
  3. 연회장 정문으로 「본관 1층」에 들어간다. 식탁에서 세검을 얻고, 벽난로에서 낙인 반지를 얻는다.
  4. 와인고 계단을 내려가 「지하 와인 저장고」에서 흑요석 반지와 안개 진화 물약을 얻는다.
  5. 중앙 계단으로 「연회장 2층」에 올라가 탐욕의 루비 반지를 얻는다.
  6. 보스 문 앞 모닥불을 지나 「엘레노어의 대연회장」으로 간다.
- **샛길로 들어오기 (정본 배치표 동선)**
  - 2장 그레이에게서 암호화된 금서를 사서, 1장 베르디에게 해독을 맡긴다.
  - 그러면 「귀족가 직행 샛길」이 열린다. 정면 화염 지대를 건너뛰고 「귀족가 뒷골목」 서쪽 끝으로 바로 들어온다.
  - 금서 해독 샛길은 **1장 동쪽 들판 끝 ↔ 4장 뒷골목 맨홀**이다 (세계 지도, 팀장 10-24 확정). 베르디가 해독한 뒤 열린다.
- **실라스**
  - 뒷골목 마차 밑에 있다. 연회장 2층의 루비 반지를 가져오면 둘 중 하나를 고른다.
    - 실라스 곁 화로(팀 제안)에 태운다 → [그림자 도둑의 망토]
    - 내가 갖는다 → 실라스가 즉사하고 반지가 저주로 귀속된다
- **이안 샛길**
  - 대로에서 이안이 공을 굴린다.
  - 화염 장막 뒤 샛길1을 따라가면 뒷골목 샛길2, 그다음 샛길3으로 이어진다. 샛길3 끝이 「어린아이들의 재 무덤」이다.
  - 무덤에서 [숨겨진 요람의 목검]과 [이안의 붉은 소년 망토]를 얻는다.
  - 직행 샛길로 들어오면 샛길2가 가까워서, 배치표 문장 「샛길 끝에서 이안의 콧노래를 따라가」와 맞는다.
- **지붕 암살자 루트**
  - 정면 거리 지붕 사다리로 올라가 지붕을 건너뛴다. 기와가 무너진 틈은 점프로 넘는다.
  - 끝 다락방에서 [도굴꾼의 그림자 반지]와 [재가 되지 못한 편지]를 얻는다.
  - 다락방 창에서 대로로 뛰어내린다 (**한 방향 길**).
- **지름길 (처음엔 잠김, 안에서 열기)**
  1. 와인고 뒷문 → 대로
  2. 2층 발코니 줄사다리 → 대로 모닥불 옆
  3. 대로 하수 뚜껑 → 정면 거리 모닥불 쪽
- **다시 찾아오기 (백트래킹)**
  - 벽난로 낙인 반지는 와인고의 안개 진화 물약이나 보스 보상 불타는 외투가 있어야 집을 수 있다. 처음엔 보이기만 하고, 다시 와서 얻는다.
  - 루비 반지는 2층에서 얻어 뒷골목 실라스에게 돌아간다. 지름길2(발코니 → 대로) 뒤 골목 입구로 가면 짧다.
- **다음 장**: 보스를 잡으면 와인고 남쪽 통로가 열려 6장(동남)으로 간다 (세계 지도).
