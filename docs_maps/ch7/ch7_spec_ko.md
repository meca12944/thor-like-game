## (1) 한 줄 소개와 분위기
왕가의 열쇠로 황금 문을 열고 올라가는 왕성 최심부. 잿빛 모래가 폭포처럼 쏟아지는 대계단과, 굳어 버린 근위대가 늘어선 대회랑 끝에 석회로 굳은 루드비히가 옥좌에 앉아 있다. 300년 멈춘 시간이 가장 짙게 고인 곳 — 황금빛이 바래 잿빛이 된 궁전.

전체 **520×460 타일** (가로 달리기 약 104초). 구역 7개, 몹 무리 47 + 정예 1, 쉼터 7, 지름길 2.

## (3) 동선
- **처음 길**: 6장 시계탑 → ① 성벽길(쉼터) → **황금 문**(왕가의 열쇠, 문 앞 쉼터) → ② 황금 문 전정(쉼터) → ③ 모래 폭포 대계단(층계참 쉼터, 쏟아지는 모래에 맞으면 아래로 밀림) → 테라스 문 → ④ 석화된 왕실 정원(분수 쉼터) → 대회랑 서쪽 계단 → ⑤ 대회랑(동쪽 끝 근위대장 석상, 옥좌의 문 앞 쉼터) → ⑥ 옥좌의 방(루드비히) → 부서진 옥좌 뒤 → ⑦ 숨겨진 제단(왕비, 사멸의 핵철 반지, 쉼터) → 8장.
- **지름길** (팀 제안, 처음엔 잠김·안쪽에서 엶):
  1. **근위대 승강기**: 대회랑 동쪽 끝 레버 → 대계단 층계참. 죽어도 대계단 쉼터에서 바로 옥좌 앞까지.
  2. **무너진 성벽 사다리**: 정원 남쪽에서 내리면 성벽길로 바로. 성벽길 ↔ 정원.
- **다시 찾아오는 길(백트래킹)**: 근위대장 석상에서 얻은 **시간이 굳은 핏방울 3/3** → 성벽길 서쪽 「귀환 길」로 **5장 수장고 1회차 루프 석관**에 가서 태초 세트 완성 (정본 2절). 다시 7장으로 와서 옥좌로.
