# 그록 그림 부탁 목록 (1~8장 한 장 모음)

> 팀장 정리, 2026-10-24. 각 장 지도 설계도(`docs_maps/chN/chN_spec_ko.md` 5절)에서 모았다. 지도 그림: `docs_maps/chN/chN_overview.png`.

## 모든 그림에 공통으로 지킬 것
- **세계: 거대한 성 안의 왕도.** 바깥 세상·먼 산·지평선은 없다. 지도 끝은 성벽·건물 담·꺼진 땅으로 막혀 있다. 어느 구역에서든 멀리 **왕성 탑**이 보인다 (같은 탑 한 가지 모양으로).
- 화풍: 지금 그록이 보내 준 1장 펠트 소품·CG와 같은 다크 판타지 화풍.
- 시점: 위에서 비스듬히 내려다보는 탑다운이다. 바닥 타일은 16px 기준이고, 큰 소품은 타일 칸 크기를 적어 두었다.
- 소품·인물·보스는 **배경 투명 PNG**로 보낸다. 바닥은 이어 붙일 수 있는 타일 세트로 보낸다.
- **빛·불꽃·검기·마법 같은 효과는 그림에 넣지 않는다.** 효과는 게임 코드로 그린다. 불·모래 폭포처럼 움직이는 것은 몇 장짜리 애니로 보내도 된다.
- 아이들(토비·이안 등)은 다치거나 위협받는 모습이 없어야 한다.
- **마물(일반 몹·정예)은 지금 부탁하지 않는다.** 사장님 10-24 「마물은 다시 기획」. 맨 아래 「나중에」 칸에만 적어 둔다.
