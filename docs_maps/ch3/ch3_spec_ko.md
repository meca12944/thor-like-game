## (1) 한 줄 소개와 분위기
왕도의 모든 역사와 시간 왜곡의 금서가 봉인된 거대 도서관. 소리 내는 자를 사냥하는 눈먼 사서들과 검은 잉크 괴물들이 배회한다. 끝없는 책장, 바닥에 흘러 굳은 잉크, 깨진 스테인드글라스로 떨어지는 빛 한 줄기.

## (3) 동선
- **처음 길**: 2장 왕도 성문 → 1층 로비(헬레나 대화) → 중앙 계단 2층 → 나선 계단 3층 → 보스 문 앞 쉼터 → 셀레네.
- **헬레나 퀘스트**: 층마다 타락한 근위대 1명 → 꺾인 맹세의 검병(1층) · 부서진 맹세의 칼자루(2층) · 부러진 검병(3층) → 로비 헬레나 → 근위대의 꺾인 창검.
- **지름길 (2, 팀 제안)**: ① 3층 무너진 책장 사다리 → 1층 로비 (안에서 내림, 헬레나에게 빨리 돌아감) ② 지하 금지된 서고 배수 통로 → 2장 하수도.
- **다시 찾아오는 길**:
  - 2장 그레이 암호화된 금서 → 1장 베르디 해독 → 지하 서고 비밀방 (소용돌이 반지·잊혀진 양피지).
  - 6장 클로비스 태엽 핵(2장 해체 공구로 분해) → 지하 연금술 화로 → 초침을 부수는 대검.
  - 숨겨진 책장 미믹의 시간이 굳은 핏방울 (2/3) → 5장 수장고 석관.
